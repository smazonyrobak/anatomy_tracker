# Atlas patch angular capture 027 — fixed diagnostic

025's descriptor succeeds when supplied a nearly correct plane; 026 proves the true rigid plane scores above the current eight proposals in 97.6% of cases but cannot usefully rank those distant proposals. Before building an enormous point×orientation atlas bank, measure whether the descriptor recognizes one anatomical point when the atlas patch's **plane orientation** is perturbed. This is the missing [SLIV-Reg](https://arxiv.org/html/2410.18683v1) requirement, not another top-eight score experiment.

Freeze 025 batch 3,000. On all 185 eligible sections of the untouched synthetic DEV panel, choose the same 32 GT-valid query points used by 025/026. For each point, render a finite-thickness 64×64 atlas patch at its **known true CCF location**. Start from the section's true rigid affine frame, then rotate the patch plane by ±5°, ±10°, ±20°, ±40° about each in-plane axis (normal tilt) or by ±15°, ±30°, ±60°, ±90° about the plane normal (in-plane roll). Keep center, physical pixel spacing and PSF fixed. Compare each query to the 32 atlas patches from that section at the same perturbation; report identity-equal exact-point top-1, top-1 within 0.5 mm, and descriptor margin over the best incorrect point, grouped by synthetic identity and background mode. The truth center is used **only in this component diagnostic**; the final locator cannot assume it.

Decision: a coarse orientation search is plausible with 025 as trained if top-1 within 0.5 mm remains ≥40% at 10° normal tilt and 15° roll, across the directions/signs, without any input mode falling below half the overall rate. If not, train the cross-contrast descriptor with independently oriented atlas positives or a rotation-equivariant 2D encoder before paying for a global bank. Passing this diagnostic does not establish unknown-plane localization, deformation recovery, real histology accuracy, calibrated probabilities or GUI readiness. Public DeepSlice and final-test animals remain untouched.
