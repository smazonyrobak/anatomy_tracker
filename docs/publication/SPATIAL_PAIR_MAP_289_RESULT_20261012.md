The 288 oracle showed a strong *global synthetic* atlas-intensity signal, not that this 96×96 local cost volume identifies the correct correspondence on damaged fragments. Before changing architecture or coupling map cost back to pose, measure whether the **fixed local patch-matching representation** recovers true offsets at surviving intact and detached-fragment sites under exact pose. That separates correspondence-information loss from decoder/optimization failure. If local matches are present, train a stronger or explicit correspondence decoder; if not, revise contrast-/scale-aware evidence rather than scaling the same network.
