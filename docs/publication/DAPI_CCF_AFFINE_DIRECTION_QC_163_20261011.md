# Published DAPI-average to Allen affine: coordinate-convention QC

The [dataset README](https://gin.g-node.org/doi/B6_dapi_template/raw/10.12751/g-node.16wrxa/README.md) applies its `ccf_to_dapi_affine_transformation.txt` to the Allen average using `antsApplyTransforms` with the DAPI average as the reference. Despite the filename, in [SimpleITK's output-to-input convention](https://simpleitk.readthedocs.io/en/release/fundamentalConcepts.html) this is a **DAPI output physical point → Allen input physical point** pull transform. The DAPI NIfTI encodes millimetres in RAS; SimpleITK reads it in LPS with the first two direction signs reversed. The Allen NRRD is LPS with 25-micrometre voxels. The published matrix already includes the approximately 1000-fold millimetre-to-micrometre scale. Do not invert it or add another unit conversion when resampling Allen data onto the DAPI grid.

The CPU-only `training/qc_dapi_ccf_affine_direction_163.py` reads the source headers and published transform, compares the published pull against deliberately wrong RAS-fed and inverse conventions, and writes `I:/AnatomyTracker/reports/dapi_ccf_affine_direction_qc_163`. At a binned low-resolution grid, published/RAS-fed/inverse coarse threshold-mask Dice was 0.9625/0.6871/0. The corresponding fractions of thresholded DAPI support with Allen template signal were 98.62%/68.41%/0%. The DAPI centre index (661.5, 104.5, 470.5) mapped to Allen index (220.07, 162.46, 227.45); numerical inverse round-trip error was below 2e-15 mm for all inspected points. The saved orthogonal overlay visibly favours the published LPS pull, but local boundaries are not identical.

Raw report: `report.json`, SHA-256 `4dea8f265c9212b3fc82e75671de6c6c9fa336383abe6d979d3ecbb1e2f4eb1e`. Three-plane overlay: `three_plane_direction_comparison.png`, SHA-256 `ffea4b3a354740ba6165a8b5ebeaf80fb06d65381462a83180e61a495392375c`.

**Boundary:** This establishes file-coordinate convention and gross average-to-average agreement only. It does not validate landmarks, small nuclei, individual BM specimen-to-DAPI registration, or native-specimen CCF labels. The independent BM volumes are on a different native grid and require a validated per-specimen transform and anatomical QC before supervised real-image training. This comparison did not open held-out BM17/BM18 images, use labels, train a model, or establish arbitrary-plane accuracy.
