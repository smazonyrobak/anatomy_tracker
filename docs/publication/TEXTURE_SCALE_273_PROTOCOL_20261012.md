# 273: fixed low-pass input comparison

The 272 acquired TRAIN check found a sagittal plane-family failure while visual TRAIN QC had shown substantially finer real tissue texture than atlas-derived synthetic sections. Test one narrow, geometry-preserving explanation before changing the generator or training schedule: does removing high-frequency input texture at inference improve coarse sagittal recognition? This is a controlled diagnostic, not model tuning on a development set.

On the identical 58 coronal and 40 sagittal median-donor TRAIN sections from 272, compare the unchanged 270 checkpoint on raw intensity, fixed 7×7 Gaussian blur with σ=1 pixel, and the same with σ=2 pixels. Blur only the grayscale channel, leaving the four auxiliary channels zero. Confirm raw predictions reproduce 272 exactly. Run the same three arms on every no-brush case of 270's frozen fresh synthetic TRAIN-inner panel, retaining its exact pose/reflection labels and valid tissue chart. Exclude synthetic brush cases because a naïve blur would paint over their explicitly black exterior; the real cohort has no brush.

Report acquired first-choice normal-family correctness and median antipodal normal angle against weak Allen affines, plus synthetic top-16 capture and first-choice valid-tissue site error. A blur is a candidate for a *future training comparison*, not an immediate GUI edit, only if it gains ≥10/40 sagittal first-choice families, loses ≤3/58 coronal first-choice families, and loses ≤4 synthetic top-16 captures relative to raw. This rule is not animal-level validation. A failure means coarse Gaussian suppression of fine texture is not the sole remedy; do not chase multiple unplanned filters on these same TRAIN cases.
