# 059 full-pose anchor-quality continuation: failed development gate

The 50,000-batch run exited normally. It used 100,000 independently drawn, eligible arbitrary-plane synthetic TRAIN sections and 50,000 distinct real TRAIN sections from the reserved pool of 263,754 sections across 1,885 donors. Each synthetic draw independently sampled plane, appearance, deformation and artifacts; accepted backgrounds were 33,365 exact-black, 33,361 raw and 33,274 imperfect-brush. This was not a paired-background experiment and did not reject chance-similar planes. Animal/specimen/experiment/section identifiers and source bindings remain in the frozen draw/config records. The real labels are weak Allen affines, not expert truth. No final-test animals, public benchmark or probability calibration were used.

The frozen evaluation compared steps 0, 10,000, 30,000 and 50,000 on the same 185 eligible synthetic DEV sections from eight held-out synthetic identities and 64 weak-real DEV sections from six separate donors. Inference reserved two inherited candidates and six new-anchor candidates, then scored their fitted atlas maps. All distances below are identity-equal means, not pooled slice averages.

The exact-pose synthetic mapper error remained 0.129 mm: the unresolved error is global pose capture/selection, not local tissue fitting. At step 50,000, all six real DEV donors worsened relative to step 0; the donor-wise mean five-point errors changed from 0.551, 0.625, 0.284, 0.582, 0.804 and 0.754 mm to 1.389, 0.737, 0.349, 0.598, 1.798 and 1.938 mm. The best new synthetic candidates improved substantially, but the fitted selector retained inherited candidates on almost every synthetic image while choosing the new candidates on almost every real image. The scorer was inherited and frozen from the 16-mode parent; this cross-domain misranking is a plausible failure mechanism, not yet a demonstrated sole cause. Normal-only candidate geometry, real weak-label noise, and synthetic/real appearance mismatch remain possible contributors.

**Decision:** no 059 checkpoint advances. None beats the predeclared 019 synthetic reference of 2.591 mm while retaining its approximately 0.595 mm weak-real disagreement. Do not install 059 in the GUI, report its uncalibrated weights as probabilities, or run the DeepSlice benchmark. Retain the 019 checkpoint as the current research reference, not as a shipped replacement. The next minimal diagnostic is to compare fitted scores, image priors, and truth-scored error for the same old/new candidates on the frozen DEV sets. Only if that identifies a recoverable selection failure should a matched scorer experiment be trained; otherwise investigate the global image-to-plane representation, potentially with 2D/3D correspondence, before further large exposure.

These checks establish frozen provenance and numerical reproducibility, not biological accuracy.
