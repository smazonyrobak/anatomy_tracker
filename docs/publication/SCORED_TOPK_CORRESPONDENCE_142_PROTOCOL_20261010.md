# 142: bounded scored-key and atlas-content comparison

Experiment 141 showed that top four coarse neighbourhoods cover 98.18% of globally reachable ≤0.5-mm v4 atlas keys on an oracle-selected near branch, versus 85.07% for top one, but the existing head selected a precise key only 15.39% of the time. This warrants a bounded *scored* comparison, not a claim that four candidates or atlas intensity improve fitting.

The coarse-to-fine matching decision is analogous to [LoFTR's dense coarse matching followed by local fine refinement](https://openaccess.thecvf.com/content/CVPR2021/html/Sun_LoFTR_Detector-Free_Local_Feature_Matching_With_Transformers_CVPR_2021_paper.html), and the explicit unmatched option is analogous to [SuperGlue's correspondence rejection/dustbin](https://openaccess.thecvf.com/content_CVPR_2020/html/Sarlin_SuperGlue_Learning_Feature_Matching_With_Graph_Neural_Networks_CVPR_2020_paper.html). Neither paper establishes that this simpler 2-D-to-3-D cross-appearance matcher works on arbitrary mouse-brain histology; 142 is the test, not a transfer of their reported performance.

Freeze the randomly initialized lineage's 132 step-2,000 pose model and its blind-16 proposal rule. Train four fresh, initially parameter-identical correspondence heads: one versus four coarse 3×5×5 neighbourhoods crossed with Allen atlas intensity-plus-support versus support-only. Use the same independent physical synthetic draws, two v4 and one v3 per update, for all arms; no alternative appearance copies of the same section. Run 1,200 updates (3,600 physical-section presentations) with a checkpoint at zero, 600 and 1,200; first 600 train correspondence/visibility, second 600 also train analytic fit. Use the 140 near/exact *training-only* candidate distribution and inherited 140 optimizer/AMP settings. Do not use DEV truth for model selection or the public benchmark. The scorer must deduplicate clamped/overlapping keys before its softmax, disallow keys with atlas support ≤0.5, and scale the fine dustbin by the number of distinct supported keys. Keep the 132 parent frozen. This is a mechanism pilot, not full-scale final training.

Sharpen the fine target: of the supported local keys, treat only those within 100 µm of the nearest as positives when that nearest key is ≤750 µm from the synthetic observed-pixel truth; otherwise train the dustbin. Retain the 140 coarse target, which rewards supported keys within max(nearest+250 µm, 1,000 µm), the same fixed/auxiliary query mixture, and the 140 affine-fit objective. Training logs must distinguish physical presentations, optimizer updates, positive-key availability, correspondence losses and fit error. Preserve input source/provenance hashes and one physical-section ID per appearance draw.

After exit, independently audit hashes and compare all four step-1,200 heads on the untouched v4/v3 synthetic DEV sections. Freeze the original 132 beam IDs and candidate poses; report truth-best original branch only as an oracle diagnostic, alongside model-prior-selected and best-corrected branches. Primary comparison: scored fine argmax ≤0.5-mm hits per globally supported ≤0.5-mm fixed tissue site on original blind-near branches. Also report blind fitted-plane ≤0.5-mm capture and plan-equal error, whole-beam ≤1.5-mm retention, and angle strata. Within the full-intensity top-four arm, repeat the original candidate with (a) atlas intensity zeroed but support unchanged and (b) source intensity flattened to its image mean, brush channels unchanged, parent features recomputed but original candidate pose retained. These are distribution-shift ablations, not causal proof, and must be described as such.

For further scaling, require on v4: ≥5 percentage points more scored fine hits for full top-four than full top-one among globally ≤0.5-mm sites, ≥5 points more than support-only top-four, ≥10 points more conditional ≤0.5-mm fitted-plane capture than the frozen original blind-near branch, and ≥0.20-mm reduction in plan-equal fitted-plane error. A selected-branch regression or a material v3 retention failure also stops this architecture. If the fine matcher still misses most geometrically available keys or content ablations barely change it, improve anatomical descriptors and the synthetic-to-acquired image model before widening K or feeding fit difficulty into the global pose model. None of these synthetic DEV gates establishes physical all-angle ability, uncertainty calibration, GUI readiness or DeepSlice superiority.
