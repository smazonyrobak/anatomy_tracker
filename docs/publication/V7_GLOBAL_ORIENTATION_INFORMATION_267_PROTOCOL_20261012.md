# 267: conditional full-sphere orientation information in frozen v7 sections

This is a **read-only image-information assay**, not blind registration or model training. The 257 assay showed that an exact atlas render usually beats nearby ±15° tilts, but did not test distant arbitrary-plane normals. Direct normal classifiers (251/254/256), dense regression (260/261), a coarse renderer bank (265), and an orientation-agnostic 2-D/3-D codebook (266) did not deliver reliable global orientation. The narrow question here is whether anatomy in the existing synthetic images distinguishes the exact atlas plane from a deterministic, broad range of distant plane normals **when centre, roll transport, physical raster span/shear, reflection, and through-plane PSF are supplied by truth**. Those privileged quantities are diagnostic only.

Use the fully frozen `one_shot_v7_heldout_dev_panel_248_004` manifest. Before loading an image or computing a score, select the first eight eligible records in stable `records.jsonl` order from each of its eight independent synthetic deformation plans, keyed by `animal_id`. Keep exactly 64 distinct physical-section IDs; do not replace a case based on an outcome. Verify the panel completion/record and selected image hashes. No section is regenerated or paired with a second appearance. The eight plans remain synthetic variations of the same Allen atlas, not independent biological animals.

Construct 112 fixed low-discrepancy equal-area axes on the antipodal hemisphere: `z=(j+0.5)/112`, `phi=j*pi*(3-sqrt(5))`, `x=sqrt(1-z²)*cos(phi)`, `y=sqrt(1-z²)*sin(phi)`, for `j=0,...,111`. For each section, flip each axis toward the true normal and exclude axes with antipodal angular separation <30°. Rotate the *entire* true proper frame by the unique minimal 3-D rotation taking its normal to the candidate normal. This parallel-transports the true in-plane basis; it is **oracle roll transport**, not a roll search. Preserve the true physical centre, positive upper-triangular raster basis (including unequal spans and shear), reflection, original 192-pixel framing, and exact stored finite-thickness PSF offsets/weights. Add the exact true state as the diagnostic positive. Render all remaining distant normals at 96-pixel scoring resolution with the 090 renderer.

Use exactly 257's model-free image score: 3×3-smoothed observed and rendered intensity, absolute Pearson correlation on each positive/negative pair's 5×5-eroded common atlas support. A pair is eligible only with ≥64 common cells, support IoU ≥0.45, and support-area fraction gap ≤0.15. Do not score on the generator's observed valid-tissue mask. For the null, independently and deterministically permute each rendered candidate's intensity *within its own atlas support* before smoothing, without changing support, framing, or the image. Record every axis's angle and angular exclusion; for every distant axis record support eligibility, intact/null positive and wrong scores, and margins. No wrong pose is chosen using the synthetic target other than the specified ≥30° diagnostic separation.

For each case with ≥16 support-eligible distant axes, the all-wrong success indicator is one only if the exact true render's score beats **every** such wrong render on their respective common supports. Compute the same indicator for the shuffled-intensity null. Cases below 16 eligible comparisons remain in the output and count toward coverage, but not the ranking mean. Report per-plan and equal-plan coverage, success, null success, worst wrong angle/margin, appearance and visible-tissue strata. The positive conditional-information gate requires ≥4 qualified cases in **each** of eight plans, equal-plan intact all-wrong success ≥75%, at least six plans individually ≥75%, and an equal-plan intact-minus-null success advantage ≥20 percentage points. Otherwise the gate fails or is coverage-inconclusive; no favorable subset may replace the fixed 64.

A pass would show a global normal signature **conditional on privileged nuisance parameters and this score**, pointing toward the blind capture/learning mechanism as the bottleneck. It would not prove that blind full-sphere search, deformation, acquired-image registration, or probability calibration works. A failure cannot prove arbitrary-plane identifiability is absent: the correlation score, atlas-to-subject appearance gap, support eligibility, and unprofiled wrong-pose nuisance values may still limit the assay. Do not turn the diagnostic true-pose rank into a deployed accuracy claim. Keep all files on `I:` with source/protocol/panel and per-case hashes; do not access CAL/FINAL biological animals or the public DeepSlice benchmark.
