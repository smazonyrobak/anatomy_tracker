# 073: blind whole-plane correlation pilot — rejected

The first learned coarse correlation head **did not improve selected plane accuracy** and is **not a GUI candidate**. The independent frozen-panel evaluation used the same 246 synthetic DEV sections/eight deformation identities and 64 weak-real DEV sections/six held-out donors at checkpoints 0, 250, 750, 1500 and 2500. At batch 2500, identity-equal selected rigid synthetic error was **2.988 mm**, versus **2.656 mm** for the pinned 059 prior. Best-eight coarse correlation proposals reached **1.250 mm**, versus 1.022 mm for the prior's less restrictive best-of-14. The predeclared advancement criteria (selected ≤2.20 mm and best-eight ≤0.75 mm) were not met. At batch 250 the synthetic selected error was 2.952 mm; longer training through 2500 did not improve it.

The real-data warning is stronger: selected error against Allen-derived **weak** five-point affines was **1.276 mm** at batch 2500 versus **0.694 mm** for the matched prior. Donor-level selected errors rose from 0.722 to 2.014 mm for donor 15219 and from 0.330 to 2.657 mm for donor 15336. These are weak reference labels, not verified histological ground truth, but the donor regression fails the development transfer gate. Best-eight weak-real error was 0.500 mm, which shows candidate-ranking headroom without validating the labels. In synthetic DEV, 171/246 sections had a best-eight candidate below 1 mm but only 64/246 selected predictions were below 1 mm; 25 selected predictions exceeded 5 mm. Imperfect-brush sections averaged 3.419 mm selected error, versus 2.815 mm for exact black and 2.864 mm for raw.

Training used 2500 distinct accepted arbitrary-plane synthetic **TRAIN** sections drawn independently from 64 provenance-preserved training animal identities, not paired appearance copies; 267 draws were rejected by the generator's eligibility rule. Appearance counts were 828 exact-black, 835 imperfect-brush and 837 raw. The parent was the random-initialization-lineage 059 checkpoint; only a new learned shared query/atlas correlation head was trained. All source and parent hashes, checkpoint receipts, 1550 evaluation rows, 246/64 case identities per checkpoint and identity-equal means were independently verified after both processes exited. Frozen artifacts are on `I:/AnatomyTracker/runs/whole_plane_correlation_073_pilot_002` and `I:/AnatomyTracker/runs/whole_plane_correlation_073_development_eval_001`.

This pilot trained and evaluated only the **coarse** 0.5-mm offset, 30° roll, three-scale, 0.0625-edge translation grid. It did not yet implement or qualify the preregistered fine refinement, so its best-eight number is not a final test of the full 073 lattice. The 073 truth-assisted geometry construction already showed a rounded fine-grid pose at 0.426 mm on average, but supplied synthetic CCF truth to find it. The present gap is therefore both a coarse-resolution limit and a blind selection failure. A targeted next experiment should retain more diverse complete-plane candidates and rank them with fit evidence on the *same inferred candidates*; it must beat the old prior on the same cases and avoid real-donor regression before exposure is scaled. No biological animal-level ground-truth validation, calibrated region probabilities, public DeepSlice benchmark, or GUI promotion occurred.
