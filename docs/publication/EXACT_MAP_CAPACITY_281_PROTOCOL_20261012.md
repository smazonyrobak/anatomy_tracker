# 281: exact-plane local-map capacity check

280 failed: a trained atlas-conditioned fit score did not beat a trained support-only score enough, and its true-plane map was essentially zero despite 0.213-mm mean coordinate residual. Before another learned scorer or full model run, test whether the existing map geometry can express that synthetic residual. This is a bounded TRAIN-only coordinate-oracle experiment, not image-based prediction, checkpoint selection, or qualification.

Freeze the synthetic v9 generator and its atlas/data bindings. With seed `20261012281`, draw four new eligible independent physical sections per held-gradient TRAIN base 56–63 (32 total), without deliberate pose reuse or appearance pairing. Log every attempted draw and exact provenance. No 280 panel section, DEV/CAL/FINAL animal, acquired evaluation case, or public benchmark enters this diagnostic. Supply each section's true synthetic rigid state and reflection, and evaluate the same 512 deterministic surviving-tissue pixels used by 280. Use the same 64×64 raster/192-source coordinates, same-grid no-warp baseline, full-canvas affine-component removal, reflected canonical field, physical derivative bound 0.35, and bilinear site sampling as the 280 exact-plane map.

For each section, fit a requested displacement field directly to the **known synthetic CCF coordinates** using mean Euclidean site error, with no atlas image or ranking loss. Evaluate two parameterizations under the identical geometry and optimizer budget: independent 64×64 requested values (the current decoder's most permissive raster) and a bilinearly upsampled 16×16 control grid (a smoother counterfactual). Initialize both at zero. Optimize 300 Adam steps at fixed learning rate 0.1 in tanh-logit units, with requested displacement `1000*tanh(logits)` µm, the same affine projection and global derivative rescale, and no extra magnitude penalty. Save the best *feasible* step by exact evaluation at 0, 100, 200, 300; report steps and trace so a failure cannot be silently attributed to no optimization. Separately fit a least-squares 3D affine residual in full-canvas `[1,s,t]` coordinates on these sites and report its error reduction as a **diagnostic of pose/local-gauge confounding**, not as an admissible local-map result. Record pre/post derivative bounds, removed affine component, field displacement mean/RMS, no-warp and fitted CCF error on identical sites, event flags (fragment, fold, bubble, seam), valid/visible fraction, obliquity, and exact donor/virtual subject/physical-section lineage. Do not call this coordinate-fitted field a deployable predictor.

Interpretation is deliberately asymmetric. A ≥0.05-mm panel-mean gain by either coordinate oracle **proves** that parameterization can represent a useful correction on these 32 sections, so 280's near-zero learned field then points toward image correspondence or optimization of shared losses. A smaller optimized gain does *not* prove impossibility: finite-step nonconvex parameterization, gauge, interpolation and global cap may limit the optimizer. A large affine-only reduction with small affine-free local gains means 280's frozen-true-pose map target was dominated by changes that belong in the joint pose state; do not misdiagnose that as a failure of atlas appearance. Compare gains by artifact subgroup and sparse support descriptively; no subgroup is a performance gate. If both capacity probes remain small, inspect gauge/derivative saturation and consider explicit piecewise fragment correspondence rather than simply scaling the same network. If the smooth 16×16 field works substantially better, replace the noisy 64×64 global-rescale path with a smooth control-grid map before another trained comparison. No result here licenses GUI promotion, real-location claims, electrode probability, or DeepSlice benchmarking.
