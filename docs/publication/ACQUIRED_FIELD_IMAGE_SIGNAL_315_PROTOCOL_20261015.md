# 315: is the acquired residual field visible in the current atlas image?

Before changing architecture or training longer, test whether the *human* affine-free VisuAlign correction itself improves image-to-atlas appearance at that plane. This is a no-training, no-model-selection information check, not physical ground truth or an animal-independent validation.

Use exactly the same 52 valid `AL1A` sections, raw full-thumbnail max(red,green)/p99 input resized to 192 pixels, human QuickNII O/U/V coordinate conversion, 96-grid VisuAlign CSV sampling and unweighted full-canvas affine projection as 314. Render the current bound Allen atlas intensity with the normalized five-sample ±50-µm PSF at the supplied human plane for four fields: zero, human affine-free residual, its sign-reversed control, and the raw full human field before affine projection. Query atlas coordinates at the *observed-image pixel plus the field*; do not warp the acquired image. The negative-field control preserves displacement magnitude and smoothness. The raw field distinguishes added affine/pose correction from the locally representable residual. No trained checkpoint is needed. Score all four on the same source tissue-mask pixels intersected with each rendering's atlas support >0.5 and eroded by 7×7; exclude sections with <400 common pixels.

Use two fixed, sign/contrast-tolerant scores from the earlier 189/204 assays: absolute Pearson correlation of 3×3-smoothed image intensities, and negative squared distance between 8-neighbor, 3-pixel MIND descriptors. For each score report the paired affine-free-human-minus-zero, affine-free-human-minus-negative and raw-full-human-minus-zero differences, positive-section counts, means and medians. A **descriptive signal gate** requires at least 35 of 52 sections to favor the affine-free human field over both zero and negative and positive median margins for *both* score types. If fewer than 45 sections pass common support, call the gate inconclusive. This is a per-section process gate within one already-inspected TRAIN animal, not a statistical claim about independent animals.

Save all per-section provenance, source and output hashes, and a fixed four-section QC grid chosen by ranks 7, 20, 33 and 46 of the 314 zero-field RMS (ascending), with acquired input and all four rendered atlas fields. No DEV/CAL/FINAL source, public benchmark, physical oblique claim, calibrated probability, or GUI route is involved.
