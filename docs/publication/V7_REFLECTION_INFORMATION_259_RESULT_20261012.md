# 259: the mirror branch is locally distinguishable in support-matched v7 cases

The frozen read-only assay compared the saved true and opposite horizontal reflections at the **same true atlas plane** for all 227 eligible synthetic DEV sections. It used the 257/180 smoothed atlas-intensity score, a deterministic shuffled-intensity null, and no regenerated or paired appearances. One hundred thirty-five sections met the prespecified common-support criteria, spanning all eight synthetic deformation plans; 92 were excluded because support was not sufficiently comparable.

Equal weight to each plan, the true reflection won **99.17%** of eligible sections, versus **45.84%** for shuffled atlas intensities. The raw count was 134/135. Exact-black, imperfect-brush and raw/variable-background eligible sections had 20/20, 17/17 and 97/98 true-branch wins, respectively. The lowest-visibility stratum had only six eligible sections and 5/6 wins. The predeclared substantial-information condition (≥80% wins and ≥20 percentage points above null) passed.

This rejects a narrow version of the hypothesis that v7 mirror ambiguity alone forces 258's coordinate map to collapse: in support-matched cases, an anatomical comparison of the two correct-plane reflections is highly informative. It does **not** show that a direct image-only network has learned this comparison, that the 92 excluded sections are decidable, or that real tissue has the same symmetry. A probabilistic model should still preserve multiple hypotheses for genuinely ambiguous or low-tissue slices. The more immediate 258 failure remains its missing physical span and near-random normal-axis estimate; direct fitted edge/plane supervision and better use of atlas evidence are warranted before more unchanged training.
