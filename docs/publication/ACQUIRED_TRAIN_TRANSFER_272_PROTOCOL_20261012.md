# 272: raw acquired TRAIN orientation-transfer diagnostic

Before more synthetic-only training, examine whether the frozen 270 image-only pose proposals recognize **actual** mouse histology at all. Use the 58 donor-distinct coronal TRAIN inputs in `joint_v7_allen_fullcanvas_192_001` and 40 donor-distinct sagittal TRAIN inputs in `allen_sagittal_ish_expansion_002_train_inputs_20261008`. Select the median section number (tie-break by section ID) of each donor, one section per donor. No acquired DEV/CAL/FINAL section and no public benchmark enters this diagnostic.

Pass each source's existing model-preprocessed intensity as the raw, unbrushed five-channel input (four channels exactly zero). Area-downsample the sagittal 256-pixel input to the 270 model's 192 pixels, without making a second image of the same section. Do not supply Allen metadata, labels, a segmentation, a neighboring section, or any constraints to inference. Evaluate the 270 selected checkpoint's first and top-16 image-only pose proposals. Compare normal-axis family (AP/DV/ML), antipodal normal angle, atlas centre, and minor field-of-view only against each section's *weak* Allen affine metadata. Record both donor/specimen/experiment/section IDs and source hashes. The Allen registration is not blinded expert ground truth, especially for local site accuracy; no millimetre error here is a validated localization metric.

This is a diagnostic rather than a checkpoint-selection gate. If either acquisition plane family is frequently misclassified, pause synthetic-only scaling and address the acquired-versus-synthetic appearance/framing mismatch. Passing coarse family recognition would still not establish arbitrary-oblique physical generalization, deformation quality, calibrated uncertainty, or deployment readiness.
