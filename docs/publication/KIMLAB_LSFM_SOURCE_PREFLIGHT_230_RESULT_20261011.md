# 230: KimLab LSFM is coordinate-compatible alternate contrast, not new truth

The [frozen source-only protocol](KIMLAB_LSFM_SOURCE_PREFLIGHT_230_PROTOCOL_20261011.md) completed. Both official 25-µm files were downloaded **only to I:** and matched the [Mendeley v1 file metadata](https://data.mendeley.com/api/datasets/2svx788ddf/files?version=1) byte counts and SHA-256 values exactly. The files are the 96,231,610-byte Allen CCF companion (`bb0b935dd60a567e9744eb4b99ff6300c7693e022408f7b34911ad4835b09ae8`) and the 61,578,216-byte registered LSFM average (`41b4606354a2d5b05a88899e707f9b8690c472b7e46e594646b847af7d4d5b4f`). The [dataset record](https://data.mendeley.com/datasets/2svx788ddf/1) lists CC BY 4.0; attribution and any separately sourced Allen-layer rights must be preserved in downstream use.

Both NIfTIs are finite `uint16`, 527×319×455, with identical qform/sform and 25-µm affine. In RAS millimetres, index increments are posterior `(0, −0.025, 0)`, inferior `(0, 0, −0.025)`, and right `(+0.025, 0, 0)`. The companion CCF image matches the first 527×319×455 voxels of our pinned Allen average at the **same array indices**: Pearson 0.999740 on the preregistered stride-four subgrid, versus at most 0.954217 among seven axis flips. Its intensities are rescaled, so absolute differences are not evidence of an anatomical mismatch. This independently resolves the `ASL_Oriented` axis ambiguity for this release without inventing a transform from the filename.

The LSFM average has broad tissue-support agreement with the pinned Allen annotation (descriptive Dice 0.977939 on the same stride-four grid when LSFM intensity >1,000), but inside that support its intensity correlation with the CCF companion is only 0.240858. The [fixed three-plane visual check](I:/AnatomyTracker/reports/kimlab_lsfm_source_230_001/fixed_orthogonal_views.png) shows matching gross anatomy and genuinely different internal contrast, with visible local differences and some edge artifacts. This supports a **small, matched alternate-modality source ablation**; it does not prove pixel-accurate correspondence, realistic physical histology, or more biological diversity. The LSFM is a population average already registered to CCF, not a new independent specimen. The released isotropic voxel grid is not evidence of isotropic acquisition; the related [DevCCF methods](https://www.nature.com/articles/s41467-024-53254-w) report anisotropic LSFM optical/z sampling followed by resampling, but describe a later release and do not establish this exact 2022 file's full processing history.

The source-only receipt is `I:/AnatomyTracker/reports/kimlab_lsfm_source_230_001/source_preflight.json`; it pins both source hashes, Allen template/annotation hashes, script and protocol hashes, affine, metrics and figure SHA-256 (`eac0abf835a27c23e304f9131fc73e61e5d05722e1d6f8638e3c69205d8930d7`). No model weights, training rows, donor split, calibrated probabilities, GUI output or public benchmark changed. The next experiment must isolate whether this extra contrast improves blind pose ranking and acquired TRAIN retention on matched draws; failure means no scale-up. Independent physical steep-oblique animal truth remains necessary for the all-angle claim.
