# 227: matched shared versus untied orientation-anchor correction

The 226 pose-exposure gate failed: extra arbitrary-plane appearances barely changed blind first-choice error. Its 64 orientation anchors are separately projected, their best geometric branch often beats first choice, and the free-pose family still wins the score. The 138 shared-correction trial could not test selection because it froze the scores. This small TRAIN-inner experiment asks whether sharing an image-conditioned correction across anchors improves both their geometry and probability ranking when the common image encoder and free-pose head may adapt.

Continue the same project-random-initialized 226 step-1,200 parent in two arms. Add a zero-initialized, 18-output correction to each existing anchor's raw state and score logits. Both arms receive the same pooled image features, each anchor's fixed local frame, and its existing 18 raw values. One arm shares the final correction projection across all 64 anchors; the other gives each anchor its own final projection. All old anchor projections remain frozen; update the new correction, common image encoder/lateral features, and free-pose head with exactly the 226 loss, learning rates, and 1,200-batch schedule. The only intended arm difference is final-projection sharing. Confirm step-zero predictions reproduce the parent and the draw identities match arm-to-arm. The untied arm has more trainable final-projection parameters, so a shared win despite that asymmetry is informative; an untied win does not by itself prove sharing is harmful.

Each batch has independently sampled v4 framed, v7 framed, and legacy v3 synthetic sections, one Lupori TRAIN weak-reference section, and one alternating older coronal/sagittal TRAIN weak-reference section. AL1A is excluded from gradients. Record complete draw/provenance rows, train losses, 0/400/800/1,200-batch checkpoints, source/protocol/input hashes, and completion receipts on I:. No deliberately paired appearance duplicates.

After both runners exit, read out the same 64 frozen 221 framed and 32 legacy cases, 64 frozen 226 v7 cases, and 64 newly drawn v7 framed cases, using identical case pixels for all checkpoints. The new cases use procedural bases 60–63, but prior training used those bases for some legacy draws, so this is **case-independent TRAIN-inner diagnosis, not synthetic-animal separation or real-animal validation**. Score every one of the 160 pose/reflection hypotheses with the physical tissue-distance oracle only for diagnosis, and report first choice, best-of-160, top-16 capture, normal-axis error, anchor-best error, anchor-best score rank, anchor-versus-free score gap and anchor mass. Never feed oracle choices back into model outputs.

The primary synthetic progression gate requires a single checkpoint to lower new-v7 first-choice median tissue error by at least 0.30 mm versus the unchanged 226 parent, improve new-v7 top-16 <2-mm capture by at least 0.05, avoid >0.20-mm first-choice regression on frozen 221 framed and 226 v7 panels, and avoid >0.15-mm best-of-160 regression on any panel. An anchor-specific mechanism claim additionally requires the highest-scored anchor branch to improve in median tissue error and the first-choice anchor rate to increase, without merely shifting probability mass to bad anchors. Compare both arms and all frozen checkpoints, but do not choose a model by a favorable single case or stratum. Any checkpoint passing this gate must still pass AL1A and distinct old TRAIN-donor weak-affine retention before further scaling. Weak affines are not physical truth.

Do not access reserved DEV/CAL/FINAL animals, physically oblique material, or public DeepSlice benchmark; do not calibrate probabilities or alter GUI inference. If neither arm passes, stop the anchor-correction recipe. The experiment is a pose selection study, not evidence that the joint pose/deformation feedback objective is solved.
