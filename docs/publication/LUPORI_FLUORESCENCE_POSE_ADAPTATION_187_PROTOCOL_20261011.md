# 187: bounded fluorescence-domain pose-capture experiment

This is **not** a new architecture or a qualifying benchmark. Continue the existing scratch-initialized 132 step-2000 model after [185/186 TRAIN label QC](LUPORI_TRAIN_LABEL_QC_185_AND_POSE_BASELINE_186_20261011.md). Its acquired Lupori candidate recall is too low for a fitter/ranker to be meaningful. The intervention is image-domain adaptation of the *same* probabilistic pose heads and shared encoder, with the atlas matcher, local mapping head and uncertainty head frozen. Do not claim calibrated probabilities, solved deformation, steep-oblique real validation or GUI readiness.

The frozen animal roles remain TRAIN `AL1A, CC2B, CC4B, CC4A`, DEV `CC1B`, CAL `CC3A`, FINAL `CC1A`. For this *inner pilot only*, hold `AL1A` out of gradient updates as a guarded TRAIN animal; use valid sections of `CC2B, CC4B, CC4A`. Neither official DEV/CAL/FINAL images nor their registrations may be opened by the trainer. Source image input is the original thumbnail resized whole-frame to 256×256, `max(red,green)/255` then divided by its image-wide 99th percentile and clipped to [0,1]; the human mask weights training target sites only and is never needed to prepare an input. Channels 1–4 are zero, so the optional smart brush is not a dependency. A repeated real section in a later epoch remains the *same* observation, not a new synthetic section or cosmetically re-generated duplicate. Shuffle real sections each epoch and never repeat within an epoch. Preserve mouse, source section, image path and source DOI; experiment ID is unavailable rather than invented.

Every optimizer batch has three fresh independently sampled v4/v4/v3 full-sphere synthetic sections, one Lupori real section, and one old weak-real rehearsal section alternating between the existing TRAIN coronal and sagittal families. Reject an ineligible synthetic draw without reusing its plane under another appearance. No pretrained external weights, features or pseudolabels. Optimize only the shared encoder/lateral layers and probabilistic pose heads. The Lupori reference is the human VisuAlign O/U/V plane converted via `quicknii_to_allen_points`/`quicknii_to_allen_vectors`; score 128 sampled tissue points plus five finite-frame points and physical normal. Use the existing 132 mixture spatial loss for synthetic and old-real rehearsal, with the same style of mixture ranking for Lupori. This adds no target mask or field to inference input and no local field to the pose loss. Only once this stage captures acquired planes will fitting difficulty be fed back into the pose network.

Run 1,200 optimizer batches, save steps 0/400/800/1200, log exact source and draw IDs, source hashes, RNG state and losses. The primary post-exit gate is on the 52 valid `AL1A` sections, comparing all milestones to the identical 132 baseline input: first-choice median five-point CCF error must drop at least 25% from 7.198 mm, and all-160 ≤1.5-mm candidate count must rise from 3/52 to at least 12/52. Report the prior-top-16 oracle separately. Then require no more than 10% regression in first-choice errors on each frozen v3 and v4 synthetic DEV panel and no material old-acquired donor-macro regression. Select among predeclared checkpoints using this guard only; *do not* tune on `CC1B`. Even a passing inner pilot calls for retraining on all four TRAIN animals, one reserved-DEV evaluation, then joint pose/map feedback work. A failed inner pilot should trigger a domain/architecture diagnosis, not a full-benchmark run or a blind longer continuation.
