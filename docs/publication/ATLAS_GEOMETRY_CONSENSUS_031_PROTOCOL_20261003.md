# Oriented-patch geometric consensus 031: frozen development protocol

030 passed its necessary *availability* gate, but those top-16 lists contain many wrong matches. This fixed experiment asks whether the correct matches can be selected and turned into a whole-section plane without using their ground-truth coordinates. It uses the frozen 030 rows and atlas-only bank, with no weight updates or new lookup.

For each of 32 oracle tissue-selected query pixels, each of its 16 atlas matches defines a full image-to-atlas affine seed: matched CCF point plus the bank's 67 µm/pixel in-plane axes; the recorded query-flip parity reverses the horizontal axis and plane normal. A seed receives support from another query when one of that query's top-16 entries lies within 1.5 mm of the seed's projected 3D point **and** its oriented frame is within 35°. Score a seed by the sum of the best per-query quality, equally penalizing position and frame disagreement. Select the highest-scoring seed; fit one three-dimensional affine plane to its supported correspondences using a small fixed derivative prior toward the seed frame. If fewer than three queries support the seed, return the seed plane. No synthetic truth coordinate, tissue mask, correct-plane orientation or 019 prediction enters the selection or fitting calculation.

Only **after** selecting and fitting, compare mapped coordinates against every valid tissue pixel's known synthetic CCF coordinate on the unchanged 185-section/eight-identity DEV panel. Report identity-equal mean and per-section rigid mapping error, the fraction below 0.75 and 1 mm, number of supported points, and raw/black/brush strata. The preregistered necessary gate is mean rigid error below 1.5 mm **and** at least 30% of sections below 0.75 mm. This is a diagnostic with oracle tissue-pixel sampling: a pass supports replacing that oracle selection with image-derived point selection and integrating the proposal into joint fit-feedback training. A failure means retrieval availability alone does not give a usable pose. Neither outcome is a real-animal result, calibrated probability, GUI replacement or public benchmark.
