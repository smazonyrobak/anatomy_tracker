# Frozen protocol — actual-generator steep-oblique visual audit

The 301 visual sample contained no cuts ≥45° from the nearest anatomical axis. This is a deliberately angle-stratified *qualitative* TRAIN-only check, not a prevalence estimate, performance gate or change to the generator.

- Draw one independently seeded v9 section from each synthetic TRAIN base animal 48–53, rejecting only ineligible draws and sections whose **post-artifact fitted** normal is <45° from its nearest cardinal axis. Record every attempt, seed, virtual subject, rejection reason and full accepted provenance. Nothing about the previous accepted section is carried into the next draw.
- For each of the six accepted sections, show the frozen 275 first-choice rendered atlas plane next to the actual v9 synthetic image and the fitted true atlas plane. Use the original finite-thickness schedule. Compute frozen first-choice rigid-site error against the dense CCF map on intact pixels for context, not as a benchmark.
- Select no examples by visual appearance or prediction result. Save a six-row grid, case metadata, frozen source/input/output/figure hashes on I:. Do not use DEV/CAL/FINAL animals, public benchmarks, prior external weights/features/pseudolabels, or real labels.

The displayed samples establish only that the generator actually produces steep independent oblique cuts and whether they look visually plausible. Six selected synthetic cases cannot establish physical arbitrary-plane competence or support a cardinal-plane restriction. Physical oblique multi-animal acquisition remains necessary.
