# Bounded TRAIN-only feature-combination check

The corrected 96-case HOG readout showed modest independent anatomical-ranking signal but did not beat the inherited fitted selector when used alone. Before adding parameters or changing the main network, test whether the signals complement each other on those same TRAIN-only records.

Freeze a single four-feature, ridge-regularized linear within-case ranker: negative image-prior score, negative inherited fitted score, rigid HOG distance, and warped HOG distance. Center each feature across the eight candidates of one section, divide by TRAIN-fold feature standard deviations, and regress centered fitted-mapping error in millimetres with fixed ridge coefficient 32. Use five deterministic folds formed by **base synthetic subject** identity, not virtual affine variant, so an anatomical deformation base cannot appear in both training and cross-fit readout. Each fold is predicted by weights fit only on the other four. No hyperparameter or feature selection after seeing the result.

Report case-equal and base-subject-equal selected error, comparison with inherited fitted selection and best-eight oracle, raw/nonraw and heavy/less-oblique changes, and per-fold coefficients. A ≥0.20-mm base-equal improvement with no raw or heavy-oblique regression beyond 0.20 mm would justify training a new observable-evidence head on a larger fresh TRAIN stream and testing it once on an identity-disjoint panel. Failure means that adding this small scalar evidence to the current matcher is not an adequate solution. This cross-fit is not physical or final validation; no weights, DEV, holdout, benchmark, calibration or GUI state change.
