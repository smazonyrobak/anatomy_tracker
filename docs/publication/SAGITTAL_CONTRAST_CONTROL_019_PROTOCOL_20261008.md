# One fixed contrast control for failed sagittal transfer

The frozen 019 sagittal transfer failed at 63.77° donor-equal selected normal error. Before a second inference readout, the **TRAIN-only** 160 acquired sagittal inputs gave median per-image 99th percentile 0.140866 in the saved once-inverted intensity channel, versus six artifact-QC synthetic samples with substantially stronger contrast. This is a mechanistic control, not a plan to duplicate sections in training or tune a model on weak DEV.

Use the exact same 80 weak-DEV images, five-point affine references, checkpoint, model and readout as `SAGITTAL_WEAK_TRANSFER_019_PROTOCOL_20261008.md`, changing only channel 0 to `clip(4.259364821544654 × input, 0, 1)` once. The global gain is fixed as `0.6 / 0.14086607396602638` from TRAIN data, not selected by looking at weak-DEV outcomes. Other four channels remain zero. Keep the original readout as the paired baseline; report donor-equal selected five-point disagreement and antipodal normal angle, plus best predicted branch and 15° uncalibrated mode mass. Do not try additional gains or crops within this control.

An improvement of at least 20° selected normal **and** 2 mm selected five-point disagreement would make contrast a plausible major contributor for further TRAIN-side investigation. Smaller change means fixed input gain alone does not explain the failure. Either result is exploratory: the reference is an automated weak affine, the four donors have already been used for development, and this control cannot certify arbitrary physical obliques, dense warp, GUI readiness or calibrated uncertainty.
