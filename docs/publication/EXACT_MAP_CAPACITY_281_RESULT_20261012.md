The smooth control grid recovered 79% of the same-site mean baseline error versus 29% for the free grid, and improved all eight base means by 0.109–0.194 mm. Five sections had <15% visible support. Maximum measured post-limit derivative was 0.3500001, consistent with the 0.35 cap within floating-point tolerance. The minimum global rescale was 0.0176 for free64 versus 0.1213 for smooth16, consistent with sharp free-grid gradients shrinking the entire field. These measurements do **not** prove the free64 field lacks representational capacity: a dense grid can express the upsampled smooth field, but it optimized much worse under the same global max-derivative rescaling. Many per-section best readouts remained at step 300 (25/32 free64, 19/32 smooth16), so neither oracle is established as converged.

The affine-only fit improved 0.050684 mm but is excluded from the local-map threshold. It shows pose/local gauge matters, although a full-canvas affine-free field can still mimic some affine motion on a partial tissue support; this single diagnostic does not uniquely partition pose and local deformation. Most importantly, the large smooth16 gain proves there is substantial correctable signal in synthetic coordinates under the current topology bound. Therefore 280's near-zero *learned* map should not be explained as absence of warping or as proof that arbitrary-angle slicing is impossible. The next bounded comparison should test whether a randomly initialized image-conditioned mapper can learn smooth controls on new TRAIN sections at the true plane, matched against the existing free-grid decoder, before putting fit feedback into a larger joint pose/deformation run. Real animal-separated oblique accuracy, uncertainty calibration, electrode-region probabilities, and the DeepSlice benchmark remain untested. Smooth control grids have precedent in nonlinear histology registration, but this coordinate-oracle result alone does not establish biological accuracy ([Casamitjana et al., 2025](https://www.nature.com/articles/s41586-025-09708-2)).
