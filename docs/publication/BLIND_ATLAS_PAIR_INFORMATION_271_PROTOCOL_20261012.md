# 271: atlas information among actual blind proposals

This is a model-free diagnostic, not a new model or an inference rule. Conditional assays 257/267 found strong atlas information when the correct pose or its nuisance framing was supplied. Blind selectors 016/090/178 failed or exploited tissue support. The question here is narrower: on the selected 270 image-only top-32 branches, can *the same observed pixels* distinguish a physically near branch from a clearly worse one using atlas intensity, at matched atlas support? Run only after 270 has exited and its independent verifier has passed; a failed 270 capture gate does not turn this diagnostic into a promotion.

Use the frozen 270 fresh v9 64-case TRAIN-inner panel and its predeclared selected checkpoint. Reconstruct each panel section with its exact generator seed solely to recover its true nine-sample thickness offsets/weights, and assert that the generated image matches the saved panel image. Rank 160 pose/reflection branches from the image alone; take the top 32 with no truth adjustment. Render each candidate's original 192-pixel chart at 96 pixels with those same offsets/weights. For every top-32 pair whose first branch has ≤1.5-mm valid-tissue physical error and whose second has ≥2.5 mm, require at least 64 cells on their common 5×5-eroded atlas support, support IoU ≥0.45 and support-area gap ≤0.15 of the canvas. These truth thresholds select **analysis pairs only**; they must not choose a candidate in any model output.

Score the input and each atlas intensity on the identical pairwise common pixels using absolute Pearson correlation after 3×3 smoothing, exactly as assay 257. Repeat with each candidate's atlas intensities independently permuted *within its unchanged support* using a deterministic section/branch seed. Also record which branch the image-only log mass prefers. Thus the intact, intensity-null and prior decisions see identical branches and pair labels; support matching is enforced rather than learned. Report pair counts, per-case/per-base fractions, intact/null/prior concordance, and tissue-visibility and angle strata. Do not infer a global posterior or use an all-candidate score across different masks.

The information gate requires at least 200 eligible near-versus-far pairs from at least six synthetic bases, equal-base intact concordance ≥70%, intact minus null ≥15 percentage points, and intact minus image-prior ≥10 points. Because pairs within a section are dependent and the panel selected 270 checkpoints, a pass justifies one fixed-score confirmation on identity-disjoint synthetic DEV; it does not justify joint training, GUI deployment, or numerical probability claims. A fail blocks another similar scalar/spatial atlas reranker and directs work toward better pose proposals or a different anatomical representation. No acquired CAL/FINAL labels or public benchmark are used.
