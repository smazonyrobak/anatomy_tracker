# Dense atlas correspondence 083: held-out synthetic gate passed

The frozen 6,000-batch pilot and independent development evaluator exited normally. The parent 059 image/pose model remained fixed; only a randomly initialized 083 image/atlas embedding pair and correlation temperature were trained. No externally pretrained features or weights were used. Each accepted presentation was a fresh arbitrary-plane synthetic draw with independently sampled deformation, appearance, artifacts, and one background/brush mode. The 6,580 recorded attempts produced 6,000 accepted sections with 6,000 distinct physical-section IDs: 1,999 exact-black, 2,035 raw-background, and 1,966 imperfect-brush. Chance-similar planes were not rejected. All files and caches for this work are on `I:`.

The evaluator used the frozen 061 panel: 246 eligible sections from eight independent held-out synthetic deformation plans. For each image it took the physically best *existing* candidate in the blind 14-branch beam and one fixed other candidate, then measured visible, in-window image-to-atlas query centres. The best candidate is an oracle **for this mechanistic correspondence test**, not a deployable branch selector. Plan-equal means are below; top-1 error is the 3-D physical error of the highest-scoring local atlas cell, not whole-slice mapped error.

| ---: | ---: | ---: | ---: | ---: |
| 0 | 5.363 | 2.740 | 6.281 | 4.590 |

| 3,000 | 4.060 | 1.790 | 4.435 | 3.028 |

At 6,000 batches, coarse CE improved 31.1% and coarse top-1 error 36.9%, with fine CE improving 25.3%. This passes the predeclared ≥20% coarse CE and top-1 improvements and ≤5% fine CE regression gate. Support counts were unchanged across checkpoints: 18,046 supported coarse and 55,001 supported fine query centres across the two candidate roles. Both the physical-best and fixed-other roles improved, as did exact-black, raw-background, and imperfect-brush strata. The brush stratum remains slightly worse than the others at the final checkpoint; no per-stratum performance claim beyond this panel is warranted.

**Decision:** advance only to conditional joint pose/deformation/ranking training. The 083 result isolates learnable local correspondence; it does **not** fix 081's wrong-branch selection or demonstrate an accurate arbitrary-plane end-to-end model. The next experiment must train fitting feedback and the scorer on the beam distribution used at inference, explicitly measure selected versus truth-best mapped error over all 14 candidates, and retain the 059/081 matched baselines. Do not promote 083 to the GUI or infer calibrated location/electrode probabilities. Real acquired labels remain weak Allen affines, not verified pose truth. Reserved animal-level calibration and final-test images/alignments remain unopened, and no DeepSlice benchmark was run.
