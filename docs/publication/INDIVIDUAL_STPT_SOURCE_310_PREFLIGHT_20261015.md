# Individual registered STPT source: bounded preflight, not training approval

The [Allen CCFv3 publication](https://pmc.ncbi.nlm.nih.gov/articles/PMC8152789/) provides [55 registered transgenic-channel volumes](https://download.alleninstitute.org/publications/allen_mouse_brain_common_coordinate_framework/transgenic_lines_25_um_grid/transgenic_lines/) alongside its [25-µm template](https://download.alleninstitute.org/publications/allen_mouse_brain_common_coordinate_framework/transgenic_lines_25_um_grid/ccf/average_template_25.nrrd). The accompanying template's downloaded SHA-256 is `e4a2b483e842b4c8c1b5452d940ea59e14bc1ebaa38fe6a9c3bacac6db2a8f4b`, **identical** to this project's pinned Allen template. One bounded individual source, `472393704_red.nrrd`, was downloaded only to `I:/AnatomyTracker/data/allen_stpt_individual_qc_310` (SHA-256 `ed97ff8c78f64116f94d44105e1842e22dee1c7b8189910da2712b66e7474f29`). Neither entered model gradients or any reserved validation cohort.

The individual NRRD header specifies `456×320×528` uint16 voxels but no space directions, origin or spacing; the template specifies `528×320×456` with 25-µm LPS directions. Transposing the individual array `(2,1,0)` and comparing every axis-flip combination at 100-µm stride gave the best atlas-brain log-intensity correlation **0.683** with no flips; the next best, ML-reflected, was **0.603**. [Orthogonal visual QC](I:/AnatomyTracker/reports/allen_stpt_individual_qc_310.png) likewise supports gross alignment but shows a strongly selective cortical reporter signal, not a general anatomical autofluorescence volume. Many voxels outside the annotation support are nonzero, so a nonzero-mask overlap is not an anatomical registration metric. This is a useful source lead, **not** a verified voxel-centre-to-CCF transform or measured physical-oblique label set.

**Decision:** do not bulk-ingest all 55 or start a model run from this source. The strongest apparent source-level diversity is in transgenic expression, not necessarily the anatomy/contrast needed for arbitrary histology. The [Allen Institute Terms of Use](https://alleninstitute.org/legal/terms-of-use) permit noncommercial research use with attribution but do not grant blanket commercial incorporation into a proprietary product; clarify deployment rights before making these volumes a deliverable dependency. The reproducible one-source check is `training/qc_allen_stpt_individual_310.py`. A more suitable multi-animal anatomical volume with authenticated CCF indexing, or a genuinely labeled physical oblique-section cohort, remains a higher-value data target. This result changes no 309 or GUI gate.
