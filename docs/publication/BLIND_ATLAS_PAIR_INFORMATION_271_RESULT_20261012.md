# 271: atlas information on blind proposals — audited diagnostic

The frozen 270 step-8,000 image-only model placed a ≤1.5-mm branch in its top 32 for 48/64 TRAIN-inner synthetic sections. Among these, 3,193 near-versus-≥2.5-mm branch pairs from all eight synthetic bases met the prespecified common-support controls. Each pair used the same observed pixels, its section's exact nine-node through-plane sampling, ≥64 eroded common-support cells, support IoU ≥0.45, and support-area difference ≤0.15. The 64 cases and 3,193 pair rows were counted independently after the assay exited; all pair thresholds and recorded win comparisons passed a separate row audit. The four output hashes match `completed.json`.

Equal-base mean near-branch preference was **70.18% for intact atlas intensity**, **50.96% for within-support shuffled atlas intensity**, and **74.86% for the image-only model's own prior**. Thus genuine atlas texture contains information beyond support shape (intact minus null +19.22 percentage points), but this fixed atlas score is 4.68 points *worse* than the current prior. The prespecified gate required intact to beat the prior by ≥10 points, so **the information gate fails**. Pair-weighted means (71.4% intact, 49.8% null, 69.0% prior) differ because case sizes are unequal; they are not the prespecified equal-base decision. All these comparisons use truth-labelled *analysis pairs*, not truth at inference or calibrated probabilities.

The sparse-tissue limitation persists: of 11 cases with <15% visible tissue, only three supplied eligible comparison pairs. In five eligible >45°-from-nearest-axis cases, intact score averaged 79.3% versus 50.0% for the prior, an exploratory subgroup too small to overturn the full-panel gate or support an arbitrary-oblique performance claim. No scalar/spatial reranker of this same kind should be trained on this result. The next useful work is improving proposal quality and realism, with a separately justified joint pose/deformation feedback design only when matched evidence supports it. This diagnostic does not promote any checkpoint, resolve the 270 capture failure, or establish physical-section generalization.
