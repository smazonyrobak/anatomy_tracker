# 060 fitted-ranker correction: predeclared development experiment

059 failed the frozen development gate despite improving the truth-scored synthetic candidate pool. A separate no-training diagnostic reproduced all 249 step-50,000 selected errors from the frozen evaluation. In the same eight-candidate beam, the truth-scored synthetic oracle is 1.416 mm but the fitted selector yields 2.853 mm. On weak-real DEV, the oracle is 0.560 mm and the selector yields 1.135 mm. Removing the image prior from the fitted score makes both sets worse (3.021 and 4.355 mm); the prior alone yields 2.962 and 0.712 mm. Thus neither unmodified component is a credible cross-domain selector. The new branch has lower truth-scored error than the best old candidate in 79/185 synthetic images but only 12/64 weak-real images; the fitted score chooses the correct old-versus-new side in 105/185 and 13/64 respectively. These are diagnostic DEV observations, not a calibrated selection rule.

Hypothesis: the inherited fitted matcher, trained on the 16-mode parent, has never learned to rank the new anchor candidates. Train **only** this existing fitted matcher on a mixed old/new eight-candidate beam; keep the 059 final image encoder, plane heads, pose refiner and tissue mapper bitwise frozen. In each batch draw two fresh, independent arbitrary-plane synthetic TRAIN slices and one distinct real TRAIN section, with the same donor-balanced TRAIN-only stream as 059. Synthetic candidate quality is visible-tissue 3D mapped error after the frozen atlas-conditioned fit; real candidate quality is disagreement with the weak Allen affine at five image points. The latter is a noisy proxy and gets a softer target distribution. The loss asks the fitted scores to rank all eight candidates by their physical error; the finite-thickness atlas rendering and learned local warp remain in the scoring path. No ground-truth plane or animal identity is supplied at inference.

Run 6,000 batches (12,000 fresh synthetic and 6,000 real TRAIN presentations), inspect frozen checkpoints 0/2,000/4,000/6,000 on the same unchanged identity-disjoint synthetic and donor-disjoint weak-real DEV panels. This is a small matched correction, not the final exposure scale. It advances only if selected synthetic mapped error is below the 019 reference of 2.591 mm **and** weak-real five-point disagreement is no worse than its approximately 0.595 mm reference, without a large donor-specific regression. Otherwise retain 019 and move to a new global image-to-volume correspondence formulation rather than more uninformative scorer training. No public benchmark, final-test animals, GUI promotion or numerical probability claims are allowed at this stage. Preserve all run sources, draws, IDs and hashes on I:.
