# 125: dense internal-anatomy supervision before blind fit feedback (predeclared)

## Question

124 learned a score from only 958 scalar support-matched pair labels and did not beat its support-only control. Test whether teaching *where each intact image patch belongs within a rendered atlas slab*, in addition to blind pair ranking, makes fitted internal anatomy discriminate physically correct arbitrary planes. This is a mechanistic development experiment, **not** GUI/model promotion. Keep the frozen 122 step-2000 pose, global matcher, mapper, 16-branch beam, source-image preprocessing, and nine-point 62.5-µm atlas PSF. Train newly randomized, identically initialized full-atlas-intensity and support-only rankers of the same parameter count on the same draws; neither arm inherits 124 weights. No prior external model weights, features or pseudolabels.

Use 10,000 independently drawn eligible v3 synthetic TRAIN sections from the same 64 TRAIN base deformations, one image/appearance per physical section. Do not deliberately duplicate a plane to change artifacts or background. Preserve every attempted seed, physical-section ID, base animal/specimen/experiment ID, model/source/data hashes, optimization trace, and step-0/final checkpoint. Each accepted section supplies dense correspondence labels from its known intact tissue-to-CCF map on valid 32×32 interior pixels. Perturb the **true mapped surface** by one independently sampled integer displacement of -2 to +2 grid cells in each image axis and -1 to +1 half-millimeter normal steps; the inverse offset is the 75-class target. The same perturbation and eligible pixels supervise both arms. Render this surface with the same fixed PSF and bounded local search used to score blind fitted maps. The synthetic true map and validity define TRAIN labels/mask only; neither can reach ranker inference inputs, pair masks or real evaluation. Use the 5×5-eroded valid interior and require the target atlas support to be present. Optimize dense correspondence cross-entropy plus the existing 124 support-matched blind pairwise loss with a fixed 1:1 coefficient where a pair is eligible. An accepted section with no eligible dense pixel contributes zero dense loss and is logged, not redrawn; similarly, an unscored blind pair contributes zero pair loss. Record separate dense and pair losses/counts for both arms. Keep architecture, coefficients, optimizer, budget and checkpoint-selection rule fixed before DEV evaluation; use the final 10,000-presentation checkpoint for the primary gate, not DEV-tuned selection.

Prepare a new 256-section geometry/appearance panel from the eight existing synthetic DEV deformation plans, with new independent draw seeds and section IDs disjoint from the earlier 256-section panel and all TRAIN physical-section IDs. Retain/report ineligible sections; do not choose planes from prior errors. These eight plans and Allen atlas have already informed this project, so the new panel tests fresh sections but **not** an unseen biological animal or untouched deformation family. Evaluate the final full/support rankers and frozen 122 on exactly the same blind beam, corrected maps, support-matched comparison pixels and fixed-PSF rendering. Report near-candidate availability, scored/abstained pairs, support Dice/area/common-pixel strata, pair ranking, selected mapped-tissue and rigid-gauge error, all eight per-plan values, and action/slot changes. Evaluate the same six coronal/eight sagittal weak-real DEV donors, reporting each donor. Include full-arm zero-atlas-intensity, atlas-intensity spatial-shuffle at fixed support, and different-source-image/features controls; the latter holds the candidate pose and fitted map fixed and therefore tests only incremental query dependence conditional on that map. Any claim of real transfer requires independent acquired-animal evidence later.

Stage-1 gate: at least 64 scored support-matched blind pairs; full correct-pair wins with a >=0.01 margin on >=75% of them, exceeding the separately trained support-only arm and **each** intensity-ablation/shuffle/source-swap control by >=10 percentage points. Plan-equal selected mapped error must improve by >=0.30 mm versus the identical frozen-122 baseline and >=0.15 mm versus support-only; selected rigid error must not regress versus 122; >=6/8 plans must not worsen in mapped error. Donor-equal weak-affine discrepancy must not worsen by >0.20 mm in either real orientation family and no donor by >0.50 mm. Report every failed condition without waiving thresholds. Do not use final animals, uncertainty calibration data, or a public benchmark.

Only if this blind evidence gate passes, run a separately predeclared matched 126 continuation that backpropagates/distills fitting evidence into direct probabilistic pose predictions and compares against same-draw no-feedback training. It must show improved **one-pass direct** pose/map accuracy without the ranker at inference, useful fit-to-pose gradient/parameter change, real-donor retention and fresh synthetic confirmation; candidate recall must also improve where no near plane is proposed. If 125 fails, stop this fit-feedback formulation rather than scaling the same score unchecked. The atlas self-rendering of synthetic tissue is a major transfer caveat: even synthetic success would not establish real histology localization, acquired arbitrary-oblique performance, calibrated electrode probabilities, GUI readiness or superiority over DeepSlice.
