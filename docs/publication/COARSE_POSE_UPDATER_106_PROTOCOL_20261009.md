# Coarse atlas-conditioned pose updater 106 — frozen protocol

The 104/105 local fitters did not improve tissue-to-atlas mapping, and their fit scores did not beat atlas-support selection. This intervention targets the upstream capture problem: a shared two-iteration updater re-renders the finite-thickness atlas correlation volume after each bounded, robust affine full-frame correction. Its predicted coarse-site displacement starts at zero, has a live direct coordinate gradient, and is limited per iteration to ±4 displayed coarse cells and ±6 mm along the plane normal. Each fitted edge correction is at most half that edge's current norm, and centre correction is at most 3 mm. Reflection is a raster-chart operation, never a physical rotation. The v3 one-pass pose proposer stays frozen. The updater inherits only this project's randomly initialized/trained 094 matcher and validity head; no original-application, external weights/features, or pseudolabels enter.

Draw 4,000 independent TRAIN sections from the v3 full-plane artifact generator, without deliberately reusing a physical section with a different background or artifact. From each frozen 14-hypothesis pose beam, train on four diverse blind candidates (physical best against the true rigid cutting plane in TRAIN, support-matched wrong, high-prior wrong, random remaining) plus one TRAIN-only true-plane candidate, exact on odd updates and mildly jittered on even updates. This fifth hypothesis is supervision for the same image, not another image presentation; it never enters blind DEV or inference. The true cutting plane is the global-pose target. The observed-pixel CCF field, including valid displaced fragments, is the separate local-map target. Both recurrent *post-update states* receive 16×16 physically measured CCF pose loss at valid sites; both direct site maps receive dense observed-to-CCF loss. The exact-pose teacher receives threefold site weight to discourage needless movement. Coarse 083 correspondence CE applies only where the true class is in range and supported. A separate matched/unmatched BCE supervises reliability on surviving sites, and validity uses mask BCE. Reliability is an uncalibrated match-ranking signal, not an electrode probability.

Train paired `atlas` and `support_only` arms from identical step-0 weights on exactly the same draws and candidate hypotheses, with separate optimizers. The control zeros only the atlas correlation logits; it retains rendered atlas support, image features, and the same architecture, so it is **not atlas-free**. Keep matcher weights frozen for updates 1–1,000; unfreeze its image/atlas descriptors and temperature for updates 1,001–4,000. The loss is 2.0 post-state pose Huber + 0.5 site-map Huber + 0.1 supported correspondence CE + 0.2 balanced reliability BCE + 0.1 validity BCE + 0.25 blind-candidate ranking + 0.02 normalized offset penalty. Huber errors are in millimetres, with the 16×16 valid-site mask; both recurrent iterations contribute equally. Rank only the four blind hypotheses by frozen pose prior plus twice the log of validity-weighted support×reliability coverage; pairwise ranking truth is the detached valid-site physical error **after** the second correction, not the input proposal error. Save both arms and separate optimizer/RNG state at updates 0, 1,000, 4,000. Freeze source, parent, protocol, draw, training, checkpoint, and completion hashes. Progress stdout every 250 updates; do not inspect the output tree during the live run.

On the reused 64-section v3 DEV panel (eight sections per deformation plan), evaluate all 14 blind hypotheses for each arm at the three saved steps, with the same prior-plus-coverage score. No true-pose teacher is selectable. Select a checkpoint by plan-equal physical 16×16 post-update error for the `atlas` arm, then report the paired `support_only` result at that same step. The preregistered advancement gate requires: `atlas` physically best-of-14 corrected error at least 0.50 mm below its own input error; `atlas` at least 0.20 mm better than `support_only` on the same physically best input candidates; selected-blind final-pose error at least 0.20 mm better than both the frozen pose-prior selector and the matched `support_only` selector; within-section score/error rank correlation at least 0.05 better than `support_only`; at least six of eight plans improve over input; and raw, imperfect-brush, and heavy-oblique (at least 30° from every principal axis) strata show no >0.20-mm regression. A positive reused-DEV result still requires a new frozen synthetic confirmation and animal-separated acquired truth before enabling fitting gradients into the pose proposer or replacing the GUI model. Proposals with zero atlas support cannot be recovered by this updater; neither arm supplies calibrated uncertainty, biological accuracy, or DeepSlice superiority.
