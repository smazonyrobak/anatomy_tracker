# V8 synthetic exterior sampling

V8 wraps the frozen v7 section generator. Each call draws one new physical plane, warp, artifacts and mode through v7, then independently draws one exterior style for that same example: 45% exact black, 30% near-black (nominal level 0.003–0.018), or 25% gray/confusing (0.03–0.35). It replaces only pixels with v7 visibility ≤0.05. V7-visible tissue pixels, brush outline and availability channels, valid mask, dense tissue-to-CCF coordinates, global state, plane normal, thickness, animal identity and section provenance are unchanged. There is no black/non-black pair of a physical section. The original v7 `mode` remains source provenance; `one_shot_slide_artifacts_v8` records the final exterior and brush availability.

The probabilities are deliberately broad **TRAIN-only sampling**, not estimates of laboratory artifact or background prevalence. The acquired [TRAIN appearance census](ACQUIRED_TRAIN_APPEARANCE_CENSUS_001_RESULT_20261008.md) found different full-canvas exact-zero fractions in coronal and sagittal cohorts (67.3% and 16.3%). A separate [512-donor TRAIN comparison](REAL_SYNTHETIC_APPEARANCE_GAP_20261009.md) found dark borders and no brush channel in every sampled acquired image, while earlier synthetic raw images often had substantial background. Whole-canvas zero fractions do not identify true exterior pixels or set event probabilities. A representative, consented slide sample from the deployment laboratory is still needed before acquisition-specific calibration.

V8 leaves tissue texture and geometric artifact prevalence unchanged. Acquired TRAIN visual QC shows finer tissue texture and more irregular edges than atlas-derived synthetic sections, but a texture perturbation without a measured tissue-only target could add misleading noise. Any later texture change should be separately versioned and assessed on fresh independent planes; no DEV/CAL/FINAL data or model result is claimed here.
