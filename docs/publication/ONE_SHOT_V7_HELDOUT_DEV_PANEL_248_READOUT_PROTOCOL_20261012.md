# 248: exploratory v7 held-out DEV readout

Run `python -m training.evaluate_one_shot_v7_heldout_dev_panel_248` from the I: repository only **after** `one_shot_v7_heldout_dev_panel_248_004/completed.json` exists. The evaluator checks the frozen 256-section manifest and file hashes before loading the batch-6000 checkpoint selected by the earlier 247 pilot. It never selects a checkpoint on this panel and never writes into the panel tree. Output is `I:/AnatomyTracker/runs/one_shot_v7_heldout_dev_panel_248_readout_001`.

This is a deliberately separate, exploratory diagnostic—not a replay of the failed 247 gate, a new promotion threshold, or an external benchmark. It evaluates every eligible independently drawn 192-pixel v7 section and retains the count of ineligible attempts. It uses the panel-bound, hash-verified [exact float32 Allen atlas cache](ALLEN_V6_FLOAT32_CACHE_248_PROTOCOL_20261012.md) to avoid repeating native NRRD preprocessing; no atlas values change. The same top-four normal anchors, both reflection options, one shared residual pose update, atlas-conditioned local map, and fitted scorer as 247 are used. An AP-shifted-intensity atlas null reruns mapping, pose update and scorer on the fixed source-prior beam; atlas support is unchanged. Exact target-plane mapping is compared with the zero-warp target plane at all observed valid pixels. Rigid pose, normal-axis, and map errors are summarized case-wise and equally across synthetic subjects, plus strata for **physical cut angle** and observed visible-support mass. The target affine-plane normal is not substituted for the physical cut angle.

All eight synthetic subject plans use the same Allen atlas and TRAIN-only acquisition framing; they are not eight independent biological animals. The synthetic inverse-map truth has a sampled accuracy certificate, not a global exact guarantee. The model is uncalibrated. This readout may diagnose simulator transfer or failure modes but cannot establish clinical/electrode-region probabilities, external generalization, or a DeepSlice advantage. No CAL, FINAL, or public benchmark data are used.
