# 115: eightfold virtual-oblique loss weight did not rescue pose

Run 115 was a matched continuation of frozen 111 step 1959, compared with the first 1,306 batches of 113. Its draw log matched the corresponding 113 prefix byte-for-byte (SHA-256 `1c4fc4dee01d4816f7e3ab9643ab82763468dda3d1ee9a70c3c1cfaa90d316f6`). It saw 2,612 accepted independent synthetic planes, 653 independently sampled virtual oblique TRAIN-donor planes and 653 distinct sagittal images. The random coronal stream incidentally selected two sections twice; there was no deliberate paired-background replay. Only the virtual pose-loss coefficient changed, from 0.25 to 2.0 on even batches. The 4,000-batch learning-rate denominator and all other losses were kept for the matched step-1,000 comparison. Training exited successfully and all frozen evaluation preflights and source hashes passed.

On the same 32 novel virtual cuts from eight TRAIN-subset held-out donors, the matched step-1,000 comparison was:

| Donor-equal pose discrepancy | 113, weight 0.25 | 115, weight 2.0 |
| --- | ---: | ---: |
| Prior-selected branch | 8.252 mm | 8.047 mm |
| Best of prior-filtered 14 | 5.425 mm | 5.221 mm |
| Oracle best of all 160 branches | 4.096 mm | 3.991 mm |

After 1,306 batches, 115 reached 7.925 mm selected, 5.267 mm best-of-14 and 3.976 mm best-of-160. The matched weight change yielded a small improvement, not an arbitrary-angle rescue. The full-160 oracle floor is itself near 4 mm, so reranking the present candidates cannot solve the primary error. At step 1,000, synthetic DEV selected discrepancy improved 3.542→3.415 mm, coronal weak DEV 1.162→1.046 mm, and sagittal weak DEV was essentially unchanged 2.066→2.071 mm. These are weak-reference and synthetic diagnostics, not biological accuracy claims. Do not promote 115 as a deployable checkpoint.

An evaluation-only paired source control rendered an atlas-derived **serial** stack at each donor's 140 weak-Allen-affine section planes, then used the same oblique pose, trilinear reslice, slab weights, contrast/background settings, artifact seed and final optional-brush mask as each donor virtual cut. All 32 paired controls were eligible. At the matched 115 step 1,000, donor-virtual versus atlas-serial selected error was 8.047 versus 7.762 mm; all-160 error was 3.991 versus 3.964 mm. This small source gap does **not** support acquired donor appearance alone as the dominant explanation. It does not clear the weak-label or serial-reslicing artifacts, because the control uses the same weak section affines and sparse serial sampling. The atlas-serial image is a simulation, not an acquired oblique slide.

The next discriminating check is a **direct atlas slab at these same frozen physical poses** (with the same appearance and v3 artifacts), compared with both serial-resliced sources. If direct slabs yield substantially better full-160 capture, sparse serial interpolation is a likely limiting factor; if not, the physical-plane distribution, framing, pose representation and/or training coverage need targeted revision. A single damaged or feature-poor cut can be intrinsically ambiguous, so arbitrary-plane support must ultimately retain multiple plausible poses and permit an unreliable/abstain result rather than promise a unique answer. Literature on serial reconstruction emphasizes that adjacent histology images need registration and that missing/damaged sections disturb 3D continuity ([Possum](https://pmc.ncbi.nlm.nih.gov/articles/PMC4896981/), [CODA](https://pmc.ncbi.nlm.nih.gov/articles/PMC10500590/)); this motivates the control, but does not determine its outcome.
