This is a positive mechanism result, not a usable one-shot predictor or proof that atlas fitting selects the right pose. The optimization starts from the **known** plane and uses an atlas intensity source that also generated the synthetic tissue; real stain, scanner, per-animal anatomy, severe detached fragments, and uncertain planes can behave differently. The fitted field is smooth and topology-constrained, so it cannot independently move arbitrary detached pieces. The current generator draws full-sphere orientations but renders one Allen average volume with 64 synthetic deformation bases; this is not biological all-angle evidence. The next priority is to test whether a **fixed, inference-valid fit difficulty** actually distinguishes good from bad *predicted* candidate planes on a fresh TRAIN-inner panel, while addressing the measured synthetic-to-acquired appearance gap. Only then should it feed a scratch-initialized joint pose/deformation model. Do not promote this diagnostic to the GUI, calibrate probabilities, or run the public DeepSlice benchmark from this result.
