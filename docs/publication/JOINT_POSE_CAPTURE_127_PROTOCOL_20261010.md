# 127: frozen full-160 versus blind-16 proposal capture

Before changing training, measure whether the frozen 122 model proposes a physically useful plane that its deployed 16-branch beam discards. Use the exact 256-section 125 synthetic DEV panel (241 eligible sections) and frozen 122 step-2000 checkpoint. No weights, candidate states, data, or existing results may change. This is reused synthetic development evidence from eight virtual deformation plans, not an independent animal test.

For each eligible image, predict all 80 modes and both reflections once. Measure every **original** branch's rigid-gauge and tissue-mapped error on all valid original pixels, in millimetres, against the panel's known synthetic affine gauge and coordinate field. The mapped error uses the same atlas-conditioned 96-pixel local mapper, finite-thickness nine-point 62.5-µm PSF, 256-pixel upsampling, and valid-pixel mean as the frozen 125 evaluator. Compare best original branch among the prior-ranked top 16, 32, 64, all 160, and the current top-eight-base/top-six-anchor/two-diverse-anchor blind beam. Also apply the frozen global matcher to that same blind beam and record its best **corrected** branch and its selected original-or-corrected action; corrected branches are not available to the prior top-k or all-160 original comparisons. Reproduce the 125 evaluator's frozen-beam best-corrected and selected metrics and branch IDs as a consistency check.

Primary diagnostic: mapped-tissue capture at <=1.5 mm, with best-error means and rigid-gauge analogues alongside. Report every original branch ID, prior score, mapped and rigid error, ranked prior order, beam IDs, and corrected-beam errors, preserving panel section, plan, appearance and angle provenance. Summarize all eligible sections, each appearance mode, four 15-degree nearest-cardinal-angle bins (last 45–55 degrees), and eight plans. These groups are unequal and descriptive, not randomized causal contrasts.

Decision rule: if all-160 original mapped capture exceeds blind-16 **original** capture by >=10 percentage points, beam pruning is a material proposal bottleneck; otherwise it is not the dominant explanation for absent near planes and direct proposal quality merits priority. Independently, the gap between blind-16 best-corrected and selected mapped error quantifies selection failure even when an eligible candidate exists. Do not feed synthetic truth into inference, select a checkpoint from this panel, promote the model, calibrate probabilities, run public benchmarks, or infer acquired-oblique accuracy from this diagnostic.
