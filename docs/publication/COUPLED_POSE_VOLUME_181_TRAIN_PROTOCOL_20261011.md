# 181 TRAIN-only coupled pose-volume capture and blind-selection gate

Freeze the scratch-lineage 132 step-2,000 pose model and its exact 8-base/6-anchor/2-diverse, 16-branch blind rule. This is a bounded inference-module assay, not a new trained network or a claim of physical-animal accuracy. Draw one independently seeded eligible full-sphere v3 section and one v4 section from each of the 64 TRAIN deformation bases; log every rejected draw and physical-section ID. Do not deliberately recolor a fixed plane. The parent has seen these TRAIN bases, so results select a mechanism only. No DEV, final animal, acquired weak-reference image, or public benchmark enters the assay.

For every frozen branch, retain its reflection and prior and make the Cartesian 3×3×3 product of local rotations about its two in-plane axes at −0.16/0/+0.16 rad and translation along its normal at −1000/0/+1000 µm. The central action is exactly the original branch. This **coupled** bank has 16×27 full-frame states; it does not insert the synthetic truth. Render all actions at a genuine 48-pixel grid with the section's nine-sample finite-thickness PSF, in small chunks. Within each parent branch, score all 27 actions by absolute Pearson correlation after fixed 3×3 smoothing on the 3×3-eroded **original-branch** atlas support. Require ≥64 cells and ≥90% original-mask atlas-support retention; subtract 0.5 times support loss from the score. For each branch retain the original and the top two 48-pixel actions from each of the intact and complete intensity-permuted arms. Re-render their **union** as an identical 96-pixel fine render set in both arms, but each arm may select only its **own** original-plus-top-two shortlist. This prevents either arm from borrowing a candidate found by the other. Use a 5×5-eroded original-branch mask and the same score/support rule to choose each arm's best fine action within each branch. No gradient fitting or learned scalar verifier is involved.

Compare the 16 branch winners on pairwise common 5×5-eroded atlas support, using the 180 rule: ≥64 shared cells, support IoU ≥0.45, support-area fraction gap ≤0.15, and both branches passing the fine support rule. Average each branch's signed absolute-Pearson margins over eligible pairs and add only `0.01 × (frozen branch prior − maximum frozen prior)` as a predeclared tie-breaker; the prior cannot supply a large anatomy margin. Exclude branches with fewer than two eligible comparisons; if none remains, return the original highest-prior branch. The control independently permutes each candidate's atlas intensity **within its own support** before smoothing, at both 48 and 96 pixels. It preserves the same source image, atlas supports, 16×27 candidate states, fine render union, beam prior, and selection algorithm. Neither arm sees true pose, valid-tissue mask, physical error, branch ID in its image score, or atlas coordinates as an image feature.

Only after the blind actions are fixed, evaluate rigid displacement at 128 evenly raster-spaced observed-valid tissue pixels, as in 171, plus the five frame points. Record truth-best capture in the original 16, all 432 actions, the shared fine render union, and the intact arm's own fine shortlist; the truth-best is an **availability oracle**, never a selector. Report direct-prior, intact-selected, and null-selected mean tissue-site error and ≤1.5-mm capture; intact-minus-null, mean support retention, pairwise comparison coverage, and paired intact+null GPU inference p95 per section. Aggregate separately for v3/v4; show sparse-tissue and ≥30° nearest-cardinal strata descriptively. Record all candidate indices needed to reproduce each selection, source/parent/protocol hashes, and input provenance. All outputs, temporary files and caches stay on `I:`.

The prespecified continuation gate requires, **in each appearance**, 64 eligible independent sections; intact-shortlist truth-best ≤0.5-mm capture at least 10 percentage points above the original 16; intact blind-selected mean tissue-site error at least 0.25 mm below direct prior; intact ≤1.5-mm capture at least 10 points above direct; intact mean at least 0.10 mm below the complete intensity-null selector; intact mean five-point error no worse than direct; ≥90% sections with a supported pairwise selection; and ≥99% mean selected-action original-mask support retention. The paired intact+null p95 from parent prediction through selection must be ≤18 seconds per section, a conservative ten-slice 180-second ceiling. Failure of any condition stops this module before DEV, pose-head feedback, nonrigid-map continuation, calibration, or GUI use. A pass licenses only a later matched joint-training experiment; it does not establish an animal-level posterior or real oblique performance.
