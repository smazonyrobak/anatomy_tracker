# 248: independent v7 synthetic DEV panel

After the active 247 training run has finished, run `python -m training.prepare_one_shot_v7_heldout_dev_panel_248` from the repository root on I:. This CPU-only preparation does not load a model or choose a checkpoint. Do not use the panel for training, calibration, or a FINAL/public claim.

The script freezes eight new development-only accepted 3D deformation plans (seed `2026101249`, indices `2000–2007`) and checks plan IDs, realization IDs, receipts, and local-field hashes against the 64 TRAIN bases, four earlier v6 DEV bases, and eight earlier eight-subject DEV cohorts. It bakes each new plan's inverse on CPU with the v7 TRAIN interpolation and sampled `≤5 µm` accuracy rule. These are eight independent synthetic deformation realizations of the same pinned Allen atlas, **not** eight biological animals. Sixty-four affine variants per base follow the v7 size/aspect distribution but are not counted as independent anatomy.

For each base, 32 separately seeded planes are drawn at 192 px by the unchanged v7 geometry/appearance-v3 and one-shot artifact-v3/v4/v6/v7 sampler. One affine variant and one appearance/background/mode are drawn per plane; there are no paired appearances, tissue-based retries, or replacements. All 256 attempted planes are retained, including ineligible ones. The fixed source-support and observed-valid thresholds are each `192²/144`; the eligible count is a result, not a target of 185. The sampler's hard-coded `split=train` provenance label is changed to `development` only after sampling from DEV-only bases.

The output is `I:/AnatomyTracker/data/one_shot_v7_heldout_dev_panel_248_001`. `protocol.json` binds input manifests, TRAIN-only acquisition-framing geometry, pinned atlas, code hashes, seeds, and package versions. Each subject has its accepted plan, receipt, baked map, and mapping checks; each section NPZ has five-channel input, pose, dense observed-pixel CCF coordinates, valid mask, visible support, source support mass, reflection, PSF offsets/weights, and eligibility. `records.jsonl` holds physical-section, subject, variant, geometry, artifact, seed, and file hashes. Only `completed.json` marks a fully frozen panel. The 247 evaluator is not changed and its 256-px assumptions do not apply to this 192-px panel; a later evaluator must bind this manifest and keep checkpoint selection/reporting separate.

The only acquired-data dependency is the existing TRAIN acquisition-framing geometry used by v7; there are no CAL/FINAL donors or public benchmark sections. The map truth remains FP32 interpolated inverse coordinates with a sampled, not global, error certificate. This is a matched-simulator DEV diagnostic, not an independent biological or external validation set.
