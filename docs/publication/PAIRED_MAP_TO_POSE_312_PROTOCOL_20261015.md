# 312: short matched pose-feedback decision

The frozen 309 checkpoint is the common starting point. The 309 continuation updated only pose and shared image features; a previous local-map trainer replaced the predicted plane with ground truth before map loss. This comparison changes **only the training gradient path from local map quality to the predicted plane and its probability**. It does not introduce a new architecture, pretrained information, an inference-time search loop, or a public benchmark.

Two arms receive identical independently drawn v10 brain-intersecting planes, synthetic deformation/artifacts, and a uniformly selected source from the pinned atlas average plus three donor-distinct TRAIN red-background volumes. Each arm has the same one-pass model, optimizer groups, pose supervision and local-map objective. For each synthetic section, the mapped branches are the current first-choice branch and the geometrically closest model branch. Neither branch is replaced by the true plane. The local-map objective combines surviving-site coordinate error with a nonrigid displacement/smoothness cost and correspondence mask supervision. In the control arm, predicted state and branch probability are detached *only for this local-map objective*; map features and weights still train. In the feedback arm, map error and deformation cost can update both state and branch probability. Direct pose supervision is unchanged in both.

Start with 256 four-section optimizer batches per arm. This is an information-path preflight, **not** a final training budget. Read the fixed 309 v10 TRAIN-inner 256-cut panel at step 0 and 256 using blind first choice, >5-mm tail, top-16 ≤1.5-mm capture, and first-choice mapped-site error on a fixed 64-cut subset. Verify identical draw identities between arms and finite gradients. Afterward, audit separate donor-held-out red-source virtual cuts and acquired-animal guards before deciding whether to extend. Do not use calibration/final animals or DeepSlice here.

Only extend the feedback arm if it improves first-choice and mapped-site errors against the matched control without worsening the harmful tail or top-16 capture, and if the independent donor/acquired guards do not regress. Training loss alone is not a success criterion. A neutral or negative result sends the work back to data/label/identifiability diagnosis, not a longer version of the same run. The donor red volumes are approximate atlas registrations, so these checks do not validate physically cut oblique histology or exact biological warps. No uncertainty probability or deployment claim follows from this preflight.
