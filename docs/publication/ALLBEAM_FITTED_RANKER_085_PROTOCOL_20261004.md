# 085: train the fitted selector on the actual 14-branch beam

083 learned local image-to-atlas correspondence on held-out synthetic sections, but the frozen 084 diagnostic showed that an untrained aggregation of match confidence **worsens** whole-plane selection (3.065 mm rigid error versus the parent prior's 2.656 mm). The next narrow question is whether the *actual fitted atlas map* contains enough information for a trainable selector to recognize the right existing branch. Do not spend a long joint pose/deformation run before answering it.

Initialize one model from internally scratch-trained parent 059 and 083 step-6,000 match embeddings. Keep pose, local mapper, and embeddings fixed during this pilot; train only the 083 spatial summary/quality path and the parent's fitted candidate scorer. Each batch uses one fresh independently randomized arbitrary-plane synthetic TRAIN section, exactly one sampled background/brush mode, and the blind top-eight old/top-six anchor candidates. Process **all 14 existing branches** in chunks of two. For each branch, use the same two-pass 083 head, finite-thickness map and atlas-rendered fitted score that inference will use. There is no inserted true pose. The head's pose correction and spatial mapper injection remain zero/frozen in this selector-isolation stage.

At the same surviving synthetic tissue pixels for every branch, measure the predicted map's exact 3-D CCF error at the 96-grid output. Let `E` be that error in mm plus `0.03 × mean(local displacement in mm squared)`. Train the total candidate logit (prior + fitted scorer + 083 quality − inherited warp penalty) toward `−E` with pointwise smooth-L1 loss, averaged over all 14 branches. This is an uncalibrated ranking energy, **not** a posterior probability. All-branch pointwise supervision avoids 081's three-way softmax mismatch and lets each branch be compared at inference without an oracle insert. Use 1,000 accepted synthetic presentations, checkpoint at 0/500/1,000, log every 100 batches, and preserve attempted/rejected draw records and exact source/checkpoint hashes on `I:`. No weak Allen affine is used as anatomical pose truth.

After the runner exits, an independent verifier will compare all 14 candidate scores and maps on the frozen 061 eight-plan synthetic DEV panel, including selected mapped error at full 256 resolution, truth-best mapped96 error, selected-minus-best gap, background strata, and the matched parent059/081 baselines. Report six-donor acquired DEV disagreement with weak Allen affines as a transfer diagnostic only; it cannot establish correct anatomy. The necessary gate for expensive joint pose/warp fine-tuning is at least a 0.25 mm plan-equal reduction in selected synthetic mapped256 error against parent059's matched 2.535 mm, without increasing truth-best14 mapped96 by >10% from its matched 0.986 mm. If this fails, inspect score calibration/features and candidate confusion rather than simply train pose and warp longer. If it passes, unfreeze pose and local deformation with fitting-loss gradients and retain best DEV checkpoint before any new animal-level qualification.
