# Frozen TRAIN-only slide-artifact stress, before any v2 training

This is a diagnostic of the inherited batch-653 model, not a validation or a release gate. Freeze the checkpoint and sample 64 independently randomized, eligible physical planes with the new v2 artifact generator (seed `2026100901`, 256-pixel input). Each draw gets a new plane, virtual subject, appearance and artifact parameters; no paired clean/damaged copy is made. Use only the TRAIN atlas/virtual subjects. Reject only the generator's pre-existing eligibility failures and record every attempt. No weights, architecture, data split or cutoff may be changed during the readout.

Compare the image-prior top branch with the inherited fitted selector over exactly the same eight top-prior branches. Report 96-grid valid-tissue mapped-CCF error and antipodal plane-normal error, the truth-best of the same eight direct branches, and candidate-choice changes. Stratify descriptively by exact-black/raw/brush input, nearest AP/DV/ML normal, heavy obliquity (`max(abs(normal)) <= 0.85`), visible-tissue support quartile, and artifact event. Recompute all means from the raw rows and verify output hashes before interpreting. The existing 64-case v1 TRAIN assay is an independent, unpaired reference, not a causal artifact effect estimate.

The v2 rates intentionally stress damage and are not acquired-slide prevalence estimates. Real Allen affines are weak cardinal references, and this synthetic test cannot establish physical steep-oblique performance or prove that unrestricted-angle localization is impossible. Sealed animal holdout, public benchmark, GUI path and calibration remain untouched.
