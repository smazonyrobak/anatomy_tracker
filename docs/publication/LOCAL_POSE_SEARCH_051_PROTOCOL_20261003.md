# 051: does truth-blind local expansion reach the 050 evidence basin?

Freeze 019 batch 18,000 and 050 batch 3,000. For each of the actual top-eight 019 branches, generate the same fixed, truth-blind local full-frame moves: translations ±0.5/1.0 mm along each local axis, rotations ±0.12/0.24 rad about each local axis, log-size ±0.05 along each in-plane axis, and shear ±0.05. Keep the original branch too; no synthetic truth, tissue mask, injected true plane, or real reference affine may enter proposal generation or scoring. Score all finite-thickness rendered planes with 050 in chunks. The selected score is 019 branch prior + 050 evidence minus 0.25 times the squared normalized move size; this penalty is fixed before evaluation. This is a diagnostic search, not calibrated inference.

On the frozen 177-section/eight-identity synthetic DEV panel, report the physically best expanded branch (oracle ceiling) and the truth-blind selected rigid tissue error, equal-weighted by synthetic identity. On 64 weak-reference real DEV sections/six donors, report donor-level five-point changes. The necessary gate is an expanded oracle ≤0.6 mm and ≥0.3 mm better than original best eight, selected ≤2.0 mm and ≥0.4 mm better than the original prior, with no weak-real donor regression >0.2 mm. If only the oracle improves, the 050 score is still not usable from imperfect starts. If neither improves, fixed local steps cannot address the proposal-capture gap; favor a new global pose representation over more search around 019.
