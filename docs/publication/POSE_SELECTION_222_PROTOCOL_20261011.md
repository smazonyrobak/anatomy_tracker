# 222: bounded TRAIN-only pose-selection ablation

Question: the 221 framed inner-64 readout has median first-choice tissue error 3.450 mm but best-of-160 1.474 mm. Is a direct ranking signal, without changing candidate architecture or data, enough to close part of that gap? The true affine cutting plane, not the nonlinear displaced-fragment coordinate field, supplies training costs. This is an inner-development experiment, not a benchmark or a model promotion.

Both arms start from the same 221 framed step-400 checkpoint (`572d3719e1d62ce36e43bb34e9853c0579c5b88a09c4cd3ee4f073d51628ec2d`) with a fresh AdamW state. The control retains the 187/221 loss exactly; the intervention adds only the selection term below. Both use 400 updates, batch size five, pose/anchor learning rate 2e-5, shared encoder/lateral learning rate 5e-6, weight decay 1e-4, cosine decay to 20%, and checkpoint steps 0/200/400. No other model parameters are trainable. Distinct random streams (`202610112230` control, `202610112231` intervention) draw independently; they do not deliberately repeat a physical synthetic section with another crop or artifact, and no chance collision is rejected.

Each update draws one fresh 166→217→v4 TRAIN section, one fresh 166→217→v3 TRAIN section, one legacy-v7→v4 TRAIN section, one Lupori TRAIN fluorescence section, and one alternating older TRAIN coronal/sagittal weak-reference section at weight 0.3. AL1A is excluded from gradients and remains an inner animal guard. All sources, caches, runs, and documentation stay on I:. The model lineage is project-random-initialized with no external trained weights/features/pseudolabels. No DEV/CAL/FINAL cases or public benchmark are used.

For each of the three synthetic slices, let `c_k` be the existing detached 160-candidate physical pose cost in mm (0.75 tissue + 0.25 five-point + antipodal normal penalty), and `l_k` its existing log probability including reflection. Define the near-best set `G = {k: c_k ≤ min(c) + 0.5 mm}`. The intervention adds

`0.5 × mean_slices max(0, 0.5 + max_{k∉G}(l_k) − max_{k∈G}(l_k))`.

The 0.5 inside the hinge is a natural-log probability margin; the outer 0.5 is the loss weight. Only `l_k` receives gradient from this new term: the near-best set is detached, and existing pose losses still teach candidate geometry. This selects any near-equivalent correct mode, including either reflection, instead of forcing one arbitrarily named mode. The control computes a zero selection term. Lupori and weak old-real losses are unchanged.

Before inspecting 222 outcomes, compare both arms at 0/200/400 on the same frozen 221 framed 64-case TRAIN-inner panel, its unframed/legacy retention panels, and the AL1A TRAIN-inner guard. The primary paired gate is a ≥0.3 mm reduction in median framed top-1 tissue-site error versus control at step 400, accompanied by a decrease in top-1 exact-affine error. Require no >0.1 mm worsening in median best-of-160 affine or dense error, no loss of top-16 <2-mm capture, no >0.2 mm AL1A median regression, and no >10% legacy-synthetic median regression. Report base/anchor first-choice counts and probability mass; a top-1 gain caused only by moving mass while candidate coverage collapses does not pass.
