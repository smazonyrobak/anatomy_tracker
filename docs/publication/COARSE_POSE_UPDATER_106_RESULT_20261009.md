# Coarse pose updater 106 — frozen result (2026-10-09)

**Decision: fail; do not advance this updater into joint fitting or GUI inference.** The predeclared seven-condition gate passed only raw/brush/steep nonregression. This is a synthetic development result, not biological validation or calibrated uncertainty.

The paired experiment trained for 4,000 updates on 4,000 independently drawn, arbitrary-plane synthetic sections. It compared a two-iteration full-frame updater using image–atlas correlation with the same architecture and draws when those correlation logits were zeroed. The `support_only` control still used atlas silhouette/support, so the comparison isolates correlation information, not all atlas information. The v3 global proposer was frozen. The matcher/validity parent came only from this randomly initialized project lineage. Evaluation used 64 previously reused synthetic DEV sections, eight per deformation plan, with 14 blind candidate planes per section. Checkpoint selection used the atlas arm's plan-equal physical pose error; step 4,000 was selected.

The blind score stayed on the original prior slot for 61/64 sections and selected the physically best final slot in only 6/64. Mean within-section score/error Spearman correlation was 0.022 for atlas and 0.012 for support-only (paired gain 0.010, required 0.050). Only three of eight plans improved in best-of-14 error. Raw, imperfect-brush and ≥30° oblique strata did not regress by >0.20 mm, but the brush stratum has only three sections. The exact true-pose diagnostic was moved away from truth by 0.161 mm (control: 0.146 mm). Training losses fell, but that did not translate into useful atlas-specific correction.

The operational failure is not explained by a scoring arithmetic error: an independent read-only audit checked the frozen receipts, source/config/checkpoint hashes, all 64 panel-section hashes, row counts, units, plan aggregation, and gate calculation. The atlas updater moved candidate centres by about 0.267 mm on average, while candidate errors are measured in millimetres; its gain on the physically best input was only about 0.009 mm. The correlation head therefore did not supply the directional, candidate-specific evidence needed for capture. Reliability/coverage alone had a weak ranking signal (mean Spearman 0.079 versus 0.068 for support-only), but the fixed prior-plus-coverage score reduced it to 0.022; mere score reweighting is not an adequate explanation for the ~1.8 mm gap between blind selection and the best available candidate.

The [actual-generator four-case grid](I:/AnatomyTracker/reports/coarse_pose_updater_106_examples_001/actual_generator_atlas_and_106_predictions.png) shows the true atlas plane, the generated observed slice, the direct proposer's plane and 106's blind-selected plane. Cases were selected by appearance/orientation and valid fraction, not by model error. It illustrates both wrong-plane predictions on informative sections and a ≥40° raw section with only ~1% surviving tissue, where a single image may be intrinsically ambiguous. This is evidence against claiming universal confident recovery, not evidence for restricting the model to near-coronal cuts.

Next, test whether the image and atlas descriptors can distinguish the correct plane from wrong planes **when the correct plane is supplied only as a diagnostic candidate**, before adding another recurrent correction or deformation feedback. A matched correct-versus-wrong candidate experiment should compare correlation against support-only and use physical pose labels solely for measurement. If it fails, improve the acquired/synthetic appearance bridge and image–atlas representation within this standalone random-init lineage; if it succeeds, fix the proposal/score/update use of that evidence. Then train the fitter at genuinely correct and predicted planes, and verify that fitting loss changes the global pose predictor. No fitting-to-coordinate learning has been demonstrated yet.
