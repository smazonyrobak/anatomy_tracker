# 055: optimize the actual atlas-search objective without a collapsing atlas tower

054's isolated four-positive/16-negative loss converged to its equal-score chance value and degraded rigid-plane local recall from 75% to 44%. The atlas tower and its 2,061,824-key bank should therefore remain **frozen** while the observed-image encoder learns to retrieve among all bank keys, not just a small mined subset. This is a targeted response to the measured collapse, not a new generic ranker.

Continue only the image stem/shared query weights from the randomly initialized, scratch-trained 025 checkpoint. Keep 030's atlas descriptor bank fixed. For each of 1,500 newly and independently sampled arbitrary-plane TRAIN sections, select 16 surviving observed-tissue patches and use their training-only CCF coordinates to identify atlas-bank keys at the four nearest positions (within 0.5 mm when available) and four closest physical frames. Canonicalize image parity with the known training pose; inference will search both parities. Optimize the exact log-sum-exp denominator over **every bank key**, using the nearby keys as multiple positives. A frozen 025 query teacher supplies a weak preservation term so the model cannot improve the surrogate by erasing its prior cross-modal representation. Save at batches 0, 500 and 1,500.

Evaluate each checkpoint against the unchanged 185-section, eight-identity synthetic DEV panel and the untouched 030 bank, using the same two-parity, GT-valid query diagnostic. The necessary progress gate is identity-equal global top-16 point recall within 0.5 mm ≥25% (030: 15.42%), top-one ≥3% (030: 1.86%), and no raw/black/imperfect-brush stratum below half the aggregate. If this small pilot fails, do not scale it or claim deployment; inspect whether bank geometry and local anatomical ambiguity fundamentally limit this representation. If it passes, next replace GT-valid query selection with image-derived tissue sampling and test truth-blind plane fitting before joining the pose/warp model. This is not final biological validation, calibration, or a DeepSlice benchmark.
