# 287: matched map-feature learning pilot (frozen before training)

## Question

Verified [286](POSE_GAUGE_MAP_286_RESULT_20261012.md) showed that a post-artifact pose label cuts the exact-state no-warp error, but the frozen-275-feature mapper gained only 0.001525 mm. Does allowing the image features to learn from coordinate supervision produce a useful local map on *new* arbitrary-plane synthetic sections? Does comparing against a rendered atlas plane add useful information beyond a direct image-to-map branch? The current atlas-conditioned head's tiny advantage over zero-atlas controls in 282 is not evidence of usefulness because all heads failed to learn.

## Fixed comparison

- Replay the **same exact 3,000 distinct TRAIN sections** and post-artifact gauge labels from verified 286, preserving their order, input bytes, CCF targets, physical IDs and optional-brush/background/artifact draw. This is an ablation reusing identical images, not second augmented copies. Freeze the 286 schedule and checkpoint hashes as parents. No DEV/CAL/FINAL animals or public benchmark.
- A frozen-feature atlas-conditioned control is the 286 post-artifact step-3,000 checkpoint. Two newly trained arms start from the same scratch-lineage 275 pose encoder and the same **286 step-zero map weights**: (A) trainable source encoder/lateral features with the existing finite-thickness atlas comparison; (B) trainable source encoder/lateral features with the direct image/pose-to-map path and **no** atlas comparison. The pose head stays frozen. All common weights must match at initialization; loading the exact step-zero tensors also removes any constructor-RNG difference between branches. Both new arms see the same 512 valid sites/section, AdamW map learning rate 1e-4, source learning rate 2e-5, weight decay 1e-4, clip 2, and exactly 3,000 optimizer batches of one unique section.
- Generate a **new** fixed 64-section TRAIN-inner panel (eight independent sections per held-gradient base 56–63) before training, disjoint by physical ID from the replayed training schedule and 286 panel. Use identical images/512 sites for all arms. Read the two new arms at steps 0, 750, 1,500 and 3,000. Evaluate the frozen control on this same new panel. Keep feature side 64 and 16×16 smooth field with physical derivative cap 0.35; this isolates feature learning and atlas-conditioning rather than changing spatial resolution or warp capacity.
- Measure exact-state same-grid no-warp and mapped 3-D CCF site error, incremental map gain, learned shift, derivative, per-base gains, support/artifact strata, and pose first-choice site error from the **unchanged** pose head before/after source adaptation. The true synthetic pose/reflection still overrides pose for map training, so this is not deployable blind inference or measured pose–warp feedback.

## Advance rule

At fixed step 3,000, advance either trainable branch only if its map gain is at least 0.020 mm, exceeds the frozen-feature control on this same new panel by at least 0.010 mm, has nonnegative mean gain on at least six of eight bases, obeys derivative ≤0.35001, and its unwarped pose first-choice error does not regress by more than 0.20 mm from the common step-zero source. A ≥0.005-mm matched gain difference between the two trained branches is needed to prefer atlas-conditioned over direct (or vice versa); smaller differences leave that choice unresolved. Failure does not prove the image lacks information: it directs a subsequent change to higher-resolution/local correspondence and broader image sources rather than simply repeating a frozen-feature schedule. No checkpoint is qualified for the GUI or probability claims from this pilot.

Save source/config/parent/input/target/checkpoint hashes, exact section IDs, attempted and accepted counts, row-level readouts and the gate decision under an I: run directory. Commit and push the runner before launch. Audit the frozen receipt and outputs after exit; preserve negative results.
