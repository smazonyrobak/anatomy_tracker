# Candidate-conditioned anatomical correspondence 021 — frozen protocol

019 and 020 isolate the current bottleneck. On the same 185 synthetic development sections, the fitted selector chose a 2.622 mm mean tissue mapping although the best of its eight proposed planes reached 1.152 mm; 020 retrained only the pooled scalar scorer and made selection worse. This is a ranking failure, not evidence that more scalar-head batches will help. The 013–015 absolute-coordinate head and 018 correct-plane-only feature contrastive objective also failed their gates.

The 021 change is deliberately narrower: retain the randomly initialized 019 batch-18,000 one-shot plane/warp model, but add *spatial correspondence evidence for each of its actual top-eight fitted planes*. Shared image and rendered-atlas descriptors are compared within a two-pixel neighbourhood at 96-pixel resolution. A pixelwise match field is pooled using the parent model's predicted tissue reliability to change candidate ranking. The parent scalar score remains the exactly matched batch-zero control. The parent global pose, local warp, atlas features and refinement weights are frozen in this isolated test. If useful, this head becomes part of the jointly fine-tuned single model; isolated-head success by itself is not a shippable model.

Train for 2,000 batches of two independently drawn arbitrary-plane synthetic sections (4,000 accepted presentations) with randomly sampled backgrounds, cuts, deformations and artifacts. Do not deliberately reuse a plane with changed artifacts. The training-only exact observed-plane branch anchors descriptor learning; it is never available at inference. Actual parent top-eight candidates provide same-section hard negatives, with a pixel treated as a negative only if its known synthetic CCF mapping is more than 700 µm wrong. Optimize dense match classification, hard-negative descriptor separation, listwise candidate ranking and expected tissue-coordinate error. No real DEV/CAL/TEST specimen, pretrained external feature, previous proprietary model, pseudo-label, public benchmark or calibration data is used in training.

Freeze checkpoints at batches 0, 500, 1,000, 1,500 and 2,000. After the run exits, evaluate every checkpoint on the unchanged 185-case synthetic DEV panel, identity-equal over eight synthetic deformation identities, and the 64-case real DEV set from six donors using inherited Allen affine five-point *weak* labels. Compare the exact same candidates against the unchanged 019 scalar score; retain only a checkpoint that improves selected synthetic tissue mapping by at least 0.25 mm without worsening real weak-label donor-mean error by more than 0.20 mm. Check low-tissue-support cases and casewise score/error association as diagnostics, not post hoc selection criteria. Keep final-test animals untouched. This is an early architecture gate, not a full benchmark or a probability-calibration study.

The concept follows dense cross-modal registration features in [CoMIR](https://proceedings.neurips.cc/paper_files/paper/2020/file/d6428eecbe0f7dff83fc607c5044b2b9-Paper.pdf) and hard-negative local descriptors in [HardNet](https://proceedings.neurips.cc/paper_files/paper/2017/file/831caa1b600f852b7844499430ecac17-Paper.pdf). Neither paper establishes that this implementation will work for arbitrary mouse histology; the unchanged development panel decides whether to continue.
