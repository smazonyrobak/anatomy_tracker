# 066: feasibility of atlas-driven in-plane search

The 065 trainable pose-specific encoder failed to improve selected or best-of-14 full-plane error. Before implementing a more expensive atlas-image search, isolate one geometric question on the frozen 059 top-eight-old/top-six-anchor beam: if the **plane normal of each proposed branch is held fixed**, how accurately could a truth-informed in-plane affine fit place the observed tissue? This is an unavailable-at-inference oracle and does not score atlas image matching.

For each of the 246 eligible sections from eight synthetic identities in the already reused 061 exploratory panel, take all visible-pixel 3D CCF targets. Recompute the same 14 prior-selected candidate normals as the 063/065 audits. For each normal, fit the image centre and two in-plane basis vectors by ordinary least squares with both basis vectors constrained perpendicular to that normal; allow translation, roll, scale and shear, making the oracle more permissive than a rigid 2D search. Also report the rigorous mean absolute displacement along each normal, which no in-plane transform can remove. Compare the truth-best candidate before fitting with the truth-best normal-fixed affine fit, identity-equal and by appearance/tissue visibility. Hash the frozen checkpoint, panel, source and results. Do not display images, train a network, use real weak labels as truth, touch final animals or public benchmark.

If the truth-best constrained fit is ≤0.75 mm identity-equal, an in-plane atlas-image search has enough geometric headroom to test. If it is worse, do not interpret a failed 2D search as an image-similarity failure; first improve or refine normal/offset proposals. Even a good oracle result does **not** establish that a blind image score can find that transform. The separate subsequent search would need its own selected-error, appearance and donor guardrails.
