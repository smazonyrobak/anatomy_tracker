# Fixed-map anatomy energy 133: predeclared DEV assay

This is an exploratory, read-only selection assay, not training, calibration, validation on real animals, or a release gate. Freeze the 132 step-2000 checkpoint and the 256-section fresh-v4-132 synthetic DEV panel (248 eligible, 8 ineligible; eight held-out synthetic deformation plans). The checkpoint failed the separate weak-real coronal guard, so a positive result here cannot promote it. No public/final benchmark or GUI inference is touched.

For each eligible image, compute the exact 132 direct-pose blind 16: eight base, six anchor, two antipodal-normal-diverse unused anchors. With the same input and atlas as trained, run `model.map` independently for each branch in chunks at 96 × 96, with the section's own frozen PSF offsets and weights and `source_shape=(256,256)`. The mapped coordinates and local deformation are then **fixed for every scoring arm**. Downsample the returned 3D coordinates to 64 × 64, integrate the pinned Allen atlas over the same PSF, and pass rendered intensity/support through the checkpoint's `atlas_encoder`. The known synthetic PSF is shared by every arm but is more information than an unconstrained real inference would have. This does not run 75-shift/pixelwise candidate matching and does not use branch coordinates, xy, or CCF position as direct scoring inputs.

At each 64-grid location compare the channel-normalized `prediction['feature']` vector and atlas descriptor by `(1 - cosine)/2`, without assuming that these two frozen streams form a validated aligned metric. One branch-independent reliability image is `0.2 + 0.8 clamp(local_5x5_std(area_resampled_input_channel_0)/0.12,0,1)`. It is reused unchanged for every candidate/control. Appearance is the reliability-weighted **support × mismatch** divided by the reliability sum; coverage is reliability-weighted **(1 − support)** divided by that same sum. Unsupported pixels are penalized, never silently removed from the denominator. Add `0.25 × mean |local displacement| in mm` and `0.25 × mean dimensionless nearest-neighbour local-displacement gradient / physical pixel step`, with the same image-derived reliability weights for all branches. The fixed-map energy is the sum of these four nonnegative terms. Primary selection is `direct log-prior − 3 × energy`; the coefficient and all energy weights are frozen here, not tuned to DEV labels.

Controls use the identical beam, prior, coordinates, atlas support, deformation and source reliability: (1) original direct log-prior alone; (2) atlas intensity set to zero before atlas encoding; (3) atlas intensity deterministically permuted **only within each branch's supported pixels** before atlas encoding; (4) source feature locations permuted once per image, identically across candidates. The latter three retain the same energy and selection formula and alter only the anatomical correspondence channel being probed. No synthetic target/valid mask may enter scoring, mapping, source reliability, or control construction.

Only after all scores are frozen, evaluate each branch against the synthetic target: mean 3D mapped-surface error on observed valid tissue, and the exact 132 mean rigid-gauge error on those pixels. Report every eligible section and preserve explicit unscored records for the eight ineligible sections. Report section-equal and synthetic-plan-equal selected mapped/rigid mean, mapped ≤1.5 mm fraction, best-in-beam bound, changed-choice counts and per-plan results for each arm. For a conditional anatomy test, choose the lowest-mapped-error near branch (≤1.5 mm) and the lowest-error wrong branch >1 mm worse whose **fitted** atlas supports have Dice ≥0.85, area-fraction gap ≤0.08, and ≥32 common supported pixels at 64 × 64. Report candidate counts, score margins and paired win rates, including when no pair exists. These labels are used only to form the post-scoring assessment pair.

The predeclared *signal gate* requires the full arm to improve synthetic-plan-equal selected mapped and rigid error by ≥0.15 mm, and mapped ≤1.5 mm selection by ≥0.05, **against both** direct prior and zero-intensity control; at least 64 conditional support-matched pairs must be available, with full pair win rate ≥0.60 and ≥0.10 above zero-intensity. Report all metrics even if this gate fails. Passing only justifies a subsequent matched training-feedback experiment, not claims of real-animal accuracy, calibrated probability, or deployment. A null full-versus-zero result means this descriptor energy has not shown usable atlas-anatomy information.
