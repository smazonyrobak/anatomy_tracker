# 212: predeclared native-anatomy pilot, not a promotion run

**Question.** Does independent TRAIN specimen anatomy with authored native-to-CCF surfaces improve the same one-shot joint model's pose and local mapping beyond matched additional atlas-derived synthetic views? The failure of the 206 MIND fit gradient is a negative result, not a reason to reuse that loss. This pilot uses direct weak coordinate supervision, keeps the final architecture, and does not yet train a learned atlas-fit feedback loop or claim calibrated uncertainty.

**Frozen source and roles.** Allen native STPT acquisition 208 selected eight distinct globally TRAIN donors by donor ID before downloading images. The six smallest donor IDs `14383, 14451, 14453, 14543, 14544, 14598` are native-gradient donors. The remaining `14599, 14600` are *inner held animals*; neither their original images nor virtual cuts may enter gradient updates or adaptive batch/hyperparameter changes. The fixed readout below is only a continuation gate, not permission to tune repeatedly on these two animals. All have 140 genuinely acquired coronal sections at 100-µm spacing and their own Allen-authored estimated CCF registration. Atlas-mapped arbitrary-angle images are only virtual reslices across those physical sections. Existing previously inspected development-retention panels may be reread only for the fixed post-run check below; CAL/FINAL animals and DeepSlice remain unopened.

**Fixed comparison.** Start two arms from the same self-trained, originally random-initialized 187 step-800 model and AdamW state. Match optimizer, batch size, RNG streams, 0/200/400-batch checkpoints, trainable heads, and common source draws. The control receives three existing synthetic arbitrary-plane cases per batch; the native arm replaces exactly one of those three with one independently drawn TRAIN-native virtual plane. Both arms also see the same acquired Lupori TRAIN section and the same older coronal/sagittal TRAIN rehearsal section on every batch. Retain the 187 rehearsal weight (0.3) so neither arm repeats the 206 retention failure. A native draw uses original red SectionImages, not Allen's CCF-resampled red volume; every plane, roll, offset, background, and artifact is sampled independently. Record attempted/accepted draws and animal, specimen, experiment, source section range, native plane, map, and seed.

**Loss and feedback boundary.** Supervise pose against the pre-artifact affine CCF gauge of each mapped native plane, and the local tissue-to-atlas coordinate map only on valid observed tissue, using teacher-forced correct plane during the initial mapper update. Train the same heads/schedule in both arms. Since an arbitrary brain-intersecting plane may expose only a small, intrinsically ambiguous tissue fragment, multiply both native pose and map losses by `min(1, visible_tissue_fraction / 0.1)` and log this factor; retain the existing synthetic loss weights. This is an information weighting, not equal effective exposure between the arms. Keep MIND-to-pose off, because 206 supplied no useful held-animal direction. The learned fitted-candidate feedback head should not be promoted until the local mapper beats zero deformation on held animals; later it can be trained to prefer candidates requiring a small plausible map *and* matching native anatomy, then checked by a separate matched experiment. No external pretrained weights, features, or pseudolabels.

**Readout, before looking at held donors.** Primary: run all 140 **physically acquired** coronal red sections from each of the two inner held animals at their original native XY canvas, resized once to the model raster with its known geometry. Report top-1 five-point CCF disagreement with Allen's authored *weak* registration, donor by donor, for 0/200/400; stratify by image-derived tissue fraction and give p50/p90 and >5-mm count. Report valid-tissue local-coordinate RMS against the authored map, comparing learned map to both a zero-deformation map and the unchanged parent. Secondary: one fixed 64-plane per-donor full-sphere virtual-oblique panel, explicitly labelled reconstructed, never counted as independent physical-angle validation. Also report unchanged frozen synthetic v3/v4, Lupori `AL1A`, and older coronal/sagittal held-animal retention readouts. Do not use these panels to alter this pilot's fixed batches.

**Scale decision.** Only extend native training if each held donor improves top-1 physical-section p50 over its matched control by at least the larger of 0.5 mm or 10%, neither donor's p90 worsens by >0.25 mm, the learned local map beats zero and unchanged-parent RMS on both donors, and synthetic/old-real retention has no material regression. Two animals support a descriptive gate, not an animal-population confidence claim. If the gate fails, diagnose source representation/registration and candidate capture before buying more epochs or donors. Even a pass would authorize staged additional native donors/exposure, not GUI deployment, arbitrary physical-oblique claims, calibrated electrode-region probabilities, or a public DeepSlice benchmark.
