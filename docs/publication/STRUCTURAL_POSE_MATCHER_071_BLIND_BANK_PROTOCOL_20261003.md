# 071 learned pose score: frozen blind-bank readout

The 071 scratch matcher selected the exact-truth candidate in 44/48 eligible synthetic-development sections after 3,000 batches. This is only a **known-answer candidate-bank** result and may be easy because the exact pose was offered. Before interpreting it as useful pose feedback, score the 14 blind atlas-search candidates already frozen by experiment 069 for the same 32 sections used in 067–070. Do not retrain, alter candidates, inspect images, or choose a new checkpoint based on this bank.

Use the checkpoint chosen by the separate 071 development panel (`batch_03000.pt`). Reconstruct the 069 candidates and the 067a truth-only geometry fits with the same physical conversion used by 070. Use a fixed five-point ±50 µm finite-thickness PSF and a 64-pixel atlas render for both groups. Compare: (1) whether the truth-only best-geometry pose scores above **every** blind 069 candidate; (2) identity-equal physical error of the highest-scoring blind candidate versus the frozen 059 image-prior choice (2.311 mm) and 069 MIND choice (3.272 mm); (3) raw, brush, and black strata. There is no oracle candidate in the blind selection.

Advance to using this score inside a joint pose/deformation training experiment only if blind selection beats the 059 prior overall and does not worsen raw sections. Even then, this reused 32-section development bank is not independent biological validation, and it does not establish that the matcher can generate missing good poses or that fitting teaches the coordinate predictor. Failure is recorded without checkpoint retuning on these sections.
