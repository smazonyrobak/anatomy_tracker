# v3 one-pass plane-capture pilot 001 (predeclared)

## Question and ancestry

Does adapting the existing one-pass pose predictor to the v3 input distribution recover the raw/no-brush candidate coverage missing on the fresh 103 development panel? The sole model parent is the project's scratch-lineage 094 step-20,000 checkpoint (`81cd7baeb34bbf5b36a84b3e13987f2794f39389828c9cd0865dd809d6e06815`). The 103 matcher is **not** a training parent: it failed its own gate. No pretrained external features, prior application model, public benchmark, DEV label, or final animal enters training. This is a pose-capture test, not a new architecture or a GUI model.

## Frozen training design

- Run on `I:` only. Draw 8,000 updates with two fresh, independently randomized eligible TRAIN planes and one real TRAIN image per update. `sample_one_shot_slide_artifacts_v3` supplies a single randomly chosen appearance/artifact realization for each new physical plane. Reject only the sampler's existing insufficient-visible-tissue cases; never reject a similar plane or manufacture paired black/gray copies. Preserve every draw seed, physical-section ID, virtual-subject/deformation lineage, angle, mode, artifact parameters and acceptance decision.
- Keep full-sphere normal, offset, in-plane rotation, thickness and virtual-subject sampling. v3's raw/exact-black/imperfect-brush probabilities are 0.70/0.15/0.15; raw exteriors can be black, near-black or non-black. These are TRAIN choices, not measured laboratory artifact prevalences. The synthetic pose target is the source cutting plane, not an affine refit to artifact-displaced pixels. Observed surviving-pixel CCF coordinates provide a separate tissue error term.
- Use the reserved Allen TRAIN-only real stream. Permute donors in cycles so each donor contributes approximately equally; draw a shuffled section within each donor and retain animal, specimen, experiment and section identity. The reference is an inherited **weak Allen affine**, not expert registration. Upsample its existing 192-pixel image to the model's 256-pixel training size. For each two synthetic examples, include one real example with a **one-sided retention loss**: penalize only when the student's probability-weighted weak-affine five-point error exceeds the frozen 094 parent's error on that same image by more than 0.05 mm. The real term cannot reward moving farther toward a coronal weak label once the inherited real performance is retained; the full-angle synthetic loss remains primary.
- Instantiate the unchanged `OneShotJointSliceModel` with 16 old modes, 64 antipodal normal anchors and all 094 options. Load 094 model weights exactly; retain a separate frozen 094 copy only to evaluate each real TRAIN image's baseline. Updates 1–2,000 train only `pose`, `anchor_pose`, `anchor_global`. Updates 2,001–8,000 additionally train the shared `encoder` and `lateral` at one-tenth the pose-head learning rate. Keep the atlas matcher/fitter, local warp/map, and all candidate-scoring heads fixed. Use the 094 synthetic direct objective (observed surviving-coordinate error, source-plane five-point/normal anchors, multimodal mass/reflection supervision), plus 0.35 times the one-sided real retention loss. AdamW weight decay 1e-4, gradient clip 5, conservative cosine decay. Save 0/2,000/4,000/8,000 checkpoints and all training/draw/real-schedule receipts. Falling TRAIN loss is not a spatial gate.

## Development readout and decision

The already-audited 103 panel (256 independent v3 synthetic sections from eight new deformation identities; 237 eligible, including 176 raw) may be reused for **development only**: its raw gap informed this pilot, and choosing a checkpoint on it is biased. For each checkpoint, form its own natural 8-old/6-anchor beam, then apply the *unchanged* frozen 094 fitter, mapper and score. On the identical sections and surviving pixels, report raw/no-brush best-of-14 mapped96 error (primary capture metric), pre-fit rigid best-of-14, 094-score-selected mapped96 error, selection regret, valid-tissue fraction, and raw/exact-black/imperfect-brush, principal-axis, nearest-axis-angle and eight-plan strata. Do not use the 103 learned matcher for selection. Compare step zero to the previously reported raw physical-best 2.742 mm only after metric/parity verification.

The capture pilot advances only if a trained checkpoint lowers raw/no-brush best-of-14 mapped error by at least 0.35 mm versus its matched step zero; at least six of eight plans' raw means improve; overall selected mapped error does not regress; no brush-mode or nearest-axis family mean regresses by more than 0.20 mm; and, on the same six disjoint Allen DEV donors used in earlier one-shot development, no donor's **prior-selected five-point weak-affine error** regresses by more than 0.20 mm. Use plan-equal synthetic means, donor-equal real means, the same 1,024 deterministic surviving pixels per panel section across all steps, and fixed step-zero support-count strata when comparing support groups. These unpaired appearance groups do **not** establish that a background caused the 103 gap: tissue support and cutting geometry differ. Inspect pre-fit versus fitted best-of-14 separately to detect drift in the frozen fitter as shared image features change.

If the development gate passes, freeze a **new untouched** identity-disjoint v3 synthetic confirmation panel before claiming a reproducible capture gain. If capture improves but selection does not, do not promote the checkpoint: candidate ranking remains a separate failure. If capture does not improve, stop this direct-adaptation branch instead of scaling exposures or adding another field/scorer. Neither synthetic panel proves physical all-angle accuracy; acquired, animal-disjoint steep-oblique truth, uncertainty calibration and a fair eventual DeepSlice comparison remain later gates.
