# Learned atlas-match selection 032: first curriculum stage

031 showed that atlas-point candidates are often present but geometric voting selects false, mutually consistent groups. This stage adds a **set-wise correspondence selector intended for the final joint model**, rather than another scalar score on 019's eight near-miss planes. A query patch retains its top 16 matches from the truth-independent, frozen 030 atlas bank. Each candidate token contains the observed and atlas descriptors, their cosine score, observed pixel location, atlas point, oriented frame, flip parity and rank. Three shared self-attention blocks let all candidate matches of one section inform each other. The model predicts one of 16 matches or “no valid match” per query; a differentiable weighted plane fit is part of the model interface for the subsequent joint pose/deformation stage.

The scientific precedent is [SuperGlue](https://openaccess.thecvf.com/content_CVPR_2020/html/Sarlin_SuperGlue_Learning_Feature_Matching_With_Graph_Neural_Networks_CVPR_2020_paper.html), which learns matching with context and unmatched points; [DSAC](https://openaccess.thecvf.com/content_cvpr_2017/papers/Brachmann_DSAC_-_Differentiable_CVPR_2017_paper.pdf) shows why hard hypothesis choice must be handled carefully if downstream fitting is to teach localization. Their tasks differ; neither establishes accuracy for arbitrary-plane histology. No weights, features or pseudolabels come from those methods.

Continue the project-born scratch 025 descriptor as a frozen front-end for this first stage. Initialize the selector randomly. For 3,000 batches of two fresh synthetic TRAIN slices, obtain 32 training-only known-valid tissue query pixels per slice, search the frozen atlas bank with both query parities, and supervise the nearest top-16 atlas location when within 500 µm of synthetic truth; otherwise supervise the no-match option. No duplicated background variant of a section is made. Only the selector updates. Save checkpoints at 0/1,000/2,000/3,000 batches and preserve draw seeds/identities. This is a *curriculum stage in the intended architecture*, not evidence of the final fitting-to-pose learning mechanism.

Evaluate every checkpoint once on the same 185 synthetic DEV sections with the fixed 030 query pixels and candidate lists. The necessary stage gate is that ≥50% of queries **with an available top-16 match** choose a location within 500 µm, false-match rate on queries with no such match is ≤20%, and the differentiable weighted plane-fit rigid tissue-coordinate mean is <2.5 mm. The 030 top-16 availability rate is only 15.42%, so an all-query ≥20% correct-match gate would be impossible. If the classification gate passes but plane fitting fails, investigate uncertainty weighting and multi-modality; do not average incompatible planes and call it solved. If neither passes, do not add the module to GUI inference. Next, replace oracle query selection by image-derived sampling and jointly train selector, pose correction and local fitter with a verified fitting-loss gradient into pose. Real donor development and probability calibration remain separate requirements.
