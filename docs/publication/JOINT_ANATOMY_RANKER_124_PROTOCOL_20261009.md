# 124: learned anatomical fit on blind candidate maps (predeclared)

## Question and scope

The frozen 122 model often contains a plausible arbitrary-plane candidate but selects the wrong one; its simple local-correlation fit and the 123 high-pass alternative do not provide reliable blind feedback. Test whether a **bounded, learned image–atlas correspondence score after the model's predicted deformation** can identify the better candidate, beyond atlas-support shape. This is a TRAIN-to-synthetic-DEV development experiment, not a model promotion. The 122 step-2000 pose, global matcher and mapper remain fixed in this first stage. If the score passes, a separately frozen continuation will make fitting evidence train direct pose probabilities; merely reranking after training does not satisfy the goal.

Use one fresh independently randomized v3 synthetic TRAIN section per accepted presentation from the 64 TRAIN deformation bases, preserving all provenance and rejected draws. Do not deliberately pair/repeat a plane to vary background or artifacts. Use the existing 16 blind beam with both original and globally corrected actions. For all corrected candidates, run the frozen 122 map. The ranker sees raw/model image features and an atlas slab extracted **at each fitted mapped surface** using a fixed nine-sample 62.5-µm PSF that is available at deployment; it never sees synthetic true thickness. Bounded local XY/through-plane correspondence and explicit displacement/strain cost approximate fitting difficulty. The score is aggregated on identical pairwise common eroded atlas-support pixels, without oracle tissue mask, source segmentation or known synthetic pose. Unsupported pairs contribute no evidence and fall back to the 122 score. Apply the resulting candidate evidence equally to that candidate's original and corrected action logits, leaving their within-candidate action choice to the frozen matcher.

Train two rankers of identical architecture and initial tensors on exactly the same sections and optimizer schedule: full atlas intensity/support versus intensity set to zero with support unchanged. Initialize the ranker embeddings afresh in both arms (do not inherit intensity-trained 083 embeddings). Freeze all 122 tensors in this stage. Supervise pairwise evidence on blind corrected candidates using synthetic mapped-tissue error, while monitoring rigid placement. The truth and valid-tissue pixels select labels only; they never enter scorer inputs or pair masks. The best candidate is the corrected slot with lowest mapped-tissue error; abstain if that error exceeds 1.5 mm. Compare it with the lowest-error wrong slot whose mapped-tissue error exceeds best by >1 mm, whose **un-eroded** mapped-support Dice is ≥0.85, whose area-fraction gap is ≤0.08, and which has ≥32 shared 5×5-eroded interior cells at side 32. Use the same deterministic pair rule for TRAIN and DEV. Use fixed PSF and identical atlas/image input treatment in both arms. Save step 0, intermediate and final rankers, training losses, pair counts and exact source/data/checkpoint/draw hashes. The frozen 122 model is not modified.

Evaluate final rankers once on all eligible sections from the existing frozen `v3_pose_capture_confirmation_panel_001` (eight synthetic development deformation plans). This panel and the six coronal/eight sagittal weak-real DEV donors have already informed this project; results are development evidence, not new independent confirmation. Recompute the 122 baseline on the identical candidate beam, maps and fixed-PSF rule. Primary readouts are pairwise anatomical ranking on identical support-matched pairs, selected mapped-tissue and rigid-gauge error, and per-plan outcomes. For real DEV, score the same frozen beam without synthetic validity/truth, then compare donor-equal weak-affine five-point discrepancy with frozen-122 baseline, reporting every donor and selected-action change. Include zero-intensity eval and a source-image-swap control to detect non-image evidence. Report all abstentions and availability of a near candidate.

The stage-1 anatomical-evidence gate requires at least 64 eligible matched development pairs, ≥75% full-intensity pair wins with ≥0.01 score margin, and a ≥10-percentage-point win advantage over the identically trained support-only arm. The selected mapped error must improve by ≥0.30 mm versus 122 and ≥0.15 mm versus support-only, with no rigid-error regression versus 122; at least six of eight synthetic plans must not worsen. Both real families must not worsen donor-equal mean by >0.20 mm versus 122, with no donor worsening by >0.50 mm. Full-intensity pair wins must exceed each zero-intensity-at-evaluation and different-image source-swap control by ≥10 percentage points on identical scored pairs; swap both raw pixels and source features, leaving the candidate states/maps fixed. Failure means no score-to-pose feedback continuation from 124; report the raw scientific trade-off without waiving the gate.

Passing would justify, **not itself complete**, a matched joint continuation in which this fitted evidence changes direct `log_mass`/reflection probabilities under continued synthetic pose/map supervision and real-image retention. That continuation must measure nonzero useful score-to-direct-probability learning, selected physical improvement beyond a no-feedback control, donor-level real retention, and later fresh synthetic confirmation. The final system still requires acquired animal-separated arbitrary-oblique expert validation, uncertainty calibration, GUI integration and a fair locked DeepSlice comparison.
