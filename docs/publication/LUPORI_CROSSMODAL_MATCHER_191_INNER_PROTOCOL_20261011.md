# 191: inner-animal test of a learned cross-modality plane comparator

The raw correlation selector failed in 190, although 189 found a local atlas-intensity direction. Before linking fitting cost back into pose learning, test whether the existing **spatial image↔rendered-atlas matcher** can learn to compare blind pose proposals from fluorescence. This is a bounded TRAIN-only experiment on the scratch-lineage 187 step-800 parent, which never saw `AL1A`: freeze its image encoder, direct pose heads, atlas-conditioned deformation mapper and all other weights. The only trainable component is a copy of its global plane matcher (`source`, `atlas`, `head`), initialized from the same parent for both arms.

Train on the 188 valid sections from `CC2B,CC4B,CC4A`, with exact 187/188 full-thumbnail `max(red,green)` image-wide-p99 input and approximate human QuickNII planes as *weak labels*. Keep the first 16 blind pose/reflection proposals fixed before using the label. For each of 600 batches, one acquired section is drawn from repeated shuffled 188-section epochs. Supervise four distinct branches: the five-site closest of the blind 16, the prior first choice, the highest-prior branch at least 1.5 mm worse than the closest, and the next-best remaining branch. The target is the four-way `softmax(-five-site error/.7 mm)`; train the model's branch log-score by cross entropy. No reference plane is inserted as a candidate. No deformation labels, DEV/CAL/FINAL images, or public benchmark are used.

Run two paired arms on the same images, branches, initialization and 600 updates. `full` sees the rendered atlas intensity **and** support; `support_only` receives zero atlas intensity while retaining identical geometry, support, image and supervision. Both use the exact five-sample finite-thickness renderer at -50,-25,0,25,50 µm with weights 1,2,4,2,1, 24² spatial matcher, AdamW 1e-4, weight decay 1e-4, gradient clipping 5. The arms cannot update pose or deformation. Save step 0/300/600, draw IDs, losses and source/checkpoint hashes.

After the run exits, score all 52 valid sections of `AL1A`, the untouched **inner TRAIN-animal guard for 187**, using the full first-16 blind beam for each arm and the frozen original direct prior. Compare first-choice five-site mean/median error, ≤1.5-mm count, and severe >5-mm count; report the oracle available within 16 separately. The fixed step-600 full arm passes this screening only if its mean error is at least 0.15 mm below the original prior and at least 0.15 mm below support-only, its ≤1.5-mm count is no lower than the original prior, and its >5-mm count does not increase. Do not select a checkpoint post hoc from guard results. A pass supports learning an anatomy-sensitive **candidate readout**, not joint deformation/pose feedback or independent final validation. A failure forbids scaling this matcher unchanged. If it passes, check synthetic/old-acquired retention before any full-TRAIN continuation.
