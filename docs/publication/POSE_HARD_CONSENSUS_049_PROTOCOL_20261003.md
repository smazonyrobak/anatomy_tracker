# 049 spatial hard-match plane fitting (pre-result protocol)

047 and 048 did not improve selection, despite a much better best-of-eight branch. The 046 patch matcher selects an atlas key within 1.5 mm of a known synthetic tissue point for ~76% of visible queries on the *physically best* 019 branch, but 047 averaged soft matches from only eight queries. This diagnostic tests a different, explicit mechanism: use 16 spatially spread, predicted-tissue query points, take a hard 046 match among 16 shortlisted atlas keys at each, and robustly fit one full 3D plane from the resulting point set. Use 128 fixed-seed four-point hypotheses, a 1.5-mm consensus radius, and the same prior-regularized refit as 043. Report the ungated fit and the frozen 041 safety gate separately. No synthetic truth is used to pick query points, keys, a hypothesis, or a branch; truth is scored only afterwards.

Freeze 019 batch 18,000, 041 batch 1,500 and 046 batch 2,000. Use the same original prior top-eight branches on all 177 eligible sections of the unchanged eight-identity synthetic 037 DEV panel and 64 acquired weak-affine DEV sections from six donors. Compare initial, all-hard-match, robust raw, and gated top-one/best-eight physical tissue errors with equal identity/donor weighting. The gate for a useful direction is ≥0.2-mm best-eight synthetic improvement, no >0.2-mm top-one synthetic worsening, and no >0.2-mm worst-real-donor weak-affine regression. The weak real affines are not expert arbitrary-plane truth. A physically best-eight branch is an unavailable oracle and never a deployable selection rule. This experiment cannot establish calibration, biological accuracy, or superiority to DeepSlice.

The 037 DEV identities have already guided architecture decisions. A promising 049 result would require a new synthetic identity holdout and then expert animal-level validation before promotion. The candidate ranker, local deformation mapper, and direct pose head are unchanged in this diagnostic. No image grids are opened.
