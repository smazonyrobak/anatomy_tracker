# 306: can the frozen 305 plane candidates be ranked better?

The 305 source-only pose mixture captured a ≤1.5-mm candidate in 56/64 frozen synthetic TRAIN-inner sections after acquired rehearsal, while its first choice remained 2.140 mm on average. The joint fit selector failed; a fixed-size local atlas stencil was comparable on only nine of 64 fresh sections. Before changing the renderer, warp or proposal geometry, isolate whether the image-conditioned probabilities can learn to select their existing candidates.

Start from the verified 305 acquired-rehearsal intervention local-step-400 checkpoint and freeze the encoder, feature pyramid, candidate states, local mapper, reliability map and all geometry/uncertainty outputs. In the three final pose/anchor output layers, train **only** the mass and reflection-logit weight/bias rows, with fresh optimizer moments and zero weight decay; all other rows must remain exactly unchanged. Use no prior external model, feature or pseudolabel. Draw four new eligible arbitrary-plane v9 synthetic sections per optimizer batch from bases 0–55, once each, with independent seeds and full provenance. Sample 128 surviving observed sites per section. Compute all candidate rigid-site errors against synthetic CCF truth only for supervision; the network receives the image alone. Optimize a soft physical-error target at 0.35-mm temperature plus expected physical-error risk. No atlas fit or deformation is run during this diagnostic.

Before training, freeze two separate 64-section panels (eight independently sampled eligible physical sections per base 56–63): an inner choice panel and an untouched-by-checkpoint-choice confirmation panel. Record accepted and rejected draws and physical-section IDs. Read out the inner panel at 0, 200, 400 and 800 four-section batches; select the checkpoint with the lowest equal-base first-choice rigid-site mean, including step 0. Evaluate the confirmation panel **once**, only for that selected checkpoint and step 0. Advancement requires at least 0.25-mm improvement on both panels, improvement in at least six of eight bases on confirmation, and no more than four lost top-16 ≤1.5-mm captures on confirmation. Exact candidate-state equality before/after the intervention is mandatory; if the inner panel never improves ≥0.25 mm, skip confirmation and real-image loading.

If the synthetic gate passes, run the selected checkpoint on the existing 52-section `AL1A` fluorescence TRAIN guard and the 20+20 fully held-out older Allen TRAIN donors, using the exact prior input and weak-reference conventions. Require `AL1A` mean five-site gap no more than +0.20 mm relative to the frozen parent, sagittal first-axis correct ≥15/20, and coronal first-axis correct ≥19/20. These are repeatedly inspected TRAIN diagnostics with approximate registration labels, **not** clean acquired-animal validation. Passing only licenses a later candidate/atlas feedback experiment; it does not establish an accurate final model, calibration, arbitrary physical oblique performance, or GUI readiness. Failure stops rank-logit-only training; do not tune the threshold or extend this unchanged experiment. No DEV/CAL/FINAL animal or public benchmark is touched. All code/data/output remain on `I:`.
