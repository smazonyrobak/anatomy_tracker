# 322: frozen C4 internal-boundary information diagnostic

This is a no-training, CPU-only TRAIN-inner diagnostic, not a deployable selector. Freeze the 321 batch-12,000 checkpoint, its 128 inner panel cases, their top-16 scored C4 candidates, and frozen 309. Do not read DEV/CAL/FINAL animals or public benchmarks. Preserve every 321/309 artifact. Write only a new 322 output directory on I:.

For each candidate, render the pinned Allen 25-um annotation at a 48×48 regular observed chart. Convert IDs to the 14 broad ontology classes used in 079, then mark **internal** four-neighbor class boundaries only where both adjacent pixels are brain. Exclude exterior-support edges. On the same 48×48 lattice, average-pool the source intensity 4×4, Gaussian-smooth at one cell, and mark the strongest 20% of gradient pixels inside blocks with ≥90% synthetic valid tissue; inversion polarity is ignored. The valid mask is privileged information used only to test whether this cue exists, not an inference input. Candidate evidence is the fraction of rendered internal-boundary pixels within two cells of a source edge, maximizing over one shared integer XY shift in [-2,2]². Require ≥24 eligible internal-boundary and ≥24 source-edge cells; otherwise candidate evidence is unavailable. No local warp, fitted pose update, candidate-specific tissue mask, or learned feature is allowed.

Run an observability preflight on the first 16 fixed inner cases. Stop without full-panel selection if fewer than 12/16 cases have ≥4 top-16 candidates with available boundary evidence or fewer than 8/16 have the truth-best top-16 candidate available. This stop tests whether the channel exists, not whether it ranks well. If observable, score all 128 cases. The boundary-only first choice is highest available evidence, breaking ties by frozen 321 prior; cases with no available candidate retain frozen 321 first choice. Compare matched support-only atlas-mask Dice and a shuffled-boundary null that permutes each candidate's boundary locations within its atlas brain support, preserving the boundary count. All three use the same candidates/cases and no fitted warp. Synthetic truth determines errors and matched near/far pair membership only after blind scores are fixed.

The diagnostic information gate requires all of: ≥40 support-matched near/far pairs (per case, take the physically best available candidate as near if ≤1.5 mm, and the highest-prior available far candidate with ≥2 mm error, ≥1 mm worse than near, and atlas-support-fraction difference ≤0.10); intact-boundary evidence prefers near on ≥70% and ≥10 percentage points more pairs than both support-only and shuffled-boundary scores; boundary-only first-choice mean rigid-site error at least 0.20 mm below frozen 321 first choice, at least 0.15 mm below frozen 309, and at least 0.15 mm below each support-only and shuffled-boundary selector; first-choice >5-mm count no greater than frozen 309's ten; and at least six of eight base-animal means non-worse than frozen 321. Report all failures, available-candidate counts, and top-16 truth oracle. If the gate fails, do not train or add another selector on this cue. A pass would justify only a separately predeclared practical source-reliability experiment and fresh confirmation, never model promotion or real-animal accuracy claims.
