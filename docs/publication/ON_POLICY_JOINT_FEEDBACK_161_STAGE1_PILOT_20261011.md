# 161 stage-1 bounded TRAIN-only pilot (pre-run)

This pilot implements only stages 1–2 of `ON_POLICY_JOINT_FEEDBACK_161_PROTOCOL_20261011.md`. Use the frozen 132 step-2000 checkpoint and its native global matcher, atlas-conditioned local mapper, and fit-quality head. Freeze the direct pose predictor and image encoder. Both arms reload identical parent weights and see one identical ordered list of independent v4 TRAIN physical sections; the only arm difference is atlas intensity available to the matcher/mapper during continuation. In the support-only arm the atlas intensity channel is zero from the first update, while atlas support, candidate states, source features, and losses remain unchanged. Both arms inherit earlier full-intensity exposure from parent 132: this isolates *continued-training* intensity access, not a clean-from-random architecture effect.

Use TRAIN bases 0–59 for 192 eligible sections that have a predicted blind-top-16 branch within 1.5 mm. Every attempt, including ineligible, sparse-tissue, and no-near sections, is recorded; only the near-eligible subset supplies mapper updates. Freeze a disjoint inner panel from TRAIN bases 60–63 before training, drawing independent physical sections until 64 distinct support-matched pair sections are available (at most 256 attempts; otherwise stop). For each section choose the lowest-rigid-cost near branch, then the lowest-cost wrong branch at least 1 mm worse with original 24×24 atlas-support Dice ≥0.85, area gap ≤0.08, and ≥32 common cells. One pair decision per physical section is counted, not all possible correlated branch pairs. No true pose is inserted into the blind pair. A supplied exact pose is used only for local-map retention supervision and assay, never for pair ranking or inference.

Run 192 one-section updates per arm with fresh, identical AdamW (2e-5, weight decay 1e-4), gradient clipping at 2, and checkpoints at 0, 96, and 192. Optimize the existing global matcher, atlas encoder, pair/warp modules, and fit-quality head; keep the direct pose, encoder/lateral, and uncertainty head frozen. On a near predicted branch and a supplied exact plane, supervise valid-site CCF map error and corrected rigid error. Add warp magnitude/smoothness regularization. If a support-matched wrong predicted branch exists, train its *native mapped fit difficulty* to exceed the near branch by `softplus(0.1 + near_difficulty − wrong_difficulty)`; do not apply map-to-truth loss to the wrong branch. Difficulty is the model's existing post-map `fit_energy` plus 0.05 times local-warp magnitude/smoothness and 0.05 times squared rigid-centre correction in 2-mm units, not a new ranking network. The fit loss uses equal terms for near/exact map error, half-weight rigid error, 0.25 pair ranking, and 0.03 warp regularization. The full and support-only arms use exactly the same objective and deterministic 256-valid-site selection rule.

At each checkpoint, assay the same 64 inner pair sections: one near/wrong fit-difficulty decision per physical section, supplied-exact and predicted-near map error, and exact-plane rigid drift. Select each arm's checkpoint by highest pair-win fraction among checkpoints with exact and near map errors no more than 0.10 mm above its own step-0 values and exact rigid drift ≤0.25 mm; tie-break by lower mean exact-plus-near map error, then earlier step. If none qualifies, retain step 0. Stage 1 passes only if the selected full-intensity arm is a trained checkpoint, improves its own step-0 pair-win fraction by at least five points, wins at least 10 percentage points more inner pair sections than the selected support-only arm, and both satisfy map retention. On the selected full arm, also assay the *same fixed pairs* with atlas intensity shifted by 100 voxels along AP while support stays fixed, and with source visual features zeroed; these are out-of-distribution diagnostic perturbations, not substitutes for the separately trained support-only arm. No DEV/final/public data, pose feedback training, external weights, GUI promotion, or calibration occurs in this pilot.
