# DevCCF P56 source preflight — not a training addition

The [official DevCCFv1 dataset](https://figshare.com/articles/dataset/DevCCFv1/26377171) states CC BY 4.0 and asks users to cite the dataset and [Kronman et al.](https://www.nature.com/articles/s41467-024-53254-w). Its P56 bundle is 406,834,574 bytes, Figshare file ID `48169843`, advertised MD5 `9acc8b145745f920549bd2d6804e734c`. The downloaded I:-drive ZIP matched that MD5 and SHA-256 `ec5cd5da9747a11fb3e266bdbde9767dc90bf1b457f6c030ed9a06f122be886a`. The accompanying README matched Figshare MD5 `c11a4e1ad8b06477a8417a995cc084a9`. The exact local source is `I:/AnatomyTracker/data/devccf_v1_source_p56_20261009`.

Only the authors' native `P56_LSFM_20um.nii.gz`, `P56_DevCCF_Annotations_20um.nii.gz`, and `P56_MRI-MaskBrain_50um.nii.gz` were extracted for inspection. Their SHA-256 values are `cb451095b44fd6f254e9051327d056473713f3e33bcb978d931259b501e5eecd`, `2cd11048713eb2a4303c7db3073177ca6cef043549a33cf8c60c7223dbe7612e`, and `a14e7a69d70df5cb95161289ef84cdcbb55ea7b51dc6d4d81d545ea751dfbdd9`, respectively. The ZIP also contains Allen-CCF-derived template/annotation layers; none was extracted or used for training. NIfTI headers of LSFM and native annotation both report `640×455×900` voxels at 20 µm isotropic spacing with the same affine. No image pixels entered a model, optimizer, synthetic generator, or benchmark in this preflight.

The [paper](https://www.nature.com/articles/s41467-024-53254-w) describes the P56 LSFM template as averaged, symmetric, and registered to an MRI morphology template; it is **not** Nissl histology from independently sampled animals. It may offer a second 3-D contrast source with native isotropic arbitrary-angle reslicing, but does not by itself fix the current model's raw/no-brush failure, provide physical oblique test slices, or supply directly usable Allen CCF target coordinates. A small, provenance-separated source ablation plus explicit coordinate/rights checks must precede any training use. Keep the primary model and all qualification outputs unchanged until that gate is designed.
