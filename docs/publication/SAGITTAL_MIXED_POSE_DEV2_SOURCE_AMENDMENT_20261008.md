The mixed-pose protocol froze eight physical-sagittal weak-DEV2 donors and 159 SectionImage IDs before downloading or evaluating their JPEGs. A source-availability inventory of exactly those 159 IDs, performed before any checkpoint readout, found 158 decodable official JPEGs. SectionImage `101345593` (donor `10430`) reproducibly returned a non-JPEG body, including at other image-service resolutions. The inventory preserved URL, HTTP/body signature, decode result and exact IDs without retaining or viewing DEV2 images. Its manifest SHA-256 is `8cec8d29c4d177073e58b8bc2871e849c1051620a4d00eb88d636017f402066d`; receipt SHA-256 is `975707c8ca6a2d60588c6b571052d2dea90c4fe016114b76cc1e38cb12fe38b2`. All eight donors retain at least 19 available sections. No sealed-holdout image was requested.

The donor split and the original 159-ID intended cohort remain frozen. For the one planned three-checkpoint comparison, evaluate **all 158 source-available DEV2 sections** with equal weight per donor, explicitly list the one unavailable source ID, and retain every numeric improvement/retention threshold and tie-break rule from `SAGITTAL_MIXED_POSE_CONTINUATION_001_PROTOCOL_20261008.md`. Do not substitute a different section, use a placeholder, relabel the absent image, or use the sealed holdout. This changes only the source-available denominator; it does not select cases based on anatomy or model performance. Record both the original 159-ID cohort and actual 158-image denominator in the result.

The original training protocol remains byte-for-byte unchanged because the active trainer binds its SHA-256. This amendment must be bound separately by the evaluator before its first model readout. Real affine references are still weak automated Allen alignments, not independent expert ground truth; passing this internal gate would not establish reliable arbitrary-plane performance, calibrated probabilities, or GUI readiness.
