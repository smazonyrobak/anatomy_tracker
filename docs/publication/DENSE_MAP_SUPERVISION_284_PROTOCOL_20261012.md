# 284: does fuller coordinate supervision teach the image mapper?

282 used 128 surviving sites per unique synthetic section and learned almost no useful map; 283 found only a 0.0034-mm gain even on previously seen sections. The synthetic generator supplies valid pixel-to-CCF coordinates much more densely. Following the image-pair registration principle of [VoxelMorph](https://ieeexplore.ieee.org/document/8633930) and the broad synthetic-appearance strategy of [SynthMorph](https://pmc.ncbi.nlm.nih.gov/articles/PMC8891043/), run one matched, bounded supervision-density comparison before adding fit-feedback machinery. Those papers motivate paired visual evidence and augmentation, not a claim that this specific loss will work for arbitrary-plane histology.

Freeze the 275 step-8,000 scratch pose encoder/lateral features in both arms; override its pose with each section's true synthetic state and reflection. Initialize the same smooth16/full-atlas mapper from the same random seed in each arm, train only `warp_shared`, `warp_condition`, `warp`, `atlas_encoder`, and `pair`, and retain the same affine-free 0.35-derivative-limited local map. Arm S uses 128 deterministic surviving coordinate sites per independently sampled v9 TRAIN section, as in 282. Arm D uses up to 2,048 evenly spaced valid sites from the same section; if fewer exist, use all valid sites and log the count. Both minimize mean Euclidean CCF site error in mm, with no rank, magnitude, or acquired-label term. Use matched AdamW learning rate 1e−4, weight decay 1e−4, gradient clip 2, batch one and 3,000 independently drawn eligible physical sections from TRAIN bases 0–55, seed `20261012284`. Replay the identical source-section schedule across arms for a fair loss comparison, but never create paired background/artifact versions within an arm or carry a previous plane into the next draw.

Before updates, freeze a new 64-section readout from TRAIN bases 56–63: eight independently sampled eligible sections per base with at least 512 valid pixels, 512 deterministic sites each, a separate seed branch, and logged rejected attempts/provenance. Report fixed readouts at steps 0, 750, 1,500, and 3,000 for each arm, no checkpoint selection by readout. The mechanism signal at step 3,000 requires D's new-base gain ≥0.02 mm, nonnegative gain in at least six of eight bases, derivative ≤0.35+1e−5, and D−S gain ≥0.01 mm. Also report train loss/site-count traces and artifact/sparse strata. No full joint training, DEV/CAL/FINAL animals, public DeepSlice comparison, or real-location/probability claim follows from this pilot. If both arms remain near zero, inspect input–atlas correspondence and gradient/field scale rather than simply extending the same schedule.
