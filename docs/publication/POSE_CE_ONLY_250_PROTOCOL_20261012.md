# 250: matched normal-only optimization check

The 249 fresh-random pose-stage run did not learn its 64-anchor normal target over 12,000 v7 synthetic TRAIN presentations: last-500 mean cross-entropy remained near `ln(64)`. Its objective mixed normal cross-entropy with a rigid-position term and clipped the combined gradient on most updates. This bounded comparison removes only that rigid term. It tests whether the loss interaction hid a learnable normal signal; it does not establish arbitrary-plane deployability.

Use the identical 249 model initialization seed, 64 TRAIN synthetic deformation bases, subject/draw seeds and accepted/rejected physical-section sequence, 3,000 batches of four sections, 192-pixel inputs, AdamW settings and 64 shared antipodal anchors. Independently initialize from that seed; never load 249 or any prior weights. Supervise only the same 15-degree soft antipodal normal cross-entropy. Preserve raw, exact-black and imperfect-brush draw probabilities. Record draw identities, loss/gradient curves and step 0/500/1,500/3,000 checkpoints with exact hashes on I:. Compare the draw log byte-for-byte with 249 after completion.

The continuation signal requires last-500 TRAIN cross-entropy at least 0.5 below `ln(64)`, and a later same-case eight-plan v7 DEV normal-axis gain of at least 10 degrees over 249. A flat curve stops this training recipe. Neither selected rigid error nor reflection probability is a criterion here because reflection is not supervised. This is development diagnosis only; do not use calibration/final animals or the public DeepSlice benchmark.
