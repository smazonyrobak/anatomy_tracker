# Frozen 083 evidence as a whole-plane score: diagnostic protocol

083 passed a held-out *local correspondence* gate, but its loss was conditioned on an existing candidate. That does not show that an inference-time score can choose among all 14 blind candidate planes. Before expensive joint training, test one fixed, label-free aggregation of the frozen 083 matcher on the eligible 061 synthetic DEV sections.

Use parent 059's unchanged top-eight old and top-six anchor beam. For every candidate, compute coarse and fine 083 logits in chunks of two. At each query cell, retain atlas classes with support ≥0.5, softmax their logits, and calculate peak excess above the uniform `1/K` chance level: `(max_probability - 1/K)/(1 - 1/K)` for `K≥2`, otherwise zero. Average over **all** query cells, including exteriors, then average fine and coarse scales. This is the sole predeclared candidate score. It uses neither the synthetic tissue-validity mask nor target coordinates, and does not require an automatic slice segmentation. Record candidate support coverage separately. No weights are fitted on DEV and no alternate score is selected post hoc.

For evaluation only, measure every existing candidate's rigid 3-D CCF error at 1,024 fixed surviving-tissue pixels, then compare score-selected error and rank of the truth-best existing candidate with the parent prior-selected error. Report plan-equal overall and background-mode strata, the best-candidate role, and margins against hard negatives. The truth-best branch is never inserted into the beam; it is an oracle diagnostic of the beam already available at inference. This test does not measure final fitted-map accuracy or real-animal transfer.

Decision rule: use this raw score as a direct selector only if it reduces plan-equal selected rigid error by ≥0.25 mm against the frozen prior and puts the truth-best existing branch in its top three for ≥50% of sections, without a background mode becoming worse than the prior by >0.25 mm. If it fails, do **not** discard the local 083 matcher: train an explicit all-14 candidate ranker and pose/map fitting feedback in the next stage, and never report the failed raw confidence as a calibrated probability. Freeze all input hashes, raw rows and summary on `I:`; do not access real calibration/final animals or the public DeepSlice benchmark.
