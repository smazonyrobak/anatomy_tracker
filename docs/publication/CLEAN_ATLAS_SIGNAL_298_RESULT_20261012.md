# 298: clean atlas images do not rescue the scalar plane score

The frozen, no-training 2×2 control completed on the same 32 distinct TRAIN-inner synthetic sections and blind 16-candidate sets as 296. It replaced the artifacted observed image with an unranked clean rendering of the **true atlas plane** and/or replaced the inference-observable common mask with the 512 saved truly valid tissue sites. Both substitutions are privileged diagnostics, not deployable inputs. Candidate states, thickness, atlas, zero-deformation objective, physical errors, and pair definition were unchanged. All 512 artifact/common candidate scores exactly matched 296's stored step-zero scores.

| Image and scoring mask | Mean rigid error of minimum-score blind candidate | Near-over-support-matched-far wins / 27 | Mean unranked true-plane score |
| --- | ---: | ---: | ---: |
| Artifacted image, common observable mask | 2.227 mm | 14/27 | 0.430 |
| Clean true-atlas image, common observable mask | 2.064 mm | 19/27 | 0.046 |
| Artifacted image, privileged valid sites | 2.409 mm | 20/27 | 0.231 |
| Clean true-atlas image, privileged valid sites | 2.617 mm | 19/27 | 0.009 |

For context, the unchanged pose model's first blind choice was **1.973 mm** and the truth-informed best available candidate was 1.073 mm on these same sections. Clean appearance improved the common-mask score's selected error by 0.163 mm and near/far pair wins by five, so appearance mismatch costs information. But even that favorable clean score selected a worse plane than the direct prior and won only 19/27 matched pairs. Using truly valid tissue sites made the true-plane score nearly perfect but made full-set candidate selection **worse**, despite some better pairwise wins. The exact plane is not part of the blind set; a low score at the exact plane does not imply an ordering that leads to it through approximate candidate poses.

Therefore the failed 296 feedback cannot be explained solely by synthetic artifacts or a bad observable mask. This particular global Pearson/coverage scalar is insufficient to select approximate blind planes reliably even under these favorable controls. The result does **not** establish that atlas anatomy lacks recoverable information, nor that arbitrary physical cutting angles are impossible: there are only 32 sections from one atlas, the diagnostic reused 296's candidate beam, and no learned spatial verifier was tested here. It does argue against more threshold, mask, or smooth-fit tuning of this unchanged score.

Post-exit audit verified the frozen source/protocol and 296 input hashes, all three 298 output hashes, 128 case-arm rows across 32 physical sections, recomputed each arm's means and pair wins, and independently rechecked all 512 artifact/common score values plus their 32 winners against 296 with zero numerical difference.
