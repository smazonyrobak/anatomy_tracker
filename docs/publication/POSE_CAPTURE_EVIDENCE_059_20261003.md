# Evidence guiding the 059 pose-capture correction

The unresolved failure is global pose capture, not local tissue mapping: in the 019 development panel, exact-pose mapped error was 0.129 mm, versus 2.591 mm when the model selected the plane. In 058, adding 64 normal anchors improved the truth-scored best-anchor synthetic candidate from 3.062 to 1.671 mm but selected error and real transfer deteriorated. A nonzero mapping-to-pose gradient did not fix candidate retrieval. These are internal development measurements, not external benchmark results.

Relevant primary evidence and its limits:

- [DeepSlice (Carey et al., 2023)](https://www.nature.com/articles/s41467-023-41645-4) regresses CCF corner vectors from a 299-pixel coronal section using a roughly 21-million-parameter ImageNet-initialized Xception network. It trained with about 131k Allen slide sections, 443k serial two-photon sections and 0.9M synthetic coronal sections. It recommends using 10–20 sections from a brain rather than a lone section for best cutting-angle estimates. Its seven-brain human-consensus benchmark is therefore important but neither a direct all-plane benchmark nor a justification for importing its pretrained weights into this project.
- [DSVR-net (Zheng et al., 2024)](https://doi.org/10.1016/j.eswa.2023.121132) separates out-of-plane content from nuisance in-plane transforms and uses differentiable resampling. This supports factorizing a plane-normal hypothesis from local in-plane pose, not rewarding the correct normal when the full plane is spatially wrong.
- [Rotation-equivariant 2D/3D feature matching (Brandstatter et al., 2024)](https://arxiv.org/abs/2410.18683) reports under-2-degree median angle error in CT/MRI single-slice tasks using 2D-to-3D features. This provides a credible alternative if direct atlas-plane regression remains unidentifiable, but same-modality clinical volumes and our variable-stain fragmented histology are not interchangeable.
- [Joint registration and synthesis (Iglesias et al., 2018)](https://pmc.ncbi.nlm.nih.gov/articles/PMC6742511/) couples registration with appearance uncertainty and deformation, but explicitly starts from a good rigid alignment. It supports fitting feedback *after* plausible pose capture, and warns by implication against trusting a flexible warp to rescue a globally wrong plane.
- [SVoRT (Xu et al., 2022)](https://pmc.ncbi.nlm.nih.gov/articles/PMC10129054/) updates slice transforms and a reconstructed volume iteratively, using information from multiple fetal-MRI slices. It establishes a plausible feedback mechanism but not superiority to a one-pass model for a single histological slice; the extra sequential and multislide information is a confound.
- [Joint part-to-whole MRI/histology registration (Athalye et al., 2026)](https://papers.miccai.org/miccai-2026/0518-Paper6039.html) coordinates global alignment, appearance decomposition and local deformation, but its two optimization phases and 18 same-specimen pairs are not evidence of population-scale single-pass atlas localization. Its global-then-local constraint reinforces avoiding pose/deformation compensation.

059 tests a targeted consequence of this evidence: retain the original 019 candidates, add fixed antipodal normal hypotheses with local residuals, supervise each hypothesis and its probability by *complete physical pose*, and use finite-thickness fitted feedback on candidates actually selected by the prior. The old branch is guaranteed a place in a multi-candidate beam. This change is a hypothesis, not a claim of improvement. Success still requires identity-disjoint all-plane synthetic capture **and** animal-disjoint real retention, followed later by calibrated uncertainty and untouched fair DeepSlice comparison. If 059 fails, the next experiment should compare learned 2D/3D correspondence or rotation-equivariant retrieval against this direct head using the same frozen identities and exposure, rather than simply stacking more fit scorers onto missed planes.
