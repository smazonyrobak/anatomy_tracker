# Matched heads-only continuation 109 — frozen protocol

The 108 continuation improved full-angle synthetic pose capture and agreement with weak sagittal affines after unfreezing shared image features, but its weak coronal DEV discrepancy rose sharply. This control asks whether the shared-feature updates caused that tradeoff, as opposed to the additional 1,306 batches and repeated exposure to the same 653 sagittal TRAIN images. This is a causal architecture diagnostic, not a new independent validation set or a claim of expert anatomical accuracy.

Branch from the exact 108 step-653 model, optimizer and random-number states. Replay global updates 654–1,959 with the same 108 coronal and sagittal schedules, synthetic subject draws, per-row appearance/artifact seeds, retries, surviving-pixel samples, loss, head learning-rate schedule, and data preprocessing. Each batch still has two independently drawn full-angle synthetic physical sections, one acquired coronal TRAIN section, and one acquired sagittal TRAIN section. The matched control deliberately uses the same examples *across the two experimental branches*; it does not create paired artifact/background versions within a branch. Preserve animal/specimen/experiment/section provenance. Keep the encoder and lateral image features frozen and their optimizer learning rates zero throughout this continuation; train only pose, anchor-pose and anchor-global heads. The atlas matcher, warp, fitted scorer and uncertainty components remain frozen as in 108. Save inherited step 653 and terminal step 1,959 with optimizer/random states. Hash the source, parent checkpoint/completion, data, schedules and the exact replayed stage-two draw log; fail if a draw diverges from 108. Keep all run, cache and generated files on I:.

After the runner exits, evaluate only the new terminal checkpoint on the exact reused 108 synthetic DEV panel and the same separate coronal/sagittal weak-real DEV donors, using the same 14 blind candidates and physical plane/error definitions. Verify inherited step-653 model equality and compare section-paired/donor-equal results against frozen 108 steps 653 and 1,959. The diagnostic succeeds in identifying an unfreezing-specific coronal cost only if the heads-only branch retains coronal weak-DEV disagreement within 0.20 mm of step 653 while 108 step 1,959 remains worse, with the same stage-two draws. Assess synthetic best-of-14 and prior-selected gains and sagittal donor consistency explicitly; a coronal-only improvement is not a usable model. If heads-only also regresses, continued exposure/loss balance or weak-label inconsistency remains plausible. If heads-only retains real performance but fails to gain synthetic coverage, the shared-feature update needs a retention constraint or better physical oblique supervision before expanding training. No sealed real holdout, final animal, uncertainty calibration, GUI replacement, or public benchmark is used here. A reused-DEV result cannot establish final generalization or the required fit-to-coordinate feedback.
