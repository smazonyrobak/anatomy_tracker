# 067: blind normal-fixed atlas-image search pilot

The 066b truth-only restricted similarity oracle showed a 338 µm best-of-14 geometric ceiling, but does not show that image evidence can find it. On a frozen deterministic 32-section exploratory subset (four per synthetic identity, chosen without CCF truth) of the already reused 061 panel, take the 059 top-eight-old/top-six-anchor candidate normals and search a finite-thickness atlas image for normal offset plus in-plane translation, roll, reflection, and isotropic scale. Score only the input image and atlas-rendered intensity/support with contrast-sign-invariant, support-weighted high-pass normalized correlation. Use no synthetic targets in search, no learned new weights, no prior pretrained model, and no tissue mask unavailable at inference. Keep source/provenance hashes. Evaluate physical error with synthetic CCF truth only **after** blind selection.

This is an exploratory pilot, not a training or final-test evaluation. The advance signal is a ≥300 µm identity-equal improvement in blindly selected error from the same 059 candidates, with best-found-of-14 ≤1 mm and no severe collapse in raw-background inputs. If not met, report separately whether the searched candidate pool still contains low-error solutions (score failure) or whether the grid/search itself misses the 066b oracle (search failure). No model promotion, GUI change, calibration or public benchmark from this pilot; a successful pilot must be confirmed on a fresh synthetic development panel and weak-real donor guardrails.
