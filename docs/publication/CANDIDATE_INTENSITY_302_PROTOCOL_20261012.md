# Frozen protocol — anatomy signal inside the 299 candidate beam

Candidate 301 found strong synthetic atlas intensity correlation even at the 299 ranker's 48-pixel sampling scale, but compared the true plane to the blind proposer's first choice rather than hard support-matched candidates. Candidate 302 is a no-training, diagnostic read of the already frozen 299 TRAIN-inner panel. It does not provide new independent validation and cannot itself promote a model.

- Use exactly the 49 predeclared near/far pairs from the 64-case 299 panel, whose atlas-support masses were matched and whose rigid-site errors differ. Do not change pairs, beam, images or atlas banks.
- Replay each recorded seed and virtual subject once only to recover the generator's intact, non-displaced, >95%-visible tissue mask. Confirm identity and bitwise input replay. Average-pool the observed image 4×4 exactly as 299 does. Define one fixed pair mask from fully intact 4×4 source blocks where *both* near and far central-depth atlas planes have >95% support. This oracle mask is a scientific information ceiling, not an inference-time input.
- For each candidate, divide the saved central-depth atlas intensity by its support and compute absolute Pearson correlation with the pooled observation on that identical fixed mask. The two candidates receive no extra translation, deformation or depth search. Record signed correlations and whether the near plane wins. Spatially permute each candidate's intensity inside the same mask 16 times as a negative control. Compare descriptive near/far results with the already frozen full and support-only learned ranker preferences.
- Save all row-level scores, masks counts, section IDs, provenance, hashes and summary on I:. Use only synthetic TRAIN-inner animals; no DEV/CAL/FINAL, public benchmark, pretrained weights/features/pseudolabels, new training or GUI change.

If the direct score wins ≥35/49 pairs with a median absolute-correlation margin ≥0.05, the hard beam contains recoverable atlas-intensity signal under oracle tissue masking; the next architecture step should build a practical image-derived reliability mask and teach the shared pose/deformation model to use intensity agreement and warp cost. A weaker result would prioritize examining local residual deformation, contrast variation and ambiguity before scaling another ranker. Either way, a pair-specific oracle tissue mask and reused panel prohibit deployment or scientific performance claims. Steep-oblique synthetic QC and physical-oblique animal validation remain separate requirements.
