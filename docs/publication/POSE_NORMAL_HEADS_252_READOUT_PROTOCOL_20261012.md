# 252: same-case independent v7 normal-head readout

After the independent eight-plan 248 v7 synthetic DEV panel has a completion receipt, evaluate four **frozen** checkpoints on every eligible section: selected 247 batch 6,000, and 249/250/251 batch 3,000. Never select a checkpoint using this panel. For each model choose the single largest image-only anchor mass, ignore the unsupervised reflection logit, and measure the antipodal normal-axis angle against the target atlas tangent state. Use the same input file for all four, average cases equally within synthetic plan and then plans equally, and report physical-cut-angle and visible-tissue strata. Record every case, provenance and hashes.

The 250 CE-only shared-query and 251 CE-only direct-head protocols already require last-500 TRAIN CE at least 0.5 below `ln(64)`; the 251 DEV criterion also requires at least 10 degrees better plan-equal normal-axis error than both 249 and 250. This diagnostic may identify relative learning even when those gates fail. It is not physical arbitrary-oblique validation, deformation evaluation, calibrated uncertainty, or a public benchmark; synthetic plans are all variants of one Allen atlas.
