# 098: the descriptor, not the decoder, is the main matching bottleneck

The frozen read-only diagnostic isolated the 097 failure. At the physically best fitted candidate, supported fine bins contain a correct tissue-to-atlas correspondence at 0.970 of atlas-available sites on the section-then-plan-equal readout, but the learned descriptor's raw top-1 bin is correct at only 0.536. The operational atlas-support penalty changes that to 0.536, and the existing local-softmax verifier **improves** it to 0.609. All remain below the unshifted fitted-plane coordinate at 0.892. Therefore changing the penalty or decoder alone is not the priority; the anatomical features need to rank the correct correspondence above hard alternatives. This does not prove that a new feature design will succeed.

The oracle ceiling is lower for non-best candidate planes, so candidate geometry still matters. For the best plane it is high enough that a missing local search window cannot explain the ≈0.36 raw-top-1 versus centre deficit. A site can have a supported positive but the descriptor often scores a wrong bin higher. The support penalty changes best-plane top-1 correctness by less than 0.001; local softmax gains ≈0.073 over penalized top-1, so it is not the cause of the remaining deficit. The 097 descriptor yields modest top-1 gains over step 0, but not enough to justify merging it into pose feedback.

**Decision:** keep the 094 checkpoint as baseline; neither adjust the decoder on this DEV panel nor promote 097. The next frozen intervention should strengthen the matcher’s anatomical context and train for hard positive-versus-hard negative ranking, preserving the same scratch-only model lineage and candidate geometry. First require a substantial physical-match gain over the unshifted plane on fresh synthetic development sections, then evaluate whether the *full joint model* improves selected pose and mapped tissue error. Only after that is promising should animal-disjoint real development, uncertainty calibration, GUI integration and the eventual public DeepSlice comparison proceed. The synthetic plans are not independent animals and these fractions do not establish deployable accuracy.
