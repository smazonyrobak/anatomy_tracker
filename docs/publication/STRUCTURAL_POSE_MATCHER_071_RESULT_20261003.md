# 071 scratch structural matcher: exact-candidate success, blind-bank failure

The 3,000-batch run finished normally. It used 9,000 distinct eligible synthetic TRAIN section draws across all 64 independent deformation bases; 880 extra draws were rejected as insufficiently visible. Each accepted section had one independently sampled plane/appearance/artifact realization, not paired background copies. Source hashes matched the committed code, and the immutable draw log preserved animal, specimen, experiment and section lineage. The checkpoint was selected using 48 eligible sections from eight synthetic-development identities disjoint from TRAIN, not real animals.

On that development bank, each image had **the exact observed affine pose among eight candidates**. The best checkpoint (batch 3,000) selected 44/48 exact poses and had 0.062 mm mean selected five-point error (raw 0.156 mm, black approximately zero, imperfect brush approximately zero). The random-order expectation was 4.286 mm, inflated by deliberately far wrong candidates. This establishes that the network can recognize an explicitly supplied correct synthetic pose in a relatively simple bank; it does **not** show that it can find an unknown atlas plane.

The pre-registered second readout used the frozen 069 blind search bank on 32 different sections of the same eight synthetic-development identities. The learned score selected **3.581 mm** identity-equal physical error, versus **2.311 mm** for the 059 image-prior choice and 3.272 mm for 069 MIND selection. Raw sections worsened from 3.008 to 4.499 mm; black worsened from 1.236 to 3.181 mm; imperfect-brush worsened from 2.996 to 3.661 mm. Only 9/32 blind selections were below 1 mm. The truth-only best-geometry pose scored higher than all 14 blind 069 candidates in 20/32 cases, but that pose was not offered in the blind selection. The pre-registered advancement gate failed.

Thus a matcher trained on perturbed known poses can look excellent when the answer is in its bank, while failing to select the best poses a blind search actually produces. This separates **candidate correction/capture** from fixed-bank discrimination. It is also consistent with the caution that image similarity is not a reliable anatomical-registration accuracy surrogate ([Rohlfing 2012](https://pubmed.ncbi.nlm.nih.gov/21827972/)). The literature supports learned cross-modal structural representations ([Casamitjana et al. 2025](https://www.nature.com/articles/s41586-025-09708-2)) and MIND-style descriptors ([Heinrich et al. 2012](https://pubmed.ncbi.nlm.nih.gov/22722056/)), but neither result proves a score-only search can recover arbitrary-plane mouse histology here.

**Decision:** do not insert the 071 matcher into the GUI or claim a better model. A targeted next experiment must train an image–render-conditioned **physical pose correction** on both random perturbations and the current model's wrong proposals, then test whether corrected blind candidates beat the 059 prior. Its fitting signal must subsequently affect the coordinate predictor in the same joint training graph; another fixed reranker would not satisfy the core goal. Real-animal reference accuracy, calibration, electrode-region probabilities and the public DeepSlice comparison remain untested.
