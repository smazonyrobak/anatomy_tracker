# 223: matched-draw anchor-conditional ranking ablation

Question: the 221 framed pose model sometimes has a physically good anchored candidate but assigns it a low rank among the 64 normal anchors and their two reflections. Does explicitly teaching the *relative ranking within that anchor family* improve selection without degrading global pose or candidate coverage? This is a bounded TRAIN-only ablation, not a model promotion or benchmark.

Both arms start from the identical 221 framed step-400 checkpoint (`572d3719e1d62ce36e43bb34e9853c0579c5b88a09c4cd3ee4f073d51628ec2d`) with fresh, identically initialized AdamW states and the same random seed (`20261011223`). Both run 400 updates and save steps 0/200/400. They use the existing batch of three independently drawn synthetic sections, one Lupori TRAIN section, and one alternating older TRAIN coronal/sagittal weak-reference section per update. The two new-geometry synthetic sections use 166→217 support-aware framing and v4/v3 artifacts; the third uses legacy v7→v4. The sampler never deliberately creates paired artifacts from the same section; chance collisions are not rejected. Both arms use the same draws and optimizer schedule: pose/anchor learning rate 2e-5, encoder/lateral 5e-6, weight decay 1e-4, cosine decay to 20%, and gradient clipping at 5. AL1A is excluded from gradients. No DEV/CAL/FINAL, public benchmark, **external** pretrained weights/features, or pseudolabels enter the experiment; the parent belongs to this project's randomly initialized lineage.

For each of the three synthetic sections, use the trainer's existing exact-affine physical cost `c_k` in mm: 0.75 tissue-site error + 0.25 five-point error + antipodal normal penalty. The first 32 branches are the 16 free modes with two reflections; branches 32–159 are 64 anchored modes with two reflections. Let `a_k` be the existing log score including reflection for the 128 anchored branches only. The intervention adds

`0.5 × mean_slices KL(softmax(−stop_gradient(c_anchor) / 0.7 mm) || softmax(a_anchor))`.

The conditional softmax is normalized **only over the 128 anchor/reflection branches**. Its target costs are detached, so this extra loss teaches the anchor-family scores, not the geometry by moving candidates toward the target. The existing global synthetic, Lupori, and old-real losses still train the same pose and shared image features. The control adds zero. This isolates the conditional ranking signal; no architecture, sampling, or optimizer change is part of the intervention.

Compare both arms at 0/200/400 using the same frozen 221 framed, unframed, and legacy TRAIN-inner cases, the same independently seeded fresh framed TRAIN-inner cases, and the same AL1A and older coronal/sagittal TRAIN weak-reference guards. Step 400 is the primary comparison; step 200 is diagnostic, not a checkpoint to cherry-pick. Define within-anchor success for a case as the anchor/reflection branch with the highest conditional score having exact-affine error <2 mm, and report the denominator of cases whose best anchored branch is <2 mm. The pre-pinned gate requires more within-anchor successes on the fresh panel than control, with the frozen framed panel agreeing in direction. Global framed top-1 median affine and dense error must not increase on either panel; best-of-160 median affine and dense error must not increase; top-16 <2-mm capture must not decrease. AL1A and older TRAIN donor-equal weak-reference medians must not increase. Report base-versus-anchor top-1 counts and anchor mass to detect a ranking gain caused by collapsing global selection. A failure of any gate means no promotion.

This experiment uses TRAIN-inner evidence only. Even a clean gate pass does not establish real steep-oblique accuracy, calibrated uncertainty, GUI readiness, or superiority to DeepSlice; those require separate animal-level evidence and later benchmarking. All source, protocol, run, and model files remain on I:. The trainer records source/protocol/config SHA-256, sampled identities, training losses, checkpoint hashes, and completion receipts.
