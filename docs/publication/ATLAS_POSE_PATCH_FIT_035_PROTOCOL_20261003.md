# Atlas-conditioned direct-pose correction, diagnostic 035

This frozen synthetic development diagnostic tests the missing causal premise before training another updater: does an atlas render at the *correct* plane produce stronger cross-modal patch evidence than the actual eight direct proposals, can that evidence select a lower-error proposal, and does its **differentiable gradient actually point toward lower physical error**? The prior 026 diagnostic already found weak ranking with a different local-best-patch score, so the gradient question is the main new evidence here. It uses scratch-trained frozen 019 direct pose and 025 cross-modal patch models. They are distinct components at this stage; this is **not** a joint trained model.

Take three eligible pre-existing DEV sections per each of eight synthetic deformation identities, sorted by input SHA. No panel image or pose is used to set model weights or a bank. For each section, score the prior top-eight pose/reflection candidates at a fixed 3×3 raster grid of 64×64 patches. Use finite-thickness atlas rendering at each candidate and mean diagonal cosine of normalized 025 observed/atlas descriptors. Add the known plane only as an **oracle diagnostic**, never as an inference candidate. Compare descriptor-selected rigid full-tissue error with the original direct-prior top-one and best-of-eight oracle error. Synthetic truth and validity masks are used only for endpoint calculation.

For each case, take the derivative of this score with respect to a bounded nine-dimensional local SO(3), translation and in-plane-basis update. Probe the prior top-one, the oracle-best of the eight proposals (diagnostic only), and a known plane perturbed by 0.1 rad and 1 mm. Compare descriptor-ascent direction with physical-error-descent direction in the same normalized update coordinates, then apply one 0.02-norm step and measure physical error. A valid gradient is more than a nonzero number: it should lead to better coordinates.

Predeclare a necessary gate: mean descriptor-selected rigid error must beat the original top-one by at least 250 µm; the exact-plane score must exceed the median wrong-candidate score in at least 70% of sections; and a descriptor-gradient step must improve prior-top-one physical error in at least 60% of cases. A failure means the current patch descriptor and fixed spatial evidence are inadequate for a direct fitting-feedback updater as proposed; do not train the same updater unchanged. Passing would justify an on-policy trained differentiable update and later joint pose/deformation continuation, not deployment or an accuracy claim. Preserve animal/specimen/experiment IDs. Do not use final-test animals, DeepSlice benchmark, or numerical uncertainty claims here.
