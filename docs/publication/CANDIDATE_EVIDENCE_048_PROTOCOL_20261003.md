# 048 candidate-evidence ranking pilot (pre-result protocol)

047 proved that atlas fitting sends gradients to predicted pose but that a low match residual is a poor test of physical correctness. Its best-of-four error remained near 1.1 mm while selecting a branch cost about 2.5 mm. This pilot directly tests whether *several* inference-available observations jointly identify the correct branch: 019 prior and atlas-fit score, 046 match concentration, 3D fit residual, fit energy, local warp size/roughness, visible-correspondence confidence, and pose movement. No truth, manual tissue mask, target plane, or donor ID enters the ranker.

Freeze the scratch 019, 041 and 046 model weights; restart from the good 019 checkpoint rather than the failed 047 pose-head continuation. For each of 1,000 newly sampled eligible arbitrary-plane synthetic TRAIN sections, generate eight pose/reflection candidates, fit and warp each, compute the eleven candidate observations, and train a new randomly initialized 11→32→1 selection head using the synthetic CCF mapping error only as the training target. Preserve each physical draw's provenance, one independently randomized appearance per plane, and checkpoints at batches 0, 500, and 1,000. This trains candidate selection, not more 047 pose updates.

Compare the three ranker checkpoints on the unchanged, animal/identity-disjoint 037 synthetic DEV panel. Report equal-identity selected mapped error, physically best-eight diagnostic error, raw 019 prior top-one, previous 047 fitted-score selection, and raw/black/imperfect-brush strata. The predeclared internal promise gate is ≥20% selected-error reduction relative to both prior and previous fitted-score selection, absolute selected error ≤1.5 mm, and no appearance stratum >10% worse than prior. Reused synthetic DEV identities support architecture selection only, not independent confirmation; if this gate passes, build a *new* synthetic identity holdout before promoting or unfreezing the joint model. No public benchmark, real final-test animal, calibrated probability, or GUI deployment is involved.
