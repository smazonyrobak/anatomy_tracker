# 061: contextual 2D-to-3D matching on actual pose proposals

The frozen 019 image predictor remains the research reference, not a deployable result. The 059 anchor continuation supplies additional arbitrary-plane proposals but failed to select them reliably; the 060 fitted scalar scorer failed as well. The 039–046 studies found that correct 3D locations usually exist in a proposal-centred search volume, whereas independent local descriptor scores, sharper softmax, robust fitting, and per-patch sub-grid regression did not make the selected pose accurate. The 041 "global" matcher gave each image point 2D self-attention and each atlas key 3D convolutional context, but **the image points and atlas keys never exchanged context before their independent dot-product scores**. The 045–046 patch matchers also scored each tissue point separately. This is the narrow structural gap tested here; it is not a claim that attention will solve histology registration.

Add bidirectional, candidate-conditioned exchange between all visible 2D image tokens and a coarse 3D atlas grid, then lift the candidate-conditioned key features back to the existing dense proposal-centred grid. Retain the same finite-thickness atlas samples and robust full-frame fit. The atlas location is the network's actual predicted proposal, never a supplied true plane at inference. Use synthetic observed-tissue-to-CCF point pairs to supervise matching; train with wrong, lookalike proposals as well as near ones. Keep a no-match/visibility output for damaged or unsupported tissue. The final intended system still needs fitting loss to update the **pose predictor**; this matcher-only pilot merely tests whether that feedback can become useful. If it cannot, do not unfreeze or scale the joint model.

Use only independent, newly drawn synthetic TRAIN sections and donor-disjoint weak-affine real TRAIN sections, with identifiers and source hashes preserved. Do not deliberately duplicate a physical section under different backgrounds. Use the existing randomly initialized project lineage; no legacy application model, external pretrained feature, or public benchmark label. Preserve raw, exact-black, and imperfect-brush variability without requiring a mask.

Freeze the development protocol before looking at model-selected results. On a newly generated synthetic-identity holdout, report: eligible truth-key availability, learned correspondence recall at 0.5 and 1.5 mm, full-frame fit error for every candidate, truth-best candidate, model-selected candidate, final mapped error, and per-appearance/visible-tissue strata. Compare directly to inherited 019/041 and 059 predictions on the same sections. On separate real DEV donors, report weak-Allen five-point disagreement and every donor's change; these are not expert labels. Include atlas-detached or shuffled-key evidence control to test whether the improvement truly uses atlas anatomy. A checkpoint advances to joint pose/warp training only if the matched synthetic selected full-frame error falls by at least 0.25 mm, truth-best-of-beam error falls by at least 0.20 mm, and no real DEV donor's weak-reference error rises by more than 0.20 mm versus the matched parent. Report the fixed 0.5-mm correspondence score as a precision check, but do not promote on point recall or lower training loss alone. Do not choose a checkpoint on public data.

No numeric probability claim, GUI replacement, or DeepSlice comparison follows from this pilot. Independent expert animal-level validation, calibration, constraints, and deployment remain separate required work.
