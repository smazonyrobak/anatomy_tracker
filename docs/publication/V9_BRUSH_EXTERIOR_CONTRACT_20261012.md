# V9 synthetic exterior contract

The existing GUI input path multiplies the image by an optional smart-brush mask, leaving exact zero outside the brush. V8 independently added gray or near-black exterior even when the brush-available channel was set, creating a train/inference contradiction. V9 keeps the same independently drawn v7 physical plane, damage and tissue pixels, but enforces exact zero outside an available brush. When no brush is supplied, each section independently samples exact-black, near-black or gray exterior. It never generates paired appearances of one physical section. The probabilities are broad TRAIN-only variation, not a measured laboratory prevalence.

V9 does not alter the frozen v8 pose-capture 268 run. It has only a syntax check so far; synthetic-image QA and acquired TRAIN appearance comparison are required before using it for a large run. This fixes input semantics, not the larger evidence gap: the current full-sphere generator renders a single smoothed Allen population template with synthetic deformations, while acquired TRAIN sections contain richer texture and do not supply trusted steep-oblique pose ground truth. Any claim of physical arbitrary-plane accuracy still requires animal-disjoint, genuinely oblique acquired validation.
