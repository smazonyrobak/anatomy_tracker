# Global atlas-point proposal 024 — frozen result and correction

The independent verifier passed: 3,000 training batches, 6,000 accepted fresh TRAIN sections (618 rejected by the existing eligibility rule), 192,000 point pairs, and four checkpoint evaluations on 185 sections from eight disjoint synthetic-development deformation plans. Accepted background modes were 1,953 raw, 2,039 exact black, and 2,008 imperfect brush. The bank contained 100,000 fixed, truth-independent atlas-support positions on a 100 µm lattice; every sampled DEV truth point had a bank position within 250 µm. Source, atlas, draws, checkpoints, panel identities, full raw retrieval indices and summary hashes are bound in `I:/AnatomyTracker/runs/atlas_point_proposal_024` and `I:/AnatomyTracker/runs/atlas_point_proposal_024_development_eval`.

Results are equally averaged over synthetic identities. The predeclared ≥20% 0.5-mm point recall and ≥50% three-match gate **failed**. Loss averaged 4.006 in the first 500 batches versus 3.720 in the last 500, while within-batch paired top-1 rose from 2.70% to 4.66% (random 1/64 ≈1.56%). There is weak learning, but nowhere near reliable global identification. More training with the same representation is not justified by these curves. The 019 checkpoint remains the best available **development** model, itself far from deployment quality.

The method mismatch is now clear from a closer reading of [Brandstätter et al., WBIR 2024](https://arxiv.org/html/2410.18683v1): their successful SLIV-Reg method does **not** compare one 2D patch descriptor with one orientation-invariant 3D cube descriptor, as 024 attempted. It extracts *many oriented 2D atlas patches* from each 3D cube, embeds them with the same rotation-equivariant 2D network used for the query, and uses robust geometric consensus. Their experiments used roughly 150–700 orientations. Their CT/MRI query and reference are from the **same subject**, unlike our distorted histology to a population Allen atlas; reported accuracy cannot be transplanted. [CoMIR, NeurIPS 2020](https://papers.nips.cc/paper/2020/hash/d6428eecbe0f7dff83fc607c5044b2b9-Abstract.html) supports learning a common 2D representation with modality-specific encoders for disparate biomedical contrasts. 024's arbitrary cube-axis flips discarded the actual section-plane appearance; weak 2D/3D matching is consistent with that mismatch, though this causal explanation has not itself been experimentally proven.

Next targeted experiment: render **finite-thickness 2D atlas patches at the known plane** and train a cross-modal 2D descriptor against fresh synthetic query patches. First test retrieval *within that known atlas plane* on disjoint DEV identities. This explicitly isolates the modality/appearance problem from the unknown-orientation search. Only if it passes should we incur a many-orientation 3D atlas search and RANSAC pose consensus. That search plus the existing warp/refinement must still be combined into one trainable checkpoint and judged on final pose/deformation accuracy, real donor-separated data, and later calibrated electrode probabilities. No public DeepSlice benchmark, expert final-test animals, calibration or GUI deployment has occurred.
