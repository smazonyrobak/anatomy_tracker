# 043 pre-run mechanism test: robust consensus on frozen 041 correspondences

042 showed that retaining only the four strongest or single strongest atlas keys improves the best available synthetic plane by just 0.04 mm, not the predeclared 0.20 mm. 041's prior-best-eight correspondence recall within 1.5 mm reaches 75%, however. The remaining hypothesis is that a minority of bad matches still corrupts the weighted least-squares fit. Test that hypothesis once with a robust geometric consensus estimator, as in [SLIV-Reg](https://arxiv.org/html/2410.18683) and [2D3D-MATR](https://openaccess.thecvf.com/content/ICCV2023/papers/Li_2D3D-MATR_2D-3D_Matching_Transformer_for_Detection-Free_Registration_Between_Images_and_ICCV_2023_paper.pdf), without training or changing the matcher.

Use the frozen 041 batch-1,500 top-eight logits and hard highest-logit 3D key for each of 256 query cells. For each candidate, draw 128 fixed-seed four-point hypotheses from its predicted confidence distribution. Fit each minimal 2D chart→3D affine frame with a weak prior ridge (0.05), score consensus by confidence-weighted inliers within 1.5 mm, and refit the best consensus with the original 041 ridge (2/1/1) and its inliers. Compare raw consensus and the unchanged learned 041 correction-gate blend against the 019 prior and original 041 soft fit. No truth, image mask, or reference affine enters consensus fitting. No parameter, seed, or checkpoint sweep after results.

Use the same frozen 177 eligible synthetic development sections from eight deformation identities and 64 weak-real development sections from six donors, as **mechanism diagnosis only**. Verify the new script independently, report identity/donor-equal physical top-one and oracle-best-eight errors, near-true cases, appearance strata, and worst weak-real donor regression. This is a positive direction only if synthetic best-eight improves by ≥0.20 mm relative to 019 while top-one worsens by no more than 0.20 mm; the weak-real comparison must be reported separately. Failure should stop fitting-rule tweaks and redirect work to the learned matching representation and candidate ranking. No public or untouched final benchmark is opened.
