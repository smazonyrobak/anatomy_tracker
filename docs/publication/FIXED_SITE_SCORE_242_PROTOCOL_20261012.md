# 242: fixed-site ablation of the learned 3-D matcher

The 240 development mechanism check found that optimizing its top-64 score worsened known-true physical-site error from 0.187 to 0.425 mm. A plausible, testable failure mechanism is the score's `−1` fill for unsupported sites: a candidate can score better simply by gaining atlas support. In the 32 development cases, 15 known-true hypotheses started with fewer than 64 supported query sites, and all 17 accepted intact known-true updates gained supported sites. A separate 3.5–4-pixel feature/label lattice error also exists. This ablation isolates **only the score-support selection defect**; it deliberately keeps the frozen 240 descriptor weights and query lattice unchanged. It cannot establish final-model quality.

Use the exact 240 best checkpoint (`cc55572e3c5e81085eec0c3e2351e9638d9a4f1dc6592b065996200201e55fad`) and its exact 32-section validation manifest. Regenerate each recorded physical image and verify its ID and input hash. Evaluate the known-true diagnostic pose and the truth-nearest reachable member of the *blindly proposed* top-16 beam if one is within 2 mm. For every role, render the same finite-thickness 17-plane bank and evaluate intact atlas intensity and the existing support-preserving shuffle. Freeze the IDs of atlas-supported source query sites at the start of each arm. The score is the mean cosine over **those same IDs with a constant denominator**, with no top-k selection, missing-site fill, or variable support reward. Retain a trial only if every frozen site remains atlas-supported. Use the same 24 Adam updates, 0.12 learning rate, 2.5-mm five-anchor cap, geometrically valid affine plane, and no-shift option as 240. Do not tune these after viewing results.

Record each case's initial and fitted physical tissue-site error, score, accepted update, frozen-site count, and any site-loss rejection. Report all/v4/v7 means and intact-versus-shuffle paired differences. The ablation is **promising as a mechanism** only if, on these same development cases, mean known-true error after intact fitting is ≤0.20 mm, mean near correction is ≥0.25 mm, and the intact near fit beats shuffled intensity by ≥0.15 mm. If any condition fails, do not continue training 240 unchanged and do not use this score as the pose-feedback mechanism. Passing these same-panel criteria would justify a new correctly centred, randomly initialized successor and independent TRAIN-inner validation; it would not justify GUI integration or a real-animal claim.
