# Frozen 143 correspondences do not yet give useful anatomical pose correction

On the same 491 synthetic DEV sections used for the direct-map baseline, a fixed confidence-weighted Huber fit aggregated the frozen 143 field's predicted tissue-to-CCF points into one affine cutting plane. The fitter saw no synthetic truth. It used only valid, non-dustbin source sites, then measured physical rigid-plane error at all valid pixels. Both the atlas-intensity-plus-support field and its separately trained intensity-zeroed, support-only control received the same frozen truth-best 132 blind-beam candidate for each section. This is an oracle candidate-availability diagnostic, not a deployable selection method.

For candidates initially within 1.5 mm of the true plane, an affine fit was possible in 149/179 v4 cases for each arm, 170/197 v3 cases for full anatomy, and 174/197 v3 cases for support-only. On the *paired cases fitted by both arms*, mean improvement was only **30 µm full versus 38 µm support-only** for v4 (142 cases), and **44 µm full versus 54 µm support-only** for v3 (165 cases). The eight-plan, arm-specific means in the frozen summary are similarly small but should not be compared directly because the fitted subsets differ. Normal-angle medians did not meaningfully improve. The support-only control is at least as good, so these learned correspondences offer no evidence of useful internal atlas anatomy for pose correction.

This rules out promoting the current 143 field or its fixed weighted-Huber aggregation as the fit-to-pose feedback mechanism. It does **not** prove that correct minority matches could not be recovered by a different robust consensus method, or that arbitrary-cut histology is intrinsically unidentifiable. The more important obstacle is a cross-modal anatomical matching signal that survives support-only controls, coupled to the direct pose and local map in one training lineage. Do not treat small rigid gains or exact-pose mapping as a solution to blind branch selection. No real physical oblique animal, probability calibration, GUI model replacement or public benchmark was involved.

The run used eight reused synthetic DEV deformation plans, not eight biological brains, and retained per-section provenance.
