# 070: existing learned atlas matcher is not a drop-in search scorer

The frozen 059 learned atlas matcher **failed** the predeclared fixed-bank control on 32 synthetic development sections/eight identities. With pose-mixture priors neutralized, the truth-fitted best-geometry transform beat 069's blind decoy in the same branch on 19/32 sections, but beat **all** blind decoys in only **10/32** (gate ≥16/32): exact-black 2/12, imperfect-brush 7/11, raw 1/9. Ranking the frozen 069 blind solutions by this matcher selected **3,958.2 µm** identity-equal physical error, worse than the 059 baseline **2,310.9 µm** and the already-rejected MIND search **3,272.3 µm**. The existing head should not be dropped into broad arbitrary-pose search.

This is consistent with its training distribution: the atlas matcher was learned for the model's predicted candidate branches, then frozen when the 64 new normal anchors were introduced; it did not see the large translation/roll/scale hard negatives optimized by 069. The result supports learning a structural correspondence metric with explicit hard negative poses, or a different jointly trained pose/warp feedback mechanism, rather than reusing this frozen head. It does not establish that any particular new architecture will succeed. No model or GUI was changed.
