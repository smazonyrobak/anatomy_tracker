# 062: does the current image encoder retain arbitrary-plane orientation?

061 failed: 6,000 batches of candidate-conditioned atlas matching lowered its training correspondence loss but reduced unseen-identity fine correspondence recall and did not improve selected full-frame pose. The truth-best of 14 available planes is about 1.02 mm; selecting one remains about 2.66 mm. An additional fitting/ranking head is therefore not the next useful change. This diagnostic asks a more upstream, falsifiable question: **can the frozen, scratch-trained 059 image encoder distinguish the correct antipodal plane normal at all?**

Train only a compact normal readout from its 4×4 global feature map. Use the existing 64 fixed antipodal normal anchors, hard nearest-anchor supervision, fresh independently sampled arbitrary-plane synthetic sections, and the same raw/exact-black/imperfect-brush variation. No true atlas plane or synthetic identity is supplied at inference. The encoder, pose head, local mapper and atlas remain frozen. This is an information probe, not a proposed final head or a calibrated posterior. Record every accepted/rejected synthetic physical section ID and complete run hashes. No real weak affine is used as orientation truth.

Before evaluation, fix the readout to checkpoints 0/1,000/3,000/5,000 on the existing 061 identity-disjoint synthetic panel, measuring antipodal-normal MAP angle, top-eight normal angle, fraction within 15° for both, and appearance/visibility strata. Compare with the unchanged 059 top-mass and top-eight normals on exactly the same sections. This panel is already exploratory development data from 061; it is **not** an untouched final test. A normal-only continuation is worth building into the full pose system only if the readout improves MAP angle by at least 10° and top-eight-within-15° coverage by at least 15 percentage points without a collapse in any appearance mode. Otherwise, orientation information is missing from these features or this readout cannot extract it; training another pose scorer or more local warping would be unfounded. Success still would **not** establish AP/ML/DV position, roll, in-plane scale, tissue deformation, real-animal accuracy, or calibrated region probabilities.

This separation is motivated by [DeepSlice](https://www.nature.com/articles/s41467-023-41645-4), which uses a large CNN and substantially more coronal training data for direct plane regression, and [AMBIA](https://link.springer.com/article/10.1007/s12021-023-09632-8), which decomposes near-coronal localization into approximate AP and local quadrant evidence. Neither solves arbitrary-plane single-slice pose. [Rotation-equivariant 2D/3D matching](https://arxiv.org/abs/2410.18683) offers a more expensive alternative if the present encoder lacks orientation information, but its same-modality CT/MRI results cannot be copied to histology. The immediate test is the cheap readout probe, not a commitment to those architectures.
