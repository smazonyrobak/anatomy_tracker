# Physically sagittal Allen TRAIN pilot

`training/acquire_allen_sagittal_train_pilot_001.py` acquired eight small official Allen ISH JPEGs, four each from donor 5331/Pdyn and donor 8884/Adora2a. The complete TRAIN-only output is `I:/AnatomyTracker/data/allen_sagittal_train_pilot_001_20261008_run2`; raw bytes are not in Git. Exact donor, specimen, experiment and section IDs, original URLs, Alignment2d/Alignment3d fields, native dimensions, section thickness, source/derived hashes and the six excluded DEV donor IDs are recorded in `manifest.json` and `receipt.json`. Manifest SHA-256 is `787d629e4323ea71dab89dba261cc1331fa040350ba4d3cca504837722ac647b`; the separate receipt SHA-256 is `6fbb6ea848528592bad8d43a27694a668435a83f09f4ad3f53e4ce0974638735`. Independent read-back verified manifest hash, eight images and zero donor overlap with the frozen six-donor DEV cohort. A failed first metadata-only output directory remains untouched; `_run2` is the complete pilot.

These are **physical sagittal sections**, a real orientation missing from the near-coronal Product-5 TRAIN images. The geometry is still Allen's automated alignment, not independent expert truth. It is useful for a bounded cross-orientation appearance/weak-pose experiment, not certification of arbitrary steep-oblique accuracy or of dense tissue deformation. The sagittal source uses reference space 10; the saved official transform ID 2 maps to Product-5/CCF reference space 9 by `(x9,y9,z9)=(x10,y10,11350−z10)` µm. The official `image_to_reference` point for section 69750516 matched the locally composed SectionImage Alignment2d and experiment Alignment3d within `9.1×10⁻¹³` µm. Downsample-four image pixels must be mapped back to native pixel centers as `(p+0.5)×16−0.5` before applying that geometry.

One visual QC of section 69750516 found a pale, nearly white brightfield background and fine cellular texture. The currently displayed v2 synthetic artifact grid is predominantly dark-background grayscale with smoother atlas-derived tissue. This single image is not a population statistic, but it exposes a concrete modality/background gap: a training mixture must either vary polarity and exterior brightness independently per new section or use a documented canonical inversion for brightfield, then demonstrate real-donor retention. Do not treat the eight new images as sufficient to fit that choice.
