# 065: pose-specific visual features for coupled plane hypotheses

The 061 contextual matcher, 062 frozen-feature normal readout, and 063–064 factor/recombination audits did not fix the missing complete-plane proposals. The 059 branch learned full visible-tissue 3D pose targets but could not change its image features; the earlier 058 branch changed the shared image features with a normal-dominated target. This pilot changes that one intersection: copy the randomly initialized project lineage's 059 encoder and lateral pyramid into a pose-specific branch, then train that branch and its 64-anchor full-pose head jointly. The old 16-mode image encoder, pose head, atlas-conditioned local mapper, candidate fitter and ranker stay frozen as a control. At inference this remains one image-to-probabilistic-plane-and-local-map network; the extra image branch is internal, not a second deployed model.

Train 8,000 batches of two independent eligible synthetic plane draws and one unique within-run real TRAIN section per batch. Synthetic supervision uses the observed 3D tissue-to-atlas map and full reflected plane, not just angle. Real sections use inherited weak Allen five-point affines and are not arbitrary-plane ground truth. Keep training-only truth-guided candidate fit separate from inference. The atlas rendering and fitted-map loss still backpropagate to the anchor pose, while the old mapper and scorer remain frozen. Retain exact source, data, specimen, experiment, section, draw and checkpoint provenance. All inputs and outputs reside on `I:`; no external pretrained weights, original GUI weights, pseudolabels, public DeepSlice evaluation, probability calibration or final-test animals are used.

After process exit, evaluate frozen steps 0, 3,000 and 8,000 on the *already used exploratory* 061 identity-separated synthetic panel (246 eligible sections from eight synthetic appearance identities) and 64 separate weak-real DEV sections from six donors. Use the same old-top-eight plus anchor-top-six reflection-expanded beam for every step. The predeclared advancement gate is identity-equal best-of-14 visible-tissue rigid error **≤0.770 mm** and selected visible-tissue rigid error **≤2.400 mm**, compared with the 059-parent 1.022/2.656 mm, without >0.200-mm weak-real donor-equal regression or collapse of raw, black and imperfect-brush strata. This is a development gate, not proof of biological generalization. If only proposal coverage improves, work on selection without promoting the entire model. If it fails, stop this branch rather than extending exposure on training loss alone. Any success must subsequently be checked on fresh synthetic identities and genuinely held-out biological animals before calibration, GUI replacement or public benchmark.
