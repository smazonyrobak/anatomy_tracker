# 295: can the image itself drive a smooth exact-plane map?

The 294 balanced multiscale matcher failed despite a positive true-coordinate image/atlas signal in 288 and a 0.137-mm smooth-control coordinate-oracle gain on a different 281 panel. Before training another matcher, isolate whether a spatially coherent deformation can be recovered by **image evidence alone** at the known synthetic plane. This is a bounded TRAIN-inner registration diagnostic, not a shippable model, blind-pose result, or use of synthetic truth at inference.

Freeze 32 new independently drawn eligible v9 physical planes with at least 512 surviving valid pixels, four per synthetic TRAIN base 56–63, disjoint in physical-section ID from all 281/282/286/287/289/292/294 panels and accepted training schedules. Select 512 distinct valid sites per accepted section by the established 281 linspace rule. Refit the same accepted v9 draw with postartifact gauge v1 (no second appearance or physical-plane draw) and use its robust post-artifact state for rendering and scoring. Preserve draw attempts, full animal/specimen/experiment IDs, gauge provenance, state/image/coordinate hashes, source/atlas provenance and exact code hashes. No deliberate reuse of any plane with only changed appearance. Do not inspect acquired DEV/CAL/FINAL, public DeepSlice material, or any output outside I:. Run at `I:/AnatomyTracker/reports/smooth_image_fit_295_001`.

For each case render one fixed finite-thickness 192×192 atlas intensity/support pair at the postartifact gauge v1 rigid plane. Compare the observed image to the bilinearly sampled atlas intensity divided by its sampled support (clamped below at 1e-4) under a 16×16 in-plane control field, upsampled to 192×192. Controls request at most `1000*tanh(logit)` µm per local component; zero the local through-plane component, project out the full-canvas affine component, and rescale the field to a maximum physical derivative bound of 0.35 as in 281. The image-only objective is `1−|weighted Pearson correlation| + 0.01×mean((constrained dense field/1000 µm)^2) + 0.01×mean squared second-difference(requested 16×16 controls/1000 µm) + 0.1×mean warped-atlas-support deficit on the fixed scoring mask`. The bending term uses second differences along both control-grid axes before upsampling, not near-zero second differences of the dense interpolation. Optimize only the control logits from zero with Adam at 0.1 for 120 updates; read out at 0/40/80/120 and select the lowest **image objective**, never the CCF coordinate error. Preserve selected fields or controls and per-case raw readouts for independent rerendering. Evaluate all 512 prespecified surviving-site CCF errors only *after* each image-only fit.

Use two matched mask arms on every physical section. The **privileged diagnostic** fixes its scoring mask before optimization from synthetic valid tissue intersected with rigid atlas support >0.9. The **inference-observable arm** fixes its scoring mask using only rigid atlas support >0.9, intersected with the user brush when present; if no brush is supplied, do not use synthetic visible/valid/fragment labels or infer a perfect outline. Both arms use exactly the same image and true plane. Report mask sizes, no-warp/fitted image objective and absolute correlation, surviving-site mean CCF error and gain, per-base gains, angle/tissue-support/artifact/brush strata, output field size/derivative, and any atlas-support exits. The privileged arm locates the segmentation-information ceiling; only the observable arm is a plausible component for later inference.

The descriptive gate for pursuing an image-loss/unrolled smooth-control model is privileged mean CCF gain ≥0.030 mm and observable mean gain ≥0.015 mm, each with at least six of eight base means positive and a lower selected image objective than at zero on at least 24/32 sections. If only privileged passes, prioritize an inference-valid tissue/quality weighting method. If neither passes despite 281/288, revisit the image objective and its local basin before scaling a learned model. This gate does **not** authorize GUI use, pose feedback, public benchmarking, calibrated uncertainty, or an arbitrary-physical-angle accuracy claim.

Smooth control grids and image-similarity registration are established strategies, but their success here must be measured rather than assumed ([Osechinskiy and Kruggel](https://pmc.ncbi.nlm.nih.gov/articles/PMC3335496/), [VoxelMorph](https://www.mit.edu/~adalca/files/papers/tmi2019_voxelmorph.pdf), [Casamitjana et al.](https://www.nature.com/articles/s41586-025-09708-2)).
