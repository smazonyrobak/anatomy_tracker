# 037: off-plane global-correlation pose feedback — frozen development protocol

The unchanged atlas-conditioned local updater failed the 036 pose-movement gate. This stage retains the standalone randomly initialized 019 image/pose/warp lineage, but trains a new shared pose-update head on **actual wrong top-eight proposals** as well as independently perturbed true planes. The head receives the source-image features, a finite-thickness atlas render and fit features at each proposed plane. Its 16×16 all-to-all image/atlas correlation gives each source location a possible distant atlas match, not just the old small same-position search window. It predicts a bounded full-frame residual update and a ranking-score residual. A same-width image-and-pose-only control is trained on the same sections, candidate poses, optimizer schedule and physical targets; its all-pair correlation is image-to-image and its extra channels contain image-only signals, with no atlas or candidate-fit information. The direct predictor and local deformation mapper stay frozen only for this diagnostic; success must be followed by training the same complete lineage jointly so fitting can change direct pose predictions.

Training is 4,000 batches of two independently sampled accepted arbitrary-plane synthetic TRAIN sections, one randomized appearance/background/artifact draw per distinct physical section. Each batch contains the current 019 prior top eight, three independent training-only perturbations of the known plane and the exact training-only plane. Both heads optimize observed-tissue spatial error and oriented-plane error on **each** candidate, a bounded full-frame residual toward the known synthetic global plane (including equivalent reflections), plus a score loss ranking corrected candidates by physical error. Local tissue differences remain in the separate observed-tissue target rather than being hidden inside the global residual. No external weights, original-GUI model labels, public benchmark labels, synthetic DEV planes or real DEV labels enter training. Log every accepted/rejected draw with its animal/specimen/experiment/section lineage; save step 0, 1,000, 2,000 and 4,000 with source and parent hashes.

Evaluation uses a new frozen synthetic DEV panel from eight deformation identities absent from training, 32 independently sampled planes per identity, generated before inspecting 037 predictions. Report equal-identity mean observed-tissue rigid error for the original top-one, corrected top-one, best-of-eight and score-selected eight; report candidate movement and antipodal plane-normal angle, not only score or loss. Retain the previously fixed 64 real images from six donor-disjoint DEV animals only as a **weak inherited Allen-affine nonregression check**; they are not expert truth. A read-only verifier recomputes metrics and hashes from raw rows. Neither calibration animals, final-test animals nor public DeepSlice benchmarks are used.

The pose-capture development gate is: atlas arm improves the **score-selected** error by at least **250 µm** and best-of-eight error by at least **200 µm** from frozen 019; at the selected checkpoint it beats the matched no-atlas control by at least **150 µm** on score-selected error; no real DEV donor's selected weak-affine mean worsens by more than **200 µm**. The unchanged first prior branch is still reported, but not a gate: in the historical frozen synthetic DEV panel it had the wrong discrete reflection in 80/185 cases, which a bounded single continuous rotation cannot generally repair. Selection among the explicit reflection alternatives is part of intended inference, while the best-of-eight movement requirement prevents claiming success from re-ranking fixed proposals alone. These criteria were set before the new 037 panel or model predictions were examined. Gate failure is reported without promoting the head or simply extending identical training. Gate success is not deployment readiness: after it, unfreeze the direct pose and constrained local warp for joint fitting-to-coordinate learning, assess independent real oblique labels and calibration, then package and test the existing GUI.
