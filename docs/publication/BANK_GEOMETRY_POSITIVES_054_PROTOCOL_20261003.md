# 054: train the patch descriptor against the atlas geometry it must search

053 measured a 21.01-point top-one recall loss when the exact oracle-warped atlas positive was replaced with the correct rigid plane, using the same frozen 025 model and synthetic DEV images. 052's whole-brain hard-negative continuation also failed. The next targeted change is the **positive example**, not another score head: only the observed tissue image carries the synthetic warp; atlas positives must be rigid patches of the form stored by the search bank.

Continue the complete scratch-trained 025 encoder and optimizer at lower learning rate for 5,000 fresh, independently sampled arbitrary-plane TRAIN sections, one appearance per section. At 16 surviving tissue points per section, use known training-only CCF coordinates to select the nearest fixed atlas-bank position and four bank frames closest to the physical image frame (flipping the image patch horizontally when necessary to use the bank's antipodal hemisphere). Render these four rigid, fixed-scale and fixed-PSF atlas patches as multiple positives. Mine 16 atlas-bank keys at least 1 mm away per point from the frozen 025 global descriptor bank and render those exact bank geometries as negatives. Optimize a four-positive-versus-16-negative contrastive loss. This uses no DEV/final/public image or model weights from outside this scratch lineage. It does not deliberately repeat a physical section with different background.

First evaluate checkpoints 0/1,000/3,000/5,000 on the **same rigid true-plane local control** as 053, without viewing images. The necessary small-bank gate is identity-equal rigid top-one recall within 0.5 mm ≥85% (053 baseline 75.20%) and exact-pixel key first ≥70% (baseline 59.67%), with no raw/black/imperfect-brush stratum below half the aggregate recall. Only if this passes should a new 2,061,824-key atlas-only bank be built and unknown-plane retrieval measured. Ultimately the 019 joint pose/map model must improve selected tissue-coordinate error; local controls and GT-valid query selection are not deployable inference. Probabilities remain uncalibrated and DeepSlice benchmarking/final-test animals remain untouched.
