# Bounded gross-pose continuation of the same joint model

The 019 image-only pose prior failed on physical sagittal ISH (63.77°/8.695 mm weak-Allen disagreement). A TRAIN-derived fixed contrast gain reduced disagreement but did not pass its mechanistic gate. The next controlled change is **physical sagittal TRAIN supervision in the same full joint model**, not a new pose-only application, a different network, a scaled synthetic-only run, or a fitted-score tweak. The parent is the internally scratch-trained 019 step-18,000 checkpoint (SHA-256 `70edfaa53fcd84a2d20be5a246948e17a7eeb0406e054cf65535e381f5895ab8`); no external pretrained weights, features or pseudolabels are allowed.

Freeze 653 optimizer batches before looking at new weak-DEV2 images. Each batch contains one of the **653 unique** new sagittal TRAIN sections from the frozen expansion (`40` donors), one distinct reserved coronal TRAIN section from a different donor (653 distinct donor selections if available), and two independently sampled full-sphere synthetic sections from the existing v7-64 source. No physical section is deliberately repeated in this stage; each synthetic draw independently randomizes its plane and appearance without a forced duplicate or black/nonblack pair, while chance similarity remains possible. The sagittal input has the same once-inverted whole-acquisition 256² preparation as the first cohort, followed by the one fixed global TRAIN-derived gain `4.259364821544654` and clipping. Coronal real input follows its original 192→256 preparation with no new gain. The four remaining channels are zero for real raw images. Synthetic state and dense labels remain from the existing source; its artifact limitations are documented. The new v2 slide-artifact source is **not** included because its stress-event rates are not calibrated.

Update only the existing joint model's image encoder and direct pose head (AdamW encoder `5×10⁻⁶`, pose `10⁻⁵`, weight decay `10⁻⁴`, gradient norm ≤5), keeping its mapper, atlas encoder, recurrent fitter and scorer frozen for this diagnostic. Use the inherited 16×2 full-pose branches and direct physical point/normal rank loss from 019, with each weak real sample weighted 0.5 relative to one synthetic sample. Synthetic planes retain full-sphere coverage; the sagittal labels are inherited Allen affines, not dense deformation truth. Save full-model checkpoints at batches 0, 326 and 653 with complete data/source hashes, schedules, RNG states and loss trace. Do not infer calibrated probabilities from branch scores.

After the run, compare all three checkpoints **once** on the same frozen 185 synthetic identity-separated DEV sections, 64 near-coronal real DEV sections from six separate donors, and all 159 newly reserved physical sagittal weak-DEV2 sections from eight separate donors. Evaluate direct selected pose and best predicted branch separately, using mapped-tissue error for synthetic and five-point weak-affine disagreement plus antipodal normal angle for real. Equal-weight animals/identities, not individual slices. Select a nonzero checkpoint only if relative to batch 0 it improves donor-equal sagittal selected normal by ≥20° and selected five-point disagreement by ≥2 mm, while worsening coronal five-point disagreement by at most 0.2 mm and synthetic selected direct-pose mapping by at most 0.25 mm. If no checkpoint meets every condition, retain 019 and investigate the specific failure before scaling. These are internal mechanism gates; no public DeepSlice benchmark, heldout weak-sagittal reserve, physical steep-oblique test, electrode probability calibration or GUI release is authorized by this protocol.
