# Off-plane atlas matching 026 — frozen result

The independent verifier passed on all 185 held-out synthetic DEV sections using the unchanged 025 batch-3,000 patch descriptor, unchanged 019 batch-18,000 pose model, and the independently verified 023 top-eight rigid errors. Atlas renders included the actual finite-thickness kernel. No weights were changed, no final-test animals or public benchmark were used, and checkpoint/panel/control/source/row hashes are bound in `I:/AnatomyTracker/runs/atlas_offplane_capture_026`.

The descriptor still recognized the **true rigid plane** despite withholding its local warp: its score exceeded every one of the eight predicted planes in 97.6% of sections (94.5% raw, 98.2% exact black, 100% imperfect brush). Its true-rigid atlas-point recall was 75.2% top-1 and 97.4% top-16 within 0.5 mm; local-window matched point error averaged 0.410 mm. Thus the exact warped-surface requirement was not absolute.

But that success does **not** provide a useful gradient among the present wrong proposals. The mean within-case Spearman association between candidate match score and *negative* rigid physical error was only 0.079. Selecting the highest-scoring predicted plane gave 2.855 mm identity-equal rigid error, versus 2.967 mm for the image prior and 1.175 mm for an oracle choosing the best of eight. The 0.112 mm reduction failed the preregistered 0.250 mm gate. Matching points on the selected predicted plane still erred by 3.241 mm. The true-rigid-win part of the gate passed, but the full capture gate **failed**.

This is a sharp distinction: the 2D cross-contrast feature is informative *at* a good plane, but the current pose network rarely proposes one close enough for this local score to rank or refine reliably. Reusing this feature as another top-eight ranker would repeat the failed 020/021 pattern. The next necessary test is its angular capture range at known atlas points; that determines whether an explicit many-orientation atlas search as in [SLIV-Reg](https://arxiv.org/html/2410.18683v1) is feasible with 025 as trained, or whether rotation-equivariant/augmented descriptors are needed first. None of these development results imply real histology accuracy, calibrated electrode-region claims or a deployed model.
